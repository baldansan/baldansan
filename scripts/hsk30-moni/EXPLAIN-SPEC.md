# Монгол тайлбар (explainer) — spec, нэг тест нэг удаа

Working dir `/home/claude/work/m30`. Input: `out/<TID>/extract.json` (асуултууд, хариу, сонсголын script).
Level ≥3 бол номын албан тайлбар бас бий: `src/L<n>/ans_*答案解析.ocr.txt` (OCR — алдаатай байж болно; тайлбарын хуудасны зураг `src/L<n>/ans_*答案解析_pages/p-NN.png`). Түүнийг үндэс болгож монголоор бич, шууд орчуулж хуулахгүй.

## Output: `out/<TID>/explain.json`
```json
{ "1": { "explanation_mn": "…", "tutor_note": { … } }, "2": { … }, … }   // key = q_no (string), БҮХ асуултад
```
`tutor_note` бүтэц (`why` заавал, бусад нь байвал):
```json
{
 "transcript": [{"zh":"女：请坐！","pinyin":"nǚ: qǐng zuò!","mn":"Эм: Суугаарай!"}],   // зөвхөн сонсгол; script мөр бүр + question_zh бол "问：…" мөр
 "key": "我在超市买东西呢",          // хариуг шийдсэн хэллэг (zh)
 "keyMn": "Би дэлгүүрт юм авч байна",
 "why": "Зөв сонголт яагаад зөв бэ — 1–3 өгүүлбэр, монголоор. Хятад үг хэллэгийг «…» дотор ханзаар нь өгнө.",
 "wrong": {"A": "яагаад буруу", "C": "…"},   // буруу сонголт бүрт (зураг бол тухайн зурагт юу байгааг хэлээд)
 "trap": "Асуултын урхи (байвал)",
 "tip": "Арга зүйн зөвлөгөө (товч)",
 "words": [{"zh":"超市","pinyin":"chāoshì","mn":"супермаркет"}]   // 3–6 түлхүүр үг
}
```
`explanation_mn` = `why`-тэй ижил утгатай, 1–3 өгүүлбэр (хуучин UI-д харагдана).

## Дүрэм
- Энгийн, амьд монгол хэл. Орос галиг (магазин, стол, кино г.м. ярианы орос үг) ХОРИОТОЙ — «дэлгүүр», «ширээ», «кино» (кино ok). Кирилл ө/ү-г зөв бич (өгүүлбэр, хүүхэд, зөвхөн).
- Ханзыг пиньинтэй нь хамт өг: «超市 (chāoshì)». Утга тайлбарлахдаа үгчилсэн калька биш, монгол хүн ингэж хэлнэ гэдэг хэлбэрээр.
- Сонсголд: юу сонссоныг (transcript), хариуг шийдсэн түлхүүр мөрийг, зөв/буруу сонголтыг тайлбарла.
- Уншихад: эх дэх түлхүүр өгүүлбэрийг ишлээд (zh + mn) яагаад гэдгийг хэл.
- 选词填空 / fill_char / complete (连词成句): дүрэм, үгийн хэрэглээг 1–2 өгүүлбэрээр тайлбарла (ямар үг ямар байрлалд, яагаад).
- Бичих (picture_sentence/essay): `why` = юу бичих ёстой, ямар бүтэц оноо авах вэ; `key` = загвар хариулт (zh) байвал; `wrong` хэрэггүй.
- Хүүхэд/эхлэгч уншина — богино, тодорхой. Нэг асуултад нийт 400 тэмдэгтээс хэтрэхгүй (essay-д 700).
- Хариуны зөв эсэхэд эргэлзвэл (номын хариу буруу гэж үзвэл) `"flag": "…"` талбар нэм, хариуг БҮҮ өөрчил.

Дуусаад `python3 check_explain.py <TID>` → OK. Товч тайлан: хэдэн асуулт, flag-ууд.
