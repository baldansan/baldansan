## Files
- `manifest.json` (2.1 MB): `{source, commit, license, license_url, attribution{syllables, words}, counts, syllables:[…], words:[…]}`
  - `syllables` (1,707): `{pinyin, pinyin_num, tone, marginal, file, size}`. `file` is the public URL path `/open/audio-cmn/syllables/cmn-<pinyin_num>.mp3`. `tone` 1–4, or 5 for the neutral tone (19 syllables). `marginal: true` marks 28 non-standard syllables whose upstream file names start with `_` (hm, hng, m, n, ng, lüan, nia…). Syllabic nasals have no tone mark in `pinyin`; use `pinyin_num`.
  - `words` (8,596): `{zh, pinyin, pinyin_src, file, url, size, level}`. `file` is relative to `/home/claude/open-media/audio-cmn/` and `url` is the upstream raw GitHub file. `zh` is taken from the file name; 27 grammar patterns such as `一_也_` are written `一…也…`. `pinyin` comes from `data/hsk_words.json` for 6,811 words; for the other 1,785 it is generated by pypinyin (tone marks; a trailing 儿 is written as erhua), so **a teacher needs to check 多音字**. `level` is the app HSK level from `data/hsk_words.json`, or null if the word is not in our list.
- **In the repo:** `public/open/audio-cmn/syllables/`, 1,707 mp3 files, 16.97 MB total (64 kbps mono, 48 kHz). This is under the 25 MB budget, so no re-encoding was done.
- **Not in the repo:** word audio, 8,596 mp3 files, 92 MB, in `/home/claude/open-media/audio-cmn/words/` (with a copy of the manifest).

## How it was produced
`python3 scripts/open/audio-cmn.py` (from the repo root). Raw clone: `/home/claude/open-media/raw/audio-cmn`. The script creates the clone if it is missing.

## Caveats
- The upstream README says "5,596 HSK_2000 words"; the actual `64k/hsk` folder has 8,596 files (words and single characters from the HSK 2000 list). There is no audio for about 580 HSK 2012 words, and the list is not HSK 3.0. Of the 8,596 words, 6,811 are in `data/hsk_words.json`.
- All word recordings are by one speaker and were recorded as isolated words (citation tones).
