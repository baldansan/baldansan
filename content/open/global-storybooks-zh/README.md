## Files
- `data.json` — `{source, source_url, repo, count, skipped[], stories[]}`. Story fields: `id` (`gsb-zh-NNNN`), `story_id`, `url`, `title`, `title_pinyin`, `title_en`, `level` (the site's reading level 1–5), `hsk_max` (highest HSK 3.0 level among words, 7 = HSK 7–9), `hsk_p90` (smallest HSK level covering 90 % of HSK-listed word tokens — more useful for sorting), `author`, `illustrator`, `translator`, `narrator`, `origin{title,url}`, `cover` (public path), `cover_url`, `audio_full`, `page_count`, `char_count`, `pages[]`, `source`, `license`, `license_url`, `attribution`.
  Page fields: `id` (`gsb-zh-NNNN-pNN`, NN = site page number, 01 is the cover), `page` (1-based story page), `zh`, `pinyin`, `hsk_max`, `en`, `image` (URL in github.com/global-asp/gsn-imagebank), `image_local`, `audio` (globalstorybooks.net mp3 URL), `audio_local`.
- `manifest.json` — every media file: `{story, page, kind (image|audio|cover|audio_full), url, path, bytes}`; `path` is relative to `/home/claude/open-media/global-storybooks-zh/` (736 files, ≈134 MB, all downloaded; NOT in the repo).
- `public/open/global-storybooks-zh/covers/NNNN.jpg` — one cover per story (≤ 320 px, ≤ 40 KB; 29 files, ≈ 600 KB).

## How it was produced
`python3 scripts/open/global-storybooks-zh.py --download` (parses `stories/zh/NNNN/index.html` + `stories/en/NNNN/index.html` from the clone; `RAW=` overrides the clone path). Shared helpers: `scripts/open/_kids_zh.py`.

## Caveats
- `pinyin` generated by pypinyin (Style.TONE, per-character readings in sentence context, grouped into words by forward-maximum matching against `data/hsk_words.json` + pypinyin's phrase list). **Needs teacher check** of 多音字 (e.g. 得 de/dé, 长 zhǎng/cháng) and of proper names (FMM can glue a name to the next word, e.g. 小明说 → xiǎo míngshuō). Tone sandhi of 一/不 follows pypinyin's dictionary (一个 yígè, but 一只 yīzhī).
- `hsk_max` is almost always 5–7 because each story contains a few rare nouns; use `level` or `hsk_p90` for grading.
- Text is already Simplified (no OpenCC conversion needed).
- No `mn` field yet (Mongolian translation is a later step).
