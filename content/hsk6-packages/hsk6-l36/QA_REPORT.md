## 2. Загвар хариулт / зохиомол (эх сурвалжид хэвлэгдээгүй)

- **练习4 分析论点和例证** — албан ёсны хариулт хэвлэгдээгүй. `lesson.json`-д «图书室» бичвэрийн 论点 (1-р өгүүлбэр) ба 3 例证 (首先 / 其次 / 另外)-ийг ӨӨРӨӨ бичсэн «загвар хариулт»; сонголтын буруу хариулт зохиомол.
- **练习5 简述课文** — нээлттэй даалгавар. `lesson.json`-д 3 асуултыг сонголттой болгож, 课文-ийн 提示-д тулгуурлан «загвар хариулт» бичсэн.
- **篇章（7）练一练 «课文-д 论点＋例证 хаана вэ»** — албан ёсны хариулт байхгүй. `grammar[3].exercises`-ийн 4 асуулт (3-р, 11–12-р, 19–23-р өгүүлбэр, «比如») өөрийн шинжилгээ — загвар хариулт.
- **练一练 (一经 / 截止)** дахь `choice` хэлбэрт хувиргасан асуултын буруу сонголт зохиомол. «专辑一经推出» (item 1): «一经发布» мөн утгын хувьд боломжтой; албан ёсны хариулт «推出» тул түүнийг зөв гэж үзэж, тайлбарт тэмдэглэсэн.
- **Багшийн ном байхгүй тул өөрөө бичсэн:** `teacher_mn`, `teacher_notes`, `common_mistakes`, `gloss_mn`, `check`, Тэмээ багшийн `hook` / `recap`. `common_mistakes`-ийн «wrong» бүгд үнэхээр буруу (截止比赛, 以截止……政策 — номын ×; 发布一经, 进行协商本着…, 本着努力学习 — үг дарааллын/бүтцийн алдаа). Хамгийн сул нь «你一经有空，就给我打电话吧» — бүтцийн хувьд хатуу буруу биш, «一经»-ийн хэрэглээ (нэг удаагийн үйлдэл, бичгийн өнгө)-д тохирохгүй гэсэн ЯРИАНЫ өнгө аясын алдаа.
- **Зохиомол жишээ өгүүлбэр («нэмэлт жишээ» гэж тэмдэглэсэн):** 一经: 这种药一经服用，很快就能见效。 · 合同一经签订，双方都必须遵守。 — 本着: 我们本着实事求是的态度…… · 学校本着因材施教的原则…… — 论点＋例证: 读书对人的成长非常重要。比如…… · 良好的习惯是成功的基础。比如……
- **Vocabulary-ийн `collocations_zh`** — эх сурвалжид 50 үгийн 搭配 байхгүй (зөвхөн 扩展1-ийн 8 үг). 课文-ийн хэллэг ба түгээмэл 搭配-ыг би бичсэн; шалгаж баталгаажуулахад зохино.
- **Монгол орчуулга:** 课文-ийн өгүүлбэрийн орчуулга бүгд `zh_mn_registry.json`-оос (өөрийн орчуулга биш). Номын жишээ (一经 2–3, 本着 2–3, 篇章 1–2, 截止/终止, 扩展1 例句) ба нэмэлт жишээг би орчуулсан; «IPCC» гэсэн латин товчлолыг «Засгийн газар хоорондын уур амьсгалын өөрчлөлтийн мэргэжлийн хороо» гэж бүтнээр орчуулав.

## 3. Эргэлзсэн / анхаарах зүйлс

- **Англи тайлбар**: «Латин 3+ үсэг монгол талбарт 0» дүрмийг баримтлан англи gloss-ийг монголоор орчуулсан.
- **层出不穷**: `pos` байхгүй → `pos: "хэллэг (成语)"`; пиньинь «céngchū bùqióng» (эх сурвалжийн зураасыг зайгаар сольсон). **命名**: эх сурвалжид «mìng míng» → «mìngmíng».
- **Хичээлийн «~700 ханз / 40 үг / 36 асуулт»** загварын тоо. Бодит тоо: 课文 29 өгүүлбэр, 1053 ханз (ханзны тоо `lines`-ээс), 50 шинэ үг, дасгалын ном 37 асуулт (17 听力 + 19 阅读 + 1 书写). `lesson.json` description-д бодит тоог оруулсан.
- **Нэр**: 东佳书院 → Дунцзя шуюань, 丽泽书院 → Лизэ шуюань, 《学规》 → «Сургуулийн дүрэм», 唐/宋/清 → Тан/Сүн/Чин гүрэн (registry-ийн glossary-тай ижил).
- **register**: 4 цэг бүгд 书面语 — 一经, 本着 нь номд бичгийн өнгө; 截止/终止 хос үг, 篇章修辞 нь 书面语-д хандсан — миний шийдвэр (номд тусгайлан заагаагүй). `語体 6 хос` (将/把…) энэ хичээлд байхгүй тул 语体-ийн асуултыг 一经↔一旦-аар орлуулсан; `discourseRhetoric`-ийг texts.json хариуцна.
- **截止——终止 examples**: номын «截止比赛/活动/战争（×）»-ийг жишээнд оруулалгүй `common_mistakes`-д буруу жишээ болгон оруулсан; «终止比赛 / 活动 / 战争» (√)-ийг нэг жишээнд нэгтгэсэн.
- **hook / recap**: `texts.json`-ийн `lessonIntro.teacher_mn`, `warmup_mn`-тэй нийцүүлэхийг удирдагч хийнэ. `warmup_mn` нь 热身1-ийн асуултаас.

## 4. Техникийн шалгалт (build_grammar.py)

- Бүх JSON `json.load`-оор уншигдсан (ensure_ascii=False, indent=1).
- grammar.json: 4 цэг; жишээ [5, 5, 7, 5]; дасгал [5, 5, 6, 5] (choice + judge); common_mistakes [2, 2, 2, 2]; бүгдэд `check`, `register`, `teacher_mn`; пиньинь хөгтэй.
- vocabulary.json: 50 мөр, дараалал эх сурвалжтай ижил; пиньинь хөгтэй; монгол утга ≥4 тэмдэгт; `exampleChinese` бүгд 课文-ийн өгүүлбэр ба тухайн үг тэнд бүтнээрээ байна; `exampleMongolian` = registry.
- quiz.json: 35 = 14 cloze (5 сонголт) + 21 multiple_choice (4 сонголт); id `hsk6-l36-q01…q35`; order_index 1–35; correct_answer ∈ options; сонголт бүрийн утга explanation-д; зөв хариуны байрлал {0: 8, 1: 8, 2: 9, 3: 7, 4: 3}.
- lesson.json: hook, exercises_textbook (9 хэсэг, 49 item; бүгдэд answer ∈ options / word_bank), collocations (17 ≥ 12; 8 нь 扩展1, 9 нь 课文), recap.
- Нэг хятад өгүүлбэр → нэг монгол орчуулга: grammar / vocabulary / lesson.collocations дотор зөрчил 0 (registry-тэй тулгасан).
- Орос галиг (студент, магазин, класс, заправк, газет, телевизор, урок, институт, парк, доктор, цукар, ресторан, компьютер) — 0. Латин 3+ үсэг монгол талбарт — 0.
- Хятад бичвэрт хагас өргөний «, ? ! : ;» байхгүй (бүтэн өргөн ，？！：). Орчуулгыг чангаар уншиж «монгол хүн ингэж хэлэх үү?» гэж шалгасан.
