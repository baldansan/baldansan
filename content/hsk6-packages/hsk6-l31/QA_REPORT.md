## 2. Загвар хариулт / зохиомол (эх сурвалжид хэвлэгдээгүй)

- **Албан ёсны хариулттай** (дээрх хүснэгт) — грамматикийн 练一练 бүгд, 练习1–4. Тиймээс `lesson.json`-д зөв хариулт = албан ёсных; буруу сонголт (distractor) бүгд ЗОХИОМОЛ.
- **练习5 (简述课文) ба 写一写** — албан ёсны хариултгүй, нээлттэй даалгавар тул lesson.json-д ороогүй (texts.json-ийн `textExercises` / `applicationSummaryWriting`-д орно). **扩展 语素义** — зөвхөн утга; би сонголттой асуулт болгосон (зөв нь номын утга, буруу нь өөр үгийн утга).
- **Бүгдийг өөрөө бичсэн:** `teacher_mn`, `teacher_notes` (сурах бичгийн 注释-д тулгуурласан санал гэж тэмдэглэсэн), `common_mistakes`, `gloss_mn`, `check`, Тэмээ багшийн `hook` / `recap`, quiz-ийн 35 асуулт (өгүүлбэр нь номоос хуулагдаагүй, 课文-ийн утгыг ашигласан), vocabulary-ийн `mongolian` + `collocations_zh` (эх сурвалжид 54 үгийн 搭配 байхгүй, зөвхөн 课文-ийн хэллэг ба түгээмэл найдвартай 搭配 — баталгаажуулахад зохино).
- **Зохиомол жишээ өгүүлбэр** («нэмэлт жишээ» гэж тэмдэглэсэн): 逐 — 老师把全班的作业逐本批改完…, 这个城市的空气质量逐月好转…; 归根到底 — 他们的矛盾归根到底是沟通不够造成的。, 学习归根结底要靠自己…; 胡乱——随便 — 考试时间快到了，他胡乱把答案填上就交卷了。, 你随便坐，别客气。; 大词小用 — 哥哥一回家就对冰箱发动了总攻…, 弟弟宣布对我的零食实行全面封锁。 Мөн lesson.json-ийн collocations-ын 18 жишээ өгүүлбэр бүгд өөрийн зохиосон.

## 3. Эргэлзсэн / анхаарах зүйлс

- **练习3 (2) — албан ёсны хариулт ба үгсийн сангийн зөрүү:** сурах бичгийн word_bank = 预期 定期 钙 **蛋白质** 急于求成, харин хариултын хуудас «钙、**维生素**、定期、急于求成、预期» гэсэн. «维生素» нь хэвлэлийн алдаа гэж үзэж, lesson.json (word_bank + answer), texts.json-д бүгдийг «蛋白质» болгож нэгтгэсэн; тайлбарт (explanation_mn, answer_source) зөрүүг тэмдэглэсэн.
- **归根到底 练一练 (2) «一句话»:** номын хариулт C. Гэхдээ D байрлал («…一句话，我和她彻底绝交了») бас боломжтой байж болох тул lesson/grammar-ын сонголтод D-г ТАВИАГҮЙ (сонголт: A, B, C).
- **逐 练一练:** сатаатуулагчид нь зөв хариулт болох магадлалтай хэсгийг (жишээ нь B+F, D+E) оруулаагүй; зөв нь номын (AC, BE, DF).
- **大词小用-ийн common_mistakes:** «wrong» нь грамматик алдаа биш, харин өнгө аясын алдаа (албан бичигт хошин хэлц хэрэглэх; хүнд явдалд хэрэглэх). Нэр томьёоны хувьд «буруу» гэж үзсэн.
- **register:** 逐 — 书面语 (ном: албан; утгын онцлог); 归根到底 — both (бичиг/албан бас, ярианд ойролцоо «说白了»); 胡乱——随便 — both; 大词小用 — both (хошин хэлц, ярианд ч бичигт ч) — миний шийдвэр.
- **pos хоосон 5 үг:** 端端正正 («тэмдэг нэр (давтсан хэлбэр)»), 半途而废 / 循序渐进 / 急于求成 («хэллэг (成语)»), 归根到底 («оруулга хэллэг») — өөрөө тэмдэглэсэн. 不敢当 нь номд «v.» тул «үйл үг (хэллэг)», 狠心 нь «n.» тул «нэр үг» гэж номоор нь үлдээсэн.
- **Пиньинь:** vocabulary-д номын пиньиныг шууд авсан (зураас, апостроф, зайг нэг хэвийн болгосон: guīgēn dàodǐ, xúnxù jiànjìn, jíyú qiúchéng, shēngxiù, xiāodú). Жишээ өгүүлбэрийн пиньинийг pypinyin + jieba-аар үүсгээд олон дуудлагатай ханзыг шалгасан: 地 (逐字逐句地 → de), 了 (光临了 → le; бусад le), 调查 diàochá, 差别 chābié, 好处 hǎochu, 觉得 juéde, 着重 zhuózhòng, 为 (wèishénme, wéihù), 行 (bùxíng), 长 (chángcháng). 不/一-ийн тон өөрчлөлт (bú, yí/yì) болон 个 → ge хөнгөн тон автоматаар хийж, гараар шалгасан. Гараар засварласан ханз: 逐字逐句地, 光临了, 一爆发.
- **Хүний нэр / нэр томьёо:** registry-тэй ижил — 王老师 → Ван багш, 记者 → сэтгүүлч, 钱学森 → Цянь Сюэсэнь, 气功 → чигун, 太极剑 → тайцзи сэлэм.
- **hook / recap / warmup_mn:** `texts.json`-ийн `lessonIntro.teacher_mn`, `warmup_mn`-тэй ЯГ ижил байх ёстой — texts.json бичигдсэний дараа удирдагч тулгана (одоо өөрөө бичсэн). `warmup_mn` нь 热身1-ийн асуултаас («健康应该包括哪些方面»).
- **description:** загварын «~700 ханз, 40 үг» биш бодит тоо: 1 ярилцлага (24 ээлж, 1098 ханз), 54 үг, 4 дүрэм, сурах бичгийн 6 дасгал, дасгалын номын 36 асуулт.
- **Сурах бичгийн 6 дасгал:** 练习1–5 + 扩展. lesson.json-д 练习5 (简述课文) оруулаагүй (нээлттэй), оронд нь 词语搭配 12 нэмсэн.

## 4. Техникийн шалгалт (build_grammar.py + validate.py)

- Бүх JSON `json.load`-оор уншигдсан (ensure_ascii=False, indent=1).
- grammar.json: 4 цэг; жишээ [5, 6, 10, 5]; дасгал [5, 5, 7, 5] (choice + judge); common_mistakes [2, 2, 3, 2]; бүгдэд `check`, `register`, `teacher_mn`; пиньинь хөгтэй.
- vocabulary.json: 54 мөр, дараалал эх сурвалжтай ижил; пиньинь хөгтэй; монгол утга ≥4 тэмдэгт; `exampleChinese` бүгд 课文-ийн өгүүлбэр; `tag: "超纲"` — 品行, 紫外线.
- quiz.json: 35 = 14 cloze (5 сонголт) + 21 multiple_choice (4 сонголт); id `hsk6-l31-q01…q35`; order_index 1–35; correct_answer ∈ options; сонголт бүрийн утга explanation-д; зөв хариуны байрлал {индекс: тоо} = {0: 9, 1: 7, 2: 9, 3: 7, 4: 3}.
- lesson.json: hook, exercises_textbook (7 хэсэг, 48 item; бүгдэд answer ∈ options / word_bank), collocations (18 ≥ 12), recap.
- Нэг хятад өгүүлбэр нь файл бүрт нэг л монгол орчуулгатай (зөрчил 0); 课文-ийн өгүүлбэр registry-тэй ижил.
- Орос галиг (студент, магазин, класс, заправк, газет, телевизор, урок, институт, парк, доктор, цукар) — 0. Латин 3+ үсэг монгол талбарт — 0 (техникийн талбар, номын A–D байрлалын тэмдэг бусад).
- Хятад бичвэрт хагас өргөний «, ? ! : ;» байхгүй (бүтэн өргөн ，？！：).
- Орчуулга бүгдийг чангаар уншиж «монгол хүн ингэж хэлэх үү?» гэж шалгасан.
