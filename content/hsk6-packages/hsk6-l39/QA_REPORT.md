## 4. Пиньинь — гараар шалгасан / засварласан

pypinyin + jieba-аар үүсгээд (不/一 өөрчлөлт автомат), доорх олон дуудлагатай үгсийг гараар тогтоосон: 得 → de (变得, 睡得), 了 → le (үйл үгэнд залгасан), 地 → de, 着 → zhe, 还 → hái (我还没看), 行 → xíng/háng (行政 xíngzhèng), 发 → fā/fà (发育 fāyù, 发牢骚 fā láosāo), 长 → zhǎng (生长), 乐 → lè (乐趣, 欢乐 huānlè; «音乐 yīnyuè»), 为 → wéi (成为, 变为), 数 → shù (数据), 种 → zhǒng (种瓜), 重 → zhòng (重要), 都 → dōu, 当 → dāng (当选 dāngxuǎn), 好 → hǎo, 传 → chuán (传递), 差 → chà (差劲), 觉/假/调 — хэрэглэсэнгүй.
