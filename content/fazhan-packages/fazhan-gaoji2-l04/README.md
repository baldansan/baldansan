# fazhan-gaoji2-l04 — 《司徒雷登》(发展汉语 高级综合 II, 第4课)

## Агуулга
- «司徒雷登» — Хятадад төрсөн америк шашин номлогч, Яньчин их сургуулийн анхны ерөнхийлөгч, АНУ-ын Хятад дахь элчин сайд Сүту Лэйдэний намтар (改编自秦海《给你呈现一个完整的司徒雷登》 г.м.). 11 догол мөр, 3 хэсэг: 更是中国人的美国人 (1-3) / 燕京大学的首任校长 (4-7) / 失败的驻华大使 (8-11).
- 5 综合注释: 用……来说/就……而言, 于 (比/在), 都=甚至, 数 (概数), 持……态度 / 经…… / 将……V为…….
- 44 шинэ үг (生词), 5 综合注释 дүрэм, тус бүрд ≥4 жишээ, ≥2 нийтлэг алдаа, ≥3 дасгал.
- 7 WORD_EXPL (重点词语 тайлбар) — агентаар бичигдсэн.
- 综合练习 бүгд (15 хэсэг, 参考答案-аар баталгаажсан хэсгүүд ба нээлттэй даалгаврууд тус тусад нь тэмдэглэгдсэн). Quiz 32 асуулт (тайлбартай).
- **Конвенци**: workbook.json-ий бүх хэсэгт `instruction_zh` (жинхэнэ сурах бичгийн хятад гарчиг) ба `instruction_mn` ("<Ангилал> · <instruction_zh> — <тайлбар>") хосоор орсон.
