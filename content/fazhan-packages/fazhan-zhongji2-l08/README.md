# fazhan-zhongji2-l08 — 《燕子买房记》(发展汉语 中级综合 II, 第8课)

Нэг жирийн хотын гэр бүл (Яньзи ба түүний нөхөр) хэдэн жил түрээсийн байранд амьдарсныхаа дараа эцэст нь орон сууц худалдаж авах шийдвэр гаргах явцыг өгүүлсэн өгүүллэг — байршил сонгох санал зөрөлдөөн, санхүүгийн тооцоо, зээлийн дарамт зэргийг жинхэнэ амьдралын жишээгээр харуулна.

## Агуулга
- Нэг өгүүллэг (7 догол мөрт хуваасан): Яньзи байр хайх болсон шалтгаан → гэр бүлийн санхүүгийн хязгаарлалт → байршлын санал зөрөлдөөн → байр үзэх → худалдан авах шийдвэр → зээлийн дарамт, тайтгарал.
- 53 шинэ үг (生词) + 1 нэр үг (燕子), бүх жишээ өгүүлбэр эх бичвэр эсвэл агентаар зохиогдсон.
- 6 综合注释 дүрэм (看（把）你/他V/Adj的, 就是……也……, 从……出发, 让/叫你V你就V, 要么, Adj/V（点儿）就Adj/V（点儿）（吧）), тус бүрд 4 жишээ, 2 нийтлэг алдаа, 2-3 дасгал — **6 дүрэм, L06/L07-оос 1-ээр илүү**.
- 7 WORD_EXPL (虽说, 亲口, 即使, 心思, 面子, 好歹, 应付) — агентаар бичигдсэн.
- COLLOC 3 бүлэг (~价, ~型, ~族), WORD_CMP 3 хос (议论/讨论, 朝向/方向, 应付/对付).
- 综合练习 11 бүлэг бүгд (一-十一, 一 хоёр дэд хэсэгтэй тул 12 хэсэг), 参考答案-тай тулгасан хэсгүүд бүгд баталгаажсан; нээлттэй даалгаврууд (九-5,6, 十一) тодорхой тэмдэглэгдсэн.
- Quiz 32 асуулт (тайлбартай).
