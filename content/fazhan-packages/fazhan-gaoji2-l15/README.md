# fazhan-gaoji2-l15 — 《廖承志致蒋经国先生信》(发展汉语（第二版）高级综合 II, 第15课)

## Агуулга
- Хичээлийн эх: Ляо Чэнчжигийн 1982 оны 7-р сарын 25-нд «人民日报»-д нийтлэгдсэн алдарт захидал (эртний бичгийн хэл + орчин үеийн бичгийн хэл хослуулсан) — 8 догол мөр, 58 өгүүлбэр.
- 词语表 55 үг (key 21) + 19 тусгай нэр (廖承志, 蒋经国, 蒋介石, 廖仲恺, 孙中山, 国民党, 三民主义 г.м.).
- 3 综合注释 дүрэм: 为(wèi/wéi) / 再者 / 何 (何必/何不/何等/何其).
- 字词准备: 猜一猜 “手”, “展”, “势”, “繁” — 4 бүлэг (WB part 1-4); 综合练习 一-九 бүгд (аудио/课件 PPT байхгүй тул 十 анхны ном-гийн дугаарлалтаас өөр — энэ хичээлд 课外实践活动 нь 九 дугаартай).
- 阅读理解 (综合练习 八) нь захидлын сэдэвтэй шууд холбоогүй, Мао Зэдуны «致徐特立» (1937) захидлыг ашигласан — номын өөрийнх нь сонголт, өөрчлөхгүй үлдээсэн.
- 7 WORD_EXPL — агентаар бичигдсэн (咫尺, 妥协, 安居乐业, 展望, 振兴, 艰辛, 前仆后继).
- workbook: part 0 = 综合注释 练习 (为 5, 再者 1, 何 3 = 9 дасгал), part 1-14 = 字词准备 (手/展/势/繁) + 综合练习 一-九.
- Quiz 32 асуулт (vocab 13, grammar 11, reading 5, usage 3), тайлбартай.

## Юу ЭНД БАЙХГҮЙ
