# fazhan-chuji2-l17 — 《约会》(Болзоо) (发展汉语 初级综合 II, 第17课)

## Агуулга
- Валентины өдрийн орой цэцэгтэй хүлээсэн залуу охиноос салах дуудлага хүлээж, цэцгээ өөр ганцаардсан охинд бэлэглэсэн, жилийн дараа тэр охинтой гэрлэсэн түүх (9 догол мөр, 27 өгүүлбэр).
- 29 шинэ үг (生词) + 1 专名 (情人节), 3 综合注释 дүрэм (尽管……但是……, 到底=终于, 到底=究竟) + 课文注释 2 (不再, 于是) = 5 дүрмийн цэг; тус бүрд ≥4 жишээ, 2 нийтлэг алдаа, 3 дасгал.
- 7 WORD_EXPL, COLLOC 2 (~机, ~场), WORD_CMP 4, RETELL 3, COMPREHENSION 12, quiz 32.
- 综合练习 一-十一 бүгд (八-ийг 1-6 / 7 复述 гэж, 九-ийг 判断 / 回答 гэж хуваасан), 课堂活动.
- **ШИНЭ КОНВЕНЦИ**: workbook.json-ий бүх хэсэгт `instruction_zh` (номын хятад гарчиг) ба `instruction_mn` («<Ангилал> · <instruction_zh> — тайлбар») хосоор орсон.
