# 第9课 爱的教育 (Education of Love) — 初级综合 II, х.90-100 (PDF 108-118)

## 综合注释
1. N1让/叫N2+V (妈妈让我回家 / 老师叫我们读课文 / 我没叫他来 / 妈妈不让我和弟弟喝酒). 试一试 (1)公司派你去哪里工作？B:__(叫 四川) (2)爸爸，我想买个新手机。B:__，她说你的手机刚用了半年。(不让 买) (3)你怎么来了？张老师__。(叫 帮助) (4)今天是星期日，你怎么不休息？B:__。(让 上班)
2. ……，特别是…… (①我爱吃中国菜，特别是四川菜。②这里很干燥，特别是春天的时候。③她很喜欢运动，特别是游泳。) 试一试 例：你们那儿冬天冷吗？很冷，特别是一月。(1)你们那儿吃的东西便宜吗？(水果) (2)你们经常去酒吧吗？(周末) (3)你喜欢吃中国菜吗？(北京烤鸭)
3. A不如B(+Adj/VP) = A没有B(+Adj) (①听CD不如听音乐会。②我的汉语不如一年以前了。③田中的汉语不如大卫说得好。) 注意: 形容词通常是褒义的。试一试 用“不如”改写: (1)我的房间小，马丁的房间大。(大) (2)今天20℃，昨天22℃。(暖和) (3)他的阅读能力很强，我的阅读能力不强。(强)
4. A有B(这么/那么)+Adj/VP, 否定: 没有 (①你的汽车有我的(这么)省油吗？②东京冬天没有北京(这么)冷。③我没有他(那么)喜欢打篮球。) 试一试 选例句: (1)A:__？B:不如你的省油。(2)A:你跟他一样喜欢打篮球吗？B:__。(3)A:东京冬天有北京冷吗？B:__。
