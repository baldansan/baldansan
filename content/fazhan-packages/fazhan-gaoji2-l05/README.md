# fazhan-gaoji2-l05 — 《红牌轶事》(发展汉语 高级综合 II, 第5课)

## Агуулга
- «红牌轶事» — 《当代足球》-ээс (原色): хөлбөмбөгийн шүүгч, улаан картын хөгжилтэй түүхүүд. 7 догол мөр, 5 дэд гарчиг: 在球场里的东西都归我管 (1-2) / 绝对职业的裁判 (3) / 都是失恋惹的祸 (4) / 裁判，你可以下场了 (5) / 红牌大战 (6-7).
- 5 综合注释: 这下/这样一来, 副+名 (很现代), “个”结构, 当回事儿/事儿 хэллэг, 无独有偶.
- 48 шинэ үг (生词), 5 综合注释 дүрэм, тус бүрд ≥4 жишээ, ≥2 нийтлэг алдаа, ≥3 дасгал.
- 8 WORD_EXPL (重点词语 тайлбар) — агентаар бичигдсэн.
- 综合练习 бүгд (17 хэсэг, 参考答案-аар баталгаажсан хэсгүүд ба нээлттэй даалгаврууд тус тусад нь тэмдэглэгдсэн). Quiz 32 асуулт (тайлбартай).
- **Конвенци**: workbook.json-ий бүх хэсэгт `instruction_zh` (жинхэнэ сурах бичгийн хятад гарчиг) ба `instruction_mn` ("<Ангилал> · <instruction_zh> — <тайлбар>") хосоор орсон.
