# fazhan-gaoji2-l09 — 《康熙皇帝》(发展汉语 高级综合 II, 第9课)

## Агуулга
- «上下五千年», Янь Чуннянь «康熙大帝»: Канси хааны намтар — шаргуу сурсан бага нас (勤奋学习), Аобайг ухаалгаар барьсан (智擒鳌拜), гурван вангийн бослогыг дарсан (平定三藩).
- 字词准备 (猜一猜 同/平/投/实), 3 综合注释 (省略主语, «数 + 人/物/事 + 评价词», «X也Y，不X也Y»), 综合练习 一-十.
- 49 шинэ үг (词语表 бүгд), 3 дүрэм (综合注释), тус бүрд ≥4 жишээ, ≥2 нийтлэг алдаа, ≥3 дасгал.
- 7 WORD_EXPL (重点词语 тайлбар) — агентаар бичигдсэн; Quiz 32 асуулт; workbook 18 part (part 0 = 综合注释 练习).
