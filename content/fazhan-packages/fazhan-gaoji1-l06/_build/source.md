# source.md — 第6课 网络时代的爱情 (PDF зургаас гараар уншсан; номын мэдээлэл, хариулт нь 参考答案-аас)

## 题解
在网络中，不论你在现实生活中的地位多么引人注目，不论你是百万富翁还是穷人，你都可以以一个普通人的身份出现，你和别人都只有代号，别的一切都可以忽略不管。

## 课文 (догол мөр бүрээр)

[1] 不管是虚幻的还是真实的，网络时代的爱情，都不可否认地悄悄走进了我们的生活。互联网开始取代月老手中的红线，使许多还未曾见面、甚至远隔千山万水的爱情追求者通过互联网相识、相知、相恋，其中有的人还挽着手走上红地毯，实现了自己追求美满婚姻的梦想。

[2] 一张虚幻的、不可触摸的网，为什么具有如此巨大的魅力呢？我们先来分析一下网上恋情发展的过程。

[3] 网上恋情的发展经过其实并不复杂，通常是在平平常常的聊天儿中开始的。一些网络爱情故事的成功者说，他们并非一开始就以寻找爱情为目的去上网，他们大多数只是随随便便地进入某个网站的聊天室，和别人谈天说地，进行交流。害怕心灵的孤独，寻找与人交流的机会，这恐怕是人的天性。而在现实生活中，由于竞争的激烈，感到孤独的人确实不少。因而，网上聊天室成了人们交流思想的“场所”，人们可以用文字、符号毫无顾忌地表达自己的思想，寻找心中渴望的友情。经过一段时间，你就会发现在与你聊天儿的网友中，有一位就是你的知己，你和他或她聊得越来越对劲儿，共同语言越来越多，再后来，你可能很想和对方见面，如果对方是一位异性，那么就有可能发展为一段网络爱情故事。网上爱情吸引着越来越多的年轻人，许多人都想试一试。

[4] 可是，据了解，网络恋情的成功率并不像人们期望的那么高。那么，网络恋情的吸引力在什么地方呢？下面我们来作一些进一步的分析探讨。

[5] 第一，网络上人际交往的隐蔽性。曾经看到这样一张漫画：一只狗坐在电脑前，用爪子敲打键盘，另一只狗在旁边用怀疑的眼光看着它。敲键盘的狗得意地说：放心吧，在网上，没人知道你是一只狗。这张漫画一针见血地指出了网上交往的特点：隐蔽性——真实身份的隐蔽，性别的隐蔽。网上聊天儿中，异性之间的交往是无所拘束的，人人都可以用一个网名或代号，通过聊天室、留言板、博客等，在世界各地的无数陌生人面前充分展示自己的个性，表达自己的思想。你只要上网进入聊天室，就随时可以找到陌生的异性朋友聊天儿，聊得来就聊下去，聊不来随时可以中断离开。这样的聊天儿甚至无需什么开场白或客套话，可以直率地说出自己想说的话。之所以能这样，就是因为网络交往有隐蔽性，你不用担心人们知道你是谁，你是男的还是女的，也不用担心说错话，因为说错了也没关系，没有人会追查。而在现实生活中，互不相识的人，尤其是互不相识的异性要想随意聊天儿是不可能的事，即使在同事或者朋友中，异性之间的交往若是过深或者过于频繁，就可能遭到他人的议论甚至指责。而在网上交往，这种隐蔽性就使得人们在交往中不用考虑这些外在因素，个人的思想感情得到充分的表达和发挥，无论性格内向拘谨还是外向随和，在网络交流中都可以直率表达，甚至连害羞的人也会主动地对网上的陌生人说：“咱们交个朋友吧！”

[6] 第二，网络上人际交往的平等性。平等性在人类的交往中具有重要意义，人类几千年来发生的大大小小的战争，很多是因为平等问题造成的。人们建立友谊的基础是平等，是精神上的快乐。这种平等，首先是地位上的平等，没有尊卑、高低之分；其次是相互之间没有利益冲突。这两点在传统的人际关系中很少能同时具备，而这在网络中是轻而易举的，是它的优势。在现实生活中，人们的交往都事先确认了对方特定的身份，或者是亲戚、同学、同事，或者是上级、下级、合作伙伴等，因而就形成了一定的交流障碍，带来了一些交往的限制。而在网络中，不论你在现实生活中地位是多么引人注目，不论你是百万富翁还是穷人，你都可以以一个普通人的身份出现，你和别人都只有代号，别的一切都可以忽略不管，只注重语言和思想的交流，获取精神上的快乐。

[7] 第三，网上人际交流的神秘性。网上的交流对象可能是未曾见过面的，聊得多了，人们就不知不觉地猜想：对方是个怎么样的人？为什么和我有这么多共同语言？这就是神秘性。神秘来源于陌生，陌生使交往带有新奇感，因而更有意思。具有神秘性的事物一般都有吸引力和诱惑力，很多人都想试一试；另外，网络的空间距离也会使人产生一种朦胧的美感，为人的想像提供足够的空间，所以也有些人只满足于在网上与想象中的情人聊天儿，并不急于见面。生活中我们常常能看到这样的事：如果恋人相距遥远，那么他们往往会互相思念，不知不觉中把对方美化成天使；而如果每天在一起，就有可能产生许多矛盾。这对于富于幻想的人来说，尤其如此。另外，我们还可以说，网络的广阔空间为谈情说爱提供了很好的土壤。两个人在网上交谈，表达感情会更加大胆热烈，即使是内向的人也会变得勇于表白。许多外貌有缺点的人有了充分展示自己魅力的机会，使对方在性格上、学问上对自己先取得好印象。这样，可以使人忽略家庭背景、身份、经济条件等外在因素，远离世俗，全心全意地投入到感情世界里，这样的爱更纯粹。

[8] 第四，网上恋情是都市人追求更高生活质量的表现。就整体来看，人类的活动领域在不断扩大，已经进入去太空旅行的世纪了。但就多数的个体而言，人的活动空间却在不断缩小，特别是在现阶段，人们的交往更因物质生活的提高而减少。据调查，目前人们在生活中来往得最多的是同事，这样的交往范围显然不能满足人们的要求，很多人渴望有在家庭和工作范围外的交际活动，扩大自己的视野，而互联网的出现正好满足了这种需要，提供了更大的交往空间，各种各样的人都可以在这里谈天说地。从另一方面说，由于网上交流不存在面对面时可能出现的尴尬，也可以不考虑对方的面子，这对于长期处于紧张工作状态的人来说，当然是一种很放松的交流方式，只有这样，才能展现真实的自己。同时，能与世界各地的人们谈天说地，也为整天忙忙碌碌的生活增添了一些浪漫色彩。

[9] 有位网友说：“网络爱情就像肥皂泡，只能欣赏，不能真正拥有，虚幻的爱情只存在于假设之中，即使是这样，我内心还是想寻找那种浪漫的感觉，寻找更为丰富多彩的生活。”这句话有一定的代表性，也许可以说，网上恋情是人们对更高生活质量追求的表现。人在满足了衣食住行的需求之后，必将在精神上有更多的期待，这就使网络恋情有了比较深厚的发展基础。

## 综合注释

### 1. 无条件复句 (不管 / 不论 / 无论……，都……)
不管 / 不论 / 无论 + хоёр ба түүнээс олон нөхцөл (A还是B · V不V · 疑问词)，(主语) + 都 / 也 + үр дүн
 - 不管你同意不同意，我都这样做。
 - 不管红茶还是绿茶，我都喜欢。
 - 她不管做什么，都非常认真。
 - 这鞋子不论多么贵，他都要买。
 - 不论你去哪儿，我都跟你在一起。
 - 无论她是否愿意，都应该独立完成这项工作。
 - 无论天气怎么样，我们都得去看看。
### 2. 未曾
(主语) + 未曾 + V + 过 / 宾语   (= 没有……过)
 - 发生这种情况，是我未曾预料到的。
 - 历史上这里还未曾发生过这么严重的地震。
 - 我未曾遇到过这种情况。
 - 她的这种人生信念未曾动摇过。
### 3. 并非
(主语) + 并非 + 名 / 形 / 动 + …… (, 只是 / 而是 ……)   (= 并不是 / 其实不是)
 - 她并非我的女朋友，我们只是比较要好的同学。
 - 我并非公司里的正式工作人员，只是在这里实习。
 - 并非所有的人都掌握了这种新技术，真正掌握这种技术的只是一部分人。
 - 我并非是有意骗你，你以后会慢慢明白的。
### 4. 据
据 + 名 / 动 / 小句 (, 主语 + 谓语)   ·   主语 + 据 + 动词 (估计 · 说 · 统计)
 - 据可靠消息，明天的天气会发生变化。
 - 据说，他刚从国外进修回来。
 - 据我们统计，药品的价格已经下降了百分之二十。
 - 明年的产量据估计，还会继续增加。
### 5. 就……来看 / 而言 / 来说
就 + 名 / 小句 + 来看 / 而言 / 来说，主句   (= 从……方面来看 / 来说)
 - 就你现在的汉语表达能力来看，要翻译这本书还有一定的困难。
 - 就汉字书写的情况来看，我们还有很多需要注意的地方。
 - 就球技而言，我们并不比你们差。
 - 就理论水平来说，老张比老刘高，就工作经验而言，老刘比老张丰富。

## 注释 练习 (бүгд)

### 1 无条件复句
1. A. 完成句子：(1) 无论古典音乐还是流行音乐，________。  => 我都喜欢
2. (2) 不管遇到什么困难，________。  => 我们都得想办法解决
3. (3) ________，我都会记住这句话。  => 无论什么时候
4. (4) ________，我们都要注意保护环境。  => 不论在什么情况下
5. B. 改正句子：(1) 不管天气非常冷，他早上都坚持锻炼。  => 不管天气多冷，他早上都坚持锻炼。
6. (2) 不论这些工作的报酬很低，她也要做好。  => 不论这些工作的报酬多低，她也要做好。
7. (3) 无论你们看不看，我要看。  => 无论你们看不看，我都要看。
### 2 未曾
1. 用“未曾”改写：(1) 他们虽然没有见过面，但已彼此熟悉对方的名字。  => 他们虽然未曾见过面，但已彼此熟悉对方的名字。
2. (2) 分手之后，我们俩还没有相遇过。  => 分手之后，我们俩还未曾相遇过。
3. (3) 在我们这个地区，此类传染病还没有发生过。  => 在我们这个地区，此类传染病未曾发生过。
### 3 并非
1. 用“并非”完成对话：(1) A：这种观点是否完全正确呢？ B：________。  => 我看，这种观点也并非完全正确。
2. (2) A：有人说，这种预防感冒的药有副作用，是这样的吗？ B：________。  => 依我看，这种说法并非正确。
3. (3) A：你们公司一直与黄先生的公司有合作关系，对吗？ B：________。  => 这种说法只是猜测，并非事实。
### 4 据
1. 用“据……”改写：(1) 请你按照实际说明情况。  => 请你据实说明情况。
2. (2) 根据医生的说法，他的病很快就会好的。  => 据医生说，他的病很快就会好。
3. (3) 记者报告说，这场大风造成了数十万美元的损失。  => 据记者报告，这场大风造成了数十万元的损失。
### 5 就……来看 / 而言 / 来说
1. 用“就……来看 / 而言 / 来说”改写：(1) 在消费能力方面，北京和上海是全国最高的。  => 就消费能力来说，北京和上海是全国最高的。
2. (2) 从会议内容来说，讨论医疗制度的改革最多。  => 就会议内容来看，讨论医疗制度的改革最多。
3. (3) 在如何保护环境方面，我们的设计还需要不断完善。  => 就如何保护环境而言，我们的设计还需要不断完善。

### part 10: 七、阅读短文并做练习（关于“网上婚姻”）：根据上文内容判断正误，并说明原因  [word]
1. 关于“网上婚姻” 一位女士发现了她的丈夫“网上结婚”的行为，一气之下，告到了法院，要求离婚，并要求法院判处丈夫赔偿自己的精神损失。就这件事，记者采访了一位婚姻法专家。专家表示，对已婚者“网上结婚”的行为不能随便做出结论。如果仅仅把“网婚”当做一种游戏，而且现实生活中的配偶（pèi’ǒu）也能谅解，那就没有什么大问题；可是如果沉迷在这种游戏中不能摆脱，而且严重伤害了配偶的感情，很可能会导致婚姻的破裂，法院应准予离婚。但是，虚拟婚姻不符合国家婚姻法的要求，不受法律承认和保护，也不能构成法律上的“重（chóng）婚罪”，因此就这种情况要求经济赔偿，有较大的难度。中国《婚姻法》规定，只有因为重婚、有配偶者与他人同居、家庭暴力、虐待并抛弃家庭成员等四种情况引起的离婚，无过错的一方才有权请求经济赔偿，而“网婚”则不属于这些范围。 判断正误：“网上婚姻”得不到法律承认和保护。  => 对
2. 判断正误：如果夫妻双方有一方“网上结婚”，另一方可以要求离婚并且得到经济赔偿。  => 误
3. 判断正误：当“网上婚姻”仅仅是一种游戏，配偶也能理解时，也不会造成大的问题。  => 对
4. 判断正误：如果丈夫或妻子在没有离婚的情况下与别人同居，另一方可以提出离婚并要求经济赔偿。  => 对
5. 判断正误：“配偶”的意思是指妻子。  => 误
