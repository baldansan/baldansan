# fazhan-gaoji1-l02 — 《起名字》(发展汉语 高级综合 I, 第2课)

## Агуулга
- Е Жаоянь (叶兆言)-ийн «名与身随»-ээс авсан 11 догол мөртэй урт эссэ (52 өгүүлбэр, 1753 ханз): зохиолчийн өөрийн, өвөөгийн, аавынх, охины нэрийн түүх; ижил нэр, нууц нэр, нэр ба «чанар» (货色).
- 51 шинэ үг (词语表, номын дарааллаар) + 专名 姚; 成语/хэллэг: 顺理成章, 迫不及待, 囊中羞涩, 无所不谈, 不谋而合, 不以为然, 喜气洋洋.
- 5 综合注释 дүрэм (转折复句, 所谓, 最（再）……不过, 此外, 鉴于), тус бүрд ≥4 жишээ, ≥2 нийтлэг алдаа, ≥3 дасгал; 综合注释-ийн «练习» бүгд (20) нь workbook-ийн part 0-д.
- 8 WORD_EXPL (免不了, 随意, 类似, 挂钩, 留心, 赌气, 分辨, 不以为然), 3 COLLOC (~名, ~物, ~近), 3 WORD_CMP, RETELL, CULTURE, INTRO, WRITING (调查 загвар).
- Workbook 11 part: part 0 = 试一试 (20), 1-3 = 字词准备 一二三, 4-10 = 综合练习 一~七.
- Quiz 32 асуулт (үг 13, дүрэм 12, ойлголт 5, хэрэглээ 2).
