# fazhan-chuji2-l19 — 《笔友》(Захидлын найз) (发展汉语 初级综合 II, 第19课)

## Агуулга
- Алис (америк охин), «Би» хоёрын олон жилийн захидлын нөхөрлөл, төгсгөлд Алисын илгээмж ба зураг (11 догол мөр, 29 өгүүлбэр, зохиогч нэргүй [印度] 佚名, сүлжээний эсээ).
- 27 шинэ үг (生词), 3 综合注释 дүрэм (只有……才……, 是……的 (үнэлгээ, тайлбар), 好在) + 课文注释 2 (好 = зорилго, V啊V) = 5 дүрмийн цэг; тус бүрд ≥4 жишээ, 2 нийтлэг алдаа, 3 дасгал.
- 7 WORD_EXPL, COLLOC 2 (~友, 信-той холбоотой үгс), WORD_CMP 5 (为了/好, 地址/地点, 曾经/已经, 吃力/累, 死/去世), RETELL 3, COMPREHENSION 16, quiz 32.
- 综合练习 一-十一 бүгд (九-ийг 判断 / 回答 гэж хуваасан), 课堂活动.
