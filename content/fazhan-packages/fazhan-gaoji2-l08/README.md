# fazhan-gaoji2-l08 — 《广告亦当入乡随俗》(发展汉语 高级综合 II, 第8课)

## Агуулга
- Пэн Хунли «国际广告中的跨文化因素»: олон улсын сурталчилгаан дахь хэл, соёл, шашны ялгаа; амжилттай жишээ (可口可乐, 百事可乐, 人头马, 青岛啤酒), бүтэлгүй жишээ (东芝, Хонконгийн «想做就去做», 骆驼牌, Грекийн сүм, 索尼), дүгнэлт «入乡随俗».
- 字词准备 (猜一猜 销/推/大……大……/决), 5 综合注释 (同……相比, 如果……不仅……还……, 替代手段 这/该/其, 谐音, 则), 综合练习 一-九.
- 47 шинэ үг (词语表 бүгд), 5 дүрэм (综合注释), тус бүрд ≥4 жишээ, ≥2 нийтлэг алдаа, ≥3 дасгал.
- 7 WORD_EXPL (重点词语 тайлбар) — агентаар бичигдсэн; Quiz 32 асуулт; workbook 15 part (part 0 = 综合注释 练习).
