## 题解
生活是一个万花筒，不论怎么变化，总有一些东西让人感到温暖，那就是人性之美。汉语常用“女中豪杰”形容女性中的杰出人物，女性的勇气有时也会令男性自愧不如。

## 字词准备 (х.33-35)
猜一猜 “偏”(偏向 偏爱 偏心 / 偏差 偏离 / 偏食 / 偏远 / 偏僻 / 偏见); “简”(简称 / 简历 简单 简明 简短 简体字 / 简要 / 简化 / 精简 / 简陋 简易); “生”(生手 / 生分 / 陌生 生疏 / 面生 / 认生 生人 欺生); “奇……怪(异)……”(奇禽怪兽 奇谈怪论 奇花异草 奇装异服)
 参考答案: 偏 1 不正，倾斜: 偏差 偏离; 2 注重一方面，不公正: 偏向 偏爱 偏心 偏食 偏见; 3 冷僻: 偏远 偏僻 / 简: 简单，使不复杂 (跟“繁”相对) / 生: 生疏 / 奇…怪(异)…: 罕见的，特殊的，非常的
