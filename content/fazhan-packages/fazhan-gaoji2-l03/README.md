# fazhan-gaoji2-l03 — 《三个丽友》(发展汉语 高级综合 II, 第3课)

## Агуулга
- Жү Хунгийн «赤橙黄绿青蓝紫» түүвэрээс сонгосон өгүүллэг «三个丽友»: 赤 (Чи) Кокосилид замын ажилчинг тэвэрсэн (1-4), 绿 (Лү) илүү өгсөн мөнгийг буцаасан (5-9), 青 (Чин) захирал «Фан авга»-д зоригтой санал хэлсэн (10-14). 14 догол мөр, 3 түүх.
- 6 综合注释: 书面语↔口语 (之 的 / 之际 / 便 就 / 均 都), 年龄表达 (年近六十), X就X，Y就Y, AABB 重叠 (四类), 语义场, ……无不…….
- 41 шинэ үг (生词), 6 综合注释 дүрэм, тус бүрд ≥4 жишээ, ≥2 нийтлэг алдаа, ≥3 дасгал.
- 7 WORD_EXPL (重点词语 тайлбар) — агентаар бичигдсэн.
- 综合练习 бүгд (15 хэсэг, 参考答案-аар баталгаажсан хэсгүүд ба нээлттэй даалгаврууд тус тусад нь тэмдэглэгдсэн). Quiz 32 асуулт (тайлбартай).
- **Конвенци**: workbook.json-ий бүх хэсэгт `instruction_zh` (жинхэнэ сурах бичгийн хятад гарчиг) ба `instruction_mn` ("<Ангилал> · <instruction_zh> — <тайлбар>") хосоор орсон.
