# source.md — 第14课 中国婚姻60年之嬗变 (PDF зургаас гараар уншсан; номын мэдээлэл, хариулт нь 参考答案-аас)

## 题解
从新中国成立前的包办婚姻，到后来的婚恋自由；从改革开放前的严格限制离婚，到现在的离婚充分自由；从单一地选择婚姻，到自由多元的选择模式，在60余年的时间里，中国人对待婚姻的态度发生了最深刻的改变。

## 课文 (догол мөр бүрээр)

[1] 1950年5月1日，《中华人民共和国婚姻法》作为新中国第一部基本法付诸实施，这部政治色彩颇浓而革命意义极大的《婚姻法》为中国人的婚姻带来了翻天覆地的变化。从此，男女平等、婚姻自由和一夫一妻制以法律的形式固定了下来。

[2] 在《婚姻法》颁布的最初几年，中国父母们曾对允许子女自主婚姻的规定普遍感到不满，而在广大农村地区，抱怨“制定《婚姻法》是毛主席他老人家糊涂了”的老人也绝非少数。于是，包办如故，买卖依旧，1953年发布的一份调查甚至显示，当时全国每年因要求离婚而遭虐杀的妇女竟有七、八万人之多。鉴于此，政府不得不在全国发起声势浩大的“贯彻《婚姻法》运动”。

[3] 1955年，国务院又批准了《婚姻登记办法》，这意味着男女双方只需到政府登记即可办理结、离婚事宜。更多的父母之命于此后宣告作废，当代中国的第一次离婚热潮也随之达到顶峰，很多中国人正是在此时第一次意识到，原来女人是有权“休夫”的。

[4] 婚姻自由使嫁娶何人成了嫁娶者自己决定的问题。于是，婚姻的选择对象便成为了下一个问题。

[5] 战场上的英雄无疑是姑娘们心中的最佳人选，对上世纪五十年代的中国女人而言，嫁给军人就等于嫁给了光荣。

[6] 同样炙手可热的还有职场上的模范。“上一次劳模会上我爱上了人一个，他的名字叫赵振华。都选他做模范，人人都把他夸。”刘巧儿在大柳树下的这段表白，道出了那个年代不少姑娘的心声。“我爱他，身强力壮能劳动；我爱他，下地生产，真是有本领；我爱他，能写能算，他的文化好。回家来，他能给我做先生。”劳动互助和共同进步成了那时“爱情”二字的代名词。

[7] 这一时期，中国处于一个政治高于一切的年代，政治成为一切的主题，婚姻也如此。

[8] 那时的中国人在政治上被划分为三六九等。作为“红五类”的革命干部、军人、工人、贫农和下中农，由于是天生的革命者而普遍受到青睐；被打入“黑五类”的地主、富农、反革命、坏分子和右派，则因其令人畏惧的政治身份而遭遇冷落。

[9] 同样，除政治原因外，“文革”十年间，中国人很少再能找到什么说得出口的离婚理由。强烈的道德谴责足以给离婚者带来比不幸婚姻更大的痛苦，而在个人生活被各种评价体系五花大绑的年代，离婚可能导致的还有前途没落。

[10] 1978年以后，发生于这个国家的一切变化令世界为之瞩目。

[11] 开放的国门使长久自闭的中国人感觉到了巨大的冲击。他们开始接受并消化外来的先进科技、多元文化和更多更丰富的生活方式。社会生活的变化之剧，令置身其中的人们感受真切而又应接不暇。

[12] 1980年4月实施的新《婚姻法》将“感情破裂”规定为离婚的重要条件。中国人似乎开始意识到，爱情也是婚姻中颇为重要的东西。

[13] 那么，又该将爱情托付给谁呢？

[14] 改革开放之初的几年，大学生曾是众多年轻人心仪的伴侣。然而，没过多久，含金量的重要性便超过了知识，一些被称做“万元户”的人又开始在婚姻市场上变得抢手。渐趋务实的人们意识到，否认经济条件对爱情、婚姻的重大意义是过于做作了。

[15] 观念的变化还不止于此，在另外一些问题上，当时的人们显然走得更远，比如性。上世纪八十年代初，性解放思潮在西方已经没落，但在刚刚开放的中国，它的合理性却在中国人对萨特与弗洛伊德的理解中得到证实：人是自由的，欲望理应被满足。而且，这些统统与道德无关。在日渐宽容的社会里，婚外恋从一度让人强烈谴责的问题慢慢退居为供人消遣的话题。

[16] 新千年以后，《婚姻法修正案》规定，同居不再非法，但禁止有配偶者与他人同居。

[17] 这个社会已经越来越宽容。

[18] 无子的“丁克”（DINK：DoubleIncomeNoKids）、无性的“丁斯”（DINS：DoubleIncomeNoSex）、“周末夫妻”、不婚主义……不断浮出水面。

[19] 在选择多元与社会宽容的同时，人们也不得不接受由此带来的迷茫与痛苦。有人心生失落，有人焦虑不安，还有人索性将婚姻承载的意义悉数去除……国家现代化进程很快，人们接触到的理念和信息越来越多，以至于大家不知道该去信仰什么了。金钱、自由、情感还是责任？每个人的考量不同。

[20] 2000年的一则消息多少有点儿令人沮丧：科学家们认定，爱情实为人脑分泌多巴胺的结果，而这种化学物质给人带来的兴奋感往往不会超过三年。这项科学研究的一个副产品式的结论是：爱情难以成为婚姻的终极诉求。

[21] 现实中，多数人也并不把爱情当做终极诉求。2009年初的一项调查显示，“经济基础”仍是影响婚姻关系确立的首要因素；除此之外，大部分年轻人在择偶时还强调“门当户对”或“相似的家庭背景和生活环境”，认同这两项的受访者达69%，而选择“只要两个人彼此相爱就好，其他无所谓”的仅有26%。显然，在多数人眼里，日子是否能过好比爱情更为重要。然而，忠诚与信任的缺失也正在使这个年代的婚姻经受着严峻的考验。

[22] 2003年7月，新的《婚姻登记条例》实行，此后，中国人离婚不再需要审查期和介绍信。参与起草2001年《婚姻法》修正案的法学专家夏吟兰教授说，强调自己的责任已经成为我国婚姻立法的一个新理念。

[23] 换言之，在这个时代，“我的婚姻我做主”，可以；“谁的婚姻谁负责”，必须。

## 综合注释

### 1. 对偶（包办如故，买卖依旧）
A（词语 + 词语），B（词语 + 词语） — 结构相同 · 字数相等 · 声韵协调 · 排列对称
 - 包办如故，买卖依旧。
 - “我的婚姻我做主”，可以；“谁的婚姻谁负责”，必须。
 - 风声、雨声、读书声，声声入耳；家事、国事、天下事，事事关心。
 - 勤奋是点燃智慧的火花，懒惰是埋葬天才的坟墓。
 - 书山有路勤为径，学海无涯苦作舟。
 - 死生契阔，与子相悦；执子之手，与子偕老。
### 2. “把”字句：唱词与韵文中的特殊情况（人人都把他夸）
① 把 + O + V + 补语/了/一会儿…（一般）   ② 把 + O + 光杆 V（唱词、韵文：人人都把他夸）   ③ 某些「动 + 补」双音节动词：把命令取消 · 把水平提高
 - 人人都把他夸呀。
 - 我的爹在区上已经把亲退呀。
 - 我挎着小筐儿忙把桥上啊。
 - 小兔小兔把门开。
 - 我们必须把水平提高。
 - 大家再加一把劲，争取把工期提前到春节前完工。
### 3. 之（的 · 那么 · 它）
① N / A + 之 + N（宝中之宝 · 春夏之交）   ② A（高/多/久/严）+ 之 + 数量/程度（规模之大 · 三四十米之高 · 百万元之多）   ③ V + 之（随之达到顶峰）
 - 粮食是宝中之宝。
 - 春夏之交，气温忽高忽低。
 - 这次革命运动规模之大、范围之广、影响之深远都是前所未有的。
 - 中国有文字可考的历史已有大约四千年之久。
 - 该地粮食产量已达三亿斤之多。
 - 社会生活的变化之剧，令置身其中的人们感受真切而又应接不暇。
### 4. 一度（曾经一度 · 一年一度 · 几度）
① S + 一度 + V（一度失业，现在有了工作）   ② 一年一度 · 再度 · 三度 · 几度 · 两度 + N / V
 - 他一度失业，现在有了工作。
 - 他曾一度产生过自杀的念头。
 - 奥林匹克运动会一度由于战争停办。
 - 一年一度的春节就要来到了。
 - 青山依旧在，几度夕阳红。
 - 两党历史上曾有过两度合作。

## 注释 练习 (бүгд)

### 1 对偶
1. 练习 (1)勤奋是点燃智慧的火花，懒惰是埋葬天才的坟墓。 体会对偶  => （参考答案: 略）агентаар: «勤奋 / 懒惰», «点燃智慧的火花 / 埋葬天才的坟墓» — бүтэц ижил, үсгийн тоо тэнцүү, утга эсрэг.
2. 练习 (2)书山有路勤为径，学海无涯苦作舟。 体会对偶  => （参考答案: 略）агентаар: «书山有路 / 学海无涯», «勤为径 / 苦作舟» — 7 үсэгтэй хоёр мөр, тэгш хэмтэй.
### 2 “把”字句（韵文）
1. 练习 (1)大家再加一把劲，争取把工期________到春节前完工。  => 提前
2. 练习 (2)我们发誓永不分离，没有人能把________。  => 我们拆散 / 我们分开
3. 练习 (3)这个箱子是你的吧？把________！  => 它拿走
### 3 之
1. 练习 (1)每个人都享有接受教育之权利。 体会“之”  => 之：相当于“的”。
2. 练习 (2)中国有文字可考的历史已有大约四千年之久。 体会“之”  => 之：相当于“那么”，强调“久”。
3. 练习 (3)该地粮食产量已达三亿斤之多。 体会“之”  => 之：相当于“那么”，强调“多”。
4. 练习 (4)早晨八九点钟，地铁非常之拥挤。 体会“之”  => 之：相当于“的”，强调“拥挤”。
### 4 一度
1. 练习 (1)这是一条曾经一度以狼为敌的猎狗。 解释画线部分  => 一度以狼为敌：曾经把狼作为敌人
2. 练习 (2)奥林匹克运动会一度由于战争停办。 解释画线部分  => 一度由于战争停办：曾经有一段时间因为战争的原因停办
3. 练习 (3)这家名声赫赫的诊所，……几经战乱，几度沉浮，并没垮台。 解释画线部分  => 几度沉浮：经历了很多次起伏
