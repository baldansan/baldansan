## Шалгах зүйл (бүгдийг, дараалан)
1. **Номтой тулгах** — хуудас бүрийг Read-ээр хараад: Let's learn-ийн БҮХ үг багцад байна уу (дутуу/илүү), ханз яг таарч байна уу, пиньинь аялгуу зөв үү (номынхтой тулга; 不/一 сандхи номд хэрхэн бичсэнийг дага), Key sentences, яриа бүрийн мөр бүр ханз яг номынх уу, дуу/chant-ийн мөрүүд бүрэн үү.
2. **Монгол орчуулга** — үг бүрийн `mongolian`: хүүхдийн үг үү (аав/ээж/багш…), утга зөв үү (англи gloss-той тулга), орос галиг (студент, класс, магазин, урок, доктор, адрес, номер, пар, фото…) байна уу; яриа/дууны `mn` утга зөв, байгалийн монгол үү (калька биш); `teacher_mn`, `explanation_mn` 9–11 настанд ойлгомжтой уу (дүрмийн нэр томьёо хэрэглэсэн бол энгийн болго).
3. **Хариулт** — grammar `check.answer`, `exercises[].answer` нь options дахь ЗӨВ хариуг заадаг уу (индекс текст, 0-ээс эхэлнэ; `shuffle` хэрэглэсэн бол скриптийн гаралт JSON-оор шалга); quiz `correct_answer` options дотор байгаа, үнэхээр зөв үү, сатаатуулагч нь ч зөв хариу болчихоогүй юу (нэгээс олон зөв хариу = алдаа); workbook `answer` номын хариултын түлхүүртэй (TEST-KEY.md) таарч байна уу, `explanation_mn` зургийн агуулгатай нийцэж байна уу.
4. **Зураг–үг таарц** (зураг хараахан үүсээгүй байж болно — pkg/images/w-*.jpg байхгүй бол энэ алхмыг алгасаж, зөвхөн manifest title = ханз яг эсэхийг шалга) — `pkg/images/w-*.jpg`-уудыг Read-ээр (contact sheet үүсгэж) хараад: зураг тухайн үгийн утгыг хүүхдэд ойлгомжтой илэрхийлж байна уу; manifest `media.images[].title` = тухайн үгийн ханз ЯГ (апп үүгээр таардаг); яриа/hero зургийн speech bubble-ийн ханз зөв үү (алдаатай ханз, латин үсэг, жинхэнэ хүн, айдастай/тохиромжгүй зүйл байвал тэмдэглэ — дахин үүсгэх шаардлагатай зургийг `regen` жагсаалтад бич).
5. **Тестийн зураг** — t*.png хайчилбар зөв зураг уу (тасарсан, буруу мөр биш), `optionImages`/`image` зам нь байгаа файл уу.
6. **Техник** — `python3 -I build_lNN.py` ажиллана; JSON доторх бүх `images/…`, `audio/…` зам файлтай; `lesson.json` orderIndex = N, lessonId = yct-4-lNN.

## Нэмэлт (YCT4)
- `texts.json` tokens: `zh`-д латин үсэг байж болохгүй (`python3 -I -c` шалгалт BRIEF §5-д).
- Quiz-ийн зөв хариу бүгд 0-р индекс дээр байж болохгүй (апп холидоггүй).
- Монгол хэллэг: «үзэсгэлэнтэй→гоё», «хөлт хорхой→үслэг хорхой» гэх мэт хүүхдийн энгийн үг; 饺子=банш, 包子=бууз, 面条=гоймон.
- 9–11 настай хүүхэд: YCT1–3-ийн үгсийг мэднэ гэж үзнэ, тайлбар арай урт байж болно, гэхдээ дүрмийн нэр томьёо хэвээр хориотой.
- Тестийн Listening-ийн сонголт зураггүй текст (A/B/C) бол `optionTexts` талбар + question_zh-д текст — зөв эсэхийг л шалга.
