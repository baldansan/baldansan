# YCT 6 — Тестийн сонсголын скрипт + албан хариу (ном х.131–137; scripts/ls-1..7.png)

✓ = 对, ✗ = 错. Албан хариуны хуудсанд хичээл бүр: Listening 1–5 (L2, L3, L4, L5, L9 дээр 1–6), Reading 1–5, Writing 1–5. "/" = хүлээн зөвшөөрөх хоёр дахь хувилбар. Скриптийн 男/女 = эр/эм хоолой, 问 = асуулт.
(ls-8, ls-9 = YCT 奖状 / Award гэрчилгээ, хариу биш.) Warm-up-ийн хариу эдгээр хуудсанд байхгүй.

## Lesson 1 — Listening: 1✓ 2✗ 3✓ 4✓ 5✗ · Reading: 1A 2B 3C 4B 5C · Writing: (өгүүлбэр, доор)
1. 男：这个冰激凌又好吃又便宜。 女：是吗？我也尝尝。
2. 女：她们都戴着一样的眼镜。 男：因为她们是姐妹。
3. 女：你手里拿着什么？ 男：给明明的礼物。
4. 男：你为什么喜欢狗？ 女：因为狗又可爱又勇敢。
5. 女：她是你姐姐吗？ 男：是的，她快初中毕业了。
