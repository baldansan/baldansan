# Texts (богино эх) модулийг холбох — 1 л засвар

Шинээр 2 файл нэмлээ:

```
components/lesson/modules/TextsModule.tsx      ← гол код
components/lesson/modules/texts-module.css     ← загвар (bs- угтвартай)
```

> **Энэ удаад `types/lesson.ts`-г өөрчлөх ХЭРЭГГҮЙ** — `ShortText` төрөл
> (`id, audio?, zh, pinyin, mn`) аль хэдийн байгаа.

---

## `LessonPlayer.tsx` — модулийг бүртгэх

Дээд талд import нэмнэ:

```ts
import TextsModule from "./modules/TextsModule";
```

`renderModule()` доторх `switch`-д `texts` тохиолдлыг нэмнэ:

```ts
case "texts":
  return <TextsModule lesson={lesson} onDone={next} />;
```

Болоо. `modules_enabled`-д `"texts"` байвал тэр байрандаа автоматаар гарч ирнэ.

---

## Хэрхэн ажилладаг вэ

- **Эх + аудио.** Хятад эхийг том, уншихад тухтай мөр зайтай харуулна. `text.audio`
  байвал тэр файлыг, байхгүй бол хөтчийн хятад хоолойг (TTS) бүх эхээр уншуулна.
- **Хурд 0.5× / 0.75× / 1×** — dialogues-тэй ижил (файлд шууд, TTS-д дараагийн
  тоглуулалтаас).
- **Орчуулга нуугдмал.** Эхэндээ зөвхөн хятад + пиньинь харагдана. Сурагч эхлээд
  өөрөө уншиж оролдоод, дараа нь **"Орчуулга харах"** дарж шалгана.
- **Пиньинь асаах/унтраах** — сорьж үзэхэд тохиромжтой.
- **Олон эх** — Өмнөх/Дараагийнх-аар шилжинэ. Шилжих бүрд орчуулга дахин нуугдана.
  Сүүлийн эх дуусахад дараагийн модуль руу (`onDone`).
