# Open Resources Catalog — "Бөөндөө Сурцгаая" (Chinese for Mongolian learners)

Compiled 2026-09-26. Stack: Next.js + Supabase. Already in use: makemeahanzi, hanzi-writer-data, krmanik/HSK-3.0, CC-CEDICT.
Audience: adults HSK1–6 and 6-year-olds (YCT level).

## How to read this catalog

- **License column**: exact license as found in the LICENSE/README/terms page (verified on 2026-09-26 unless marked "unverified").
- ✅ = reusable in a commercial/freemium app (with attribution / share-alike where stated).
- ⚠️ = NonCommercial (NC), NoDerivatives (ND), no license file, unclear provenance, or copyrighted. Treat as **link-out / reference only** unless you get permission.
- **SA (ShareAlike)** propagates to *data derived from it* (e.g. our Mongolian translations of CC-CEDICT glosses must be published CC BY-SA). It does **not** infect app code. Keep SA data in separate files with attribution.
- **NC** is incompatible with any paid tier, ads, or the Buunduu Cargo commercial context — assume NC = not allowed.
- **ND** forbids translation and simplified-character conversion — useless for a Mongolian-language app except verbatim display.
- **Effort**: low = download + import script (< 1 day); med = parsing/cleanup/UI (days); high = ML/hosting/large editorial work (weeks).
- Legal background (China): Copyright Law Art. 5 excludes laws, regulations and official documents of state organs (e.g. 《通用规范汉字表》, curriculum-standard appendices) from protection. Classical texts (唐诗, 三字经, 韩非子 …) are public domain everywhere; *modern annotations, translations, recordings and textbook editions of them are not*.

## Resources to AVOID (summary)

Chinese Grammar Wiki (NC), MUSE (NC), ARASAAC (NC), F5-TTS weights (NC), Free ST / MAGICDATA (NC-ND), TED-based OPUS corpora (NC-ND), OpenSubtitles (copyright), Tatoeba cmn audio (5,741 of 5,825 recordings not licensed offsite), Taiwan MOE dictionaries (ND + no simplification), Jun Da lists (commercial use needs permission), edge-tts in production (ToS unclear), Piper huayan (dataset license unknown), hitokoto (AGPL + copyrighted quotes), repos without LICENSE files (story-collection, zispace/hanzi-chars — re-key from official source instead), CTI sample papers & YCT lists (copyright CTI), 统编版 textbooks (人教社 copyright).

## Integration notes

1. **Attribution page**: extend `/help` credits with a data-sources table (StoryWeaver, Global Storybooks, Tatoeba, Wiktionary, audio-cmn, OpenMoji/Twemoji/Fluent, FLORES+, NTREX, LibriVox, CC-CEDICT…). CC BY/BY-SA require: author, title/source link, license link, "changes made".
2. **Keep SA data separate**: `public/data/sa/…` for CC BY-SA-derived JSON (our Mongolian glosses of Wiktionary/CC-CEDICT/zhongdex), published under CC BY-SA 4.0.
3. **Pipeline for classical texts**: chinese-poetry JSON → OpenCC (t2s) → pinyin-pro (+ phrase-pinyin-data for 多音字) → teacher check → LibriVox/CosyVoice audio.
4. **Audio strategy**: human audio where licensed (audio-cmn words/syllables, Global Storybooks pages, LibriVox poems); self-hosted CosyVoice/Kokoro for everything else; retire edge-tts for published content.
5. **zh↔mn gap**: there is no open Chinese–Mongolian dictionary of useful size. Best path = pivot via English senses (CC-CEDICT/Wiktionary) + Claude translation + teacher review, then evaluate translation quality on FLORES+/NTREX zh–mn pairs.
