# Common rules for ingesting open resources into the app repo

Repo: /home/claude/repo (Next.js). Put app-ready data under `content/open/<source-slug>/` with:
- `data.json` (or several JSON files) — compact, UTF-8, simplified Chinese, fields documented in `README.md`.
- `README.md` — source URL, exact license (copy the license name + link; for CC BY / CC BY-SA include the required attribution line), what was fetched, date, counts, how the JSON was produced (script path), and any caveats (e.g. Traditional→Simplified conversion done with OpenCC, pinyin generated by pypinyin — needs teacher check of 多音字).
- Scripts under `scripts/open/<source-slug>.py` (or .mjs) that regenerate the JSON from the raw download so it's reproducible.
- Keep repo growth small: total new files per source < 25 MB. Large media (mp3, images) → download into `/home/claude/open-media/<source-slug>/` (NOT the repo) and commit only a `manifest.json` with URLs + local relative paths + sizes; images/audio that are small and essential (e.g. one cover per book ≤ 40 KB) may go under `public/open/<source-slug>/`.
- Every text item should carry: `id`, `zh` (simplified), `pinyin` (word-spaced, tone marks; generate with pypinyin `Style.TONE` per character/word — `pip install pypinyin opencc-python-reimplemented --break-system-packages`), optional `en`, `level` (estimate 1–6 HSK where meaningful using data/hsk_words.json: level = the highest HSK level among content words, or "kids"/"classic"), `source` (name), `license`, `attribution`.
- Do NOT invent content, translations or explanations. Mongolian translation is a later step (leave `mn` absent).
- Only permissively licensed / public-domain content (CC0, CC BY, CC BY-SA, MIT, Apache, public domain). Skip NC/ND/unclear.
- Network: plain HTTPS (curl/python requests, git clone --depth 1) works from this sandbox. Respect rate limits (sleep 0.3s between API calls); Wikimedia needs a User-Agent header.
- At the end run `python3 -c "import json,glob; [json.load(open(f)) for f in glob.glob('content/open/**/*.json', recursive=True)]"` from the repo root to validate, and report: per source counts, sizes, any items skipped and why. Do not git commit.
