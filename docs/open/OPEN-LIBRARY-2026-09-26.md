## 5. Анхаарах / багш шалгах зүйлс

1. **Пиньинь** — chinese-poetry, Wiktionary-ийн зарим (`pinyin_check` тэмдэгтэй, ⚠ гэж харагдана), Tatoeba-ийн 16,492 «auto» өгүүлбэр — pypinyin-ээр үүссэн, 多音字 багш шалгана. Tatoeba-ийн 3,508 «reviewed» нь найдвартай.
2. **HSK түвшин** — Zhongdex-ийн HSK 3.0 жагсаалт манай `data/hsk_words.json`-той нийтлэг үгсийн **41%-д зөрж байна** (`content/open/zhongdex/compare-hsk_words.json`). Манай жагсаалтыг дахин шалгах хэрэгтэй.
3. **Монгол орчуулга** — санаатайгаар нэмээгүй (`mn` талбар байхгүй). Багшийн хяналттай дараагийн шат. Зөвхөн Tatoeba-ийн 21 + NTREX-ийн 1,997 (мэдээний хэл, хүнд) хятад–монгол хос байна.
4. **CC BY-SA** дата (Wiktionary, zhongdex, audio-cmn, NTREX)-аас үүсмэл орчуулга мөн CC BY-SA-гаар нээлттэй байх ёстой — тусдаа файлд хадгална.
5. **Зураг/дуу upstream-аас** — globalstorybooks.net, raw.githubusercontent.com, storage.googleapis.com (StoryWeaver). Хэрэв эдгээр сайт унавал ном зураггүй болно → удахгүй өөрийн storage-д хуулах.
6. Аюулгүй байдал: татах скриптийн нэг нь User-Agent-д таны имэйлийг оруулсан байсныг арилгаж, түүхийг цэвэрлэж push хийсэн (commit 9c868cd, 86eb487). Одоо `https://baldansan.vercel.app` гэж танилцуулна.

## 6. Дараа юу хийх вэ (санал, дарааллаар)

1. Тогтуунд зориулж **Global Storybooks L1 (5 ном, дуутай)** + 三字经-ийн эхний 20 мөр → «хүүхдийн зам»-ын эхний долоо хоног.
2. Багшаар: 三字经/弟子规 пиньинь, 成语 HSK1–3 (≈650) пиньинь шалгуулах → дараа нь монгол тайлбар.
3. Жишээ өгүүлбэрийг хичээлийн үгэнд холбох (үг → «энэ үгтэй өгүүлбэр» товч; zhongdex-ийн `words` талбараар шууд боломжтой).
4. LibriVox аудиог сонгодог хуудсанд тоглуулагч болгох.
5. Зураг/дууг Supabase Storage руу зөөх (`manifest.json` бэлэн).
