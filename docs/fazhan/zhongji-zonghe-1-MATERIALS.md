## Эх сурвалж бүр юу өгдөг

1. **Сурах бичиг** (OCR, чанар дунд — пиньинь алдаатай, ханз заримдаа): 题解 → 课文 (эх
   бичвэр, 2–4 догол мөр) → 词语学习 (生词 ~40 үг: ханз / пиньинь / үгийн төрөл / англи) →
   专名 → 注释 → 语言点 (4–6 дүрэм, бүтэц + жишээ + 练一练) → 综合练习 (一…七: 词语填空,
   语素 词语, 完成句子, 整理成句子, 课文理解 хүснэгт, 回答问题, 写一写). Хичээл бүрийн
   титул хуудас OCR-д хоосон (зураг).
2. **Хариулт** (参考答案, pdftotext, чанар сайн): 综合练习-ийн бүх хаалттай даалгаврын зөв
   хариулт хичээл бүрээр. Нээлттэй (回答问题/写一写) — 略.
3. **教案** (pymupdf, чанар сайн — OCR хэрэггүй): 3 次课 × 90 мин-ийн ЗААХ АЛХАМ минутаар:
   作者简介/题解 → 词语学习 (认读, 易读错词语, 猜词 填空 ppt) → 导入课文 (асуултууд +
   参考答案) → 处理课文 (догол мөр бүрээр асуулт/хариулт, 语言点-ийг курсын дунд тайлбарлах
   дараалал, ppt дугаар) → 语言点 练习 → 复述课文 загвар → 综合练习 → 布置作业. Энэ бол
   «Тэмээ багшийн» ярианы ЭХ — Монгол хичээлийн бүтцийг үүнээс авна.
4. **课件 PPT** (python-pptx): 教案-ийн ppt(N) дугаар = энэ файлын слайд. Агуулга: 作者简介,
   用本课的词语填空 (үгийн дасгал), 语言点 бүрийн 4–5 жишээ өгүүлбэр, 比较 (度过/渡过 г.м.
   ойролцоо үгийн ялгаа), 模仿课文说一说 загвар, 复述 загвар, соёлын зургийн слайд
   (牡丹花, 北京西山, 蝉 — зөвхөн гарчиг үлдсэн).
5. **mp3** (албан ёсны, Windows PC `发展汉语mp3（口语听力综合）\综合（全套）\中级综合1mp3\`):
   `NN 第K课 生词.mp3` (үгийн уншлага) + `NN 第K课 课文.mp3` (эх бичвэр). Repo-д ОРООГҮЙ
   (нийт ~290 МБ) — хичээл угсрахдаа `device_stage_files`-ээр татаж аппын audio/-д.

## Хичээл угсрахад ашиглах дараалал (fazhan-zhongji1-lNN)
`FAZHAN-LESSON-STANDARD.md` схемээр: vocabulary ← сурах бичгийн 词语学习 (англи gloss + 课文-тэй
тулгаж орчуулна) + PPT 填空 → жишээ; texts ← 课文 + 教案-ийн догол мөрийн асуулт (reflection) +
PPT 复述/模仿 загвар (writingSample); grammar ← 语言点 (бүтэц) + PPT жишээ (examples) + 练一练 →
exercises (choice) + 教案-ийн тайлбар (teacher_mn); workbook ← 综合练习 + 参考答案 (answer) +
explanation_mn; quiz ← бүгдээс; audio ← mp3.
