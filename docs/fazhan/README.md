## Хэрхэн ашиглах

- Хичээл олох: файл дотор `## 第N课` гарчгаар хайна.
- Хуудас бүр `<!-- p.NNN -->` тэмдэгтэй (PDF хуудас; хэвлэсэн хуудасны дугаартай
  тохирохгүй — offset тооцоогүй).
- **Сурах бичиг** (`textbooks/`): хичээл бүр том өнгөт дугаар + гарчгийн зурагтай
  хуудсаар эхэлдэг (OCR энэ зурган дугаарыг уншиж чаддаггүй тул **дараалан
  дугаарласан** — 1-ээс эхэлнэ). Хичээлийн эхлэлийг ном бүрт өөр тэмдгээр таньсан
  (`_ocr/assemble.py`, хэд хэдэн аргаас хүлээгдсэн тоонд хамгийн ойрыг сонгодог):
  - chuji-zonghe-1: хичээл бүр "第一部分 **Part One**" (фонетик) гэж эхэлдэг — 29/30
    (нэг хичээлийн эхлэл PDF х. 204–231-ийн хооронд OCR-д алга, тэр мужид 2 хичээл
    нэг `## 第17课` дор орсон).
  - chuji-zonghe-2: "题解 **Introduction**" — 25/25.
  - zhongji/gaoji: англи хадмалгүй, цэвэр хятад. Хуудасны толгойд ээлжлэн
    **хичээлийн нэр** (тэгш х.) / "中级综合 Intermediate Comprehensive Course" (сондгой
    х.) давтагддаг → хичээлийн нэрийн мөр өөрчлөгдөх газар = шинэ хичээл. Нүүр/
    хавсралтын хуудсыг `_ocr/overrides.json`-ийн `exclude_starts`-аар хассан.
  Хичээл дотор chuji: 语音练习 → 课文一/二/三 (生词, 课文) → 综合注释 → 补充词语 →
  课堂活动 → 综合练习; zhongji/gaoji: 题解/课文 → 词语学习 → 语言点 → 综合练习.
- **Хариултын ном** (`workbook/*-answers.md`): хичээл бүр **хятад тоогоор**
  ("第一课", "第二课"…) дугаарлагдсан; нэг хуудсанд 3–5 хичээлийн хариулт нягт
  байрладаг тул `## 第N课` гарчиг хуудасны ӨМНӨ тавигдсан — тухайн хуудсан дээрх
  "第N课" мөрийг дотроос нь ол. 5 ном PDF-ийн өөрийн текст давхаргаас (`pdftotext`)
  гаргасан — ханз, пиньинийн хөг зөв. zhongji-zonghe-2-answers л скан тул OCR, 4
  хичээлийн гарчиг алдагдсан (агуулга нь байгаа, хуудсаараа ойролцоох хичээлээс ол).

## Чанарын анхааруулга

- **Сурах бичгийн хичээлийн дугаарлалт автомат.** Хичээлийн тоо хүлээгдсэнтэй
  таарч байгаа ч эхлэх хуудас 1–2 хуудсаар зөрж болно (гарчгийн зурагтай хуудас
  OCR-д хоосон гардаг тул дараагийн текст хуудсыг эхлэл гэж авсан байж болно).
  **Аппад оруулахын өмнө `## 第N课`-ийн агуулгыг номтой тулгаж шалгах.**
- **Пиньиний хөгийн тэмдэг OCR-д маш их алдаатай** (`hǎo` → `hao`, бүр "UR UF" мэт)
  — ханзаас дахин гарга. Ханз ч алдаатай (жиш: 你是哪国人 → 你是哪国信).
- Зурагтай хэсэг (алгаар зурсан тоо, хүний зураг) текст болохгүй — санамсаргүй
  тэмдэгт үлдсэн байж болно. 生词 хүснэгтийн баганууд хольж уншигдсан байж болно.
- PDF маш том scan (2014×2732 pt) тул 220 dpi дээр ч жижиг текст тод биш —
  `docs/hsk-source/`-ийн номуудаас илүү их алдаатай гэж тооц.
- Гарчгийн/нүүрийн хуудсууд (ном бүрийн эхний 10–20 х.: 说明, 目录, 人物介绍 г.м.)
  1-р хичээлийн өмнө гарчиггүй орсон.

## Дахин үүсгэх / үргэлжлүүлэх

`_ocr/ocr.py` (PDF → `pages/<book>/pNNN.txt`, дараалал `_ocr/queue.txt`: мөр бүр
`<pdf>\t<book>`) → `_ocr/assemble.py <book>` (pages → `books/<book>.md` +
`.index.json`, дараа нь гараар `textbooks/`/`workbook/`-руу хуулна). Текст
давхаргатай PDF бол OCR-гүй `pdftotext -f N -l N` хуудас бүрчлэн ижил бүтцэд
бичнэ (`assemble.py` дахь `NATIVE_TEXT`). `_ocr/overrides.json`: `starts` (бүх
эхлэлийг гараар), `extra_starts`/`exclude_starts`, `first_lesson`.

Тооцоо: контейнер 2 CPU, tesseract ~11–15 с/хуудас (2 worker) → ном бүр 45–75 мин,
6 ном нийт ~5.5 цаг. Контейнерт `/mnt/user-data/uploads/…` руу
`device_stage_files`-ээр PDF татна (нийт ~420 МБ).

PDF-үүд эх: хэрэглэгчийн Windows PC
`C:\Users\PC\Desktop\Surtsgaay app\Ebooks\Hyatad hel\fazhanhanyu\发展汉语教学PPT课件成人留学生长期对外汉语教学教案第二版资料\`:
- `发展汉语34本\` — сурах бичиг (综合 + бусад ур чадварын ном, нийт 34).
- `发展汉语答案 （口语阅读综合）\综合（全套）\` — 综合-ийн 参考答案 (6 файл).
- `教案（30本）\综合（全套6本）\` — 教案, хичээл тус бүр тусдаа файл (доор).
- Мөн `PPT （29本）\`, `发展汉语mp3（口语听力综合）\`, `试题（赠送）\` — хараахан үзээгүй.

## Хамрагдаагүй (дараагийн чатад үргэлжлүүлэх)

- **教案 (багшийн төлөвлөгөө) бүгд хийгдээгүй.** 6 ном × 15–30 хичээл = 115 файл,
  формат холимог:
  - `.pdf` (75 файл): 初级综合1 (30), 初级综合2 (25), 中级综合1 (15), 高级综合1-ийн
    L1, L12–15 (5). Embedded custom font (TT4/Adobe-GB1) тул `pdftotext` ханзыг
    алддаг (зөвхөн пиньинь, тоо гарна) — OCR хэрэгтэй, гэхдээ файл бүр жижиг (A4,
    ~7 х.) тул хурдан (~3 с/х., нийт ~30 мин).
  - `.doc` (30 файл: 中级综合2 бүгд, 高级综合2 бүгд) → `soffice --headless --convert-to
    docx` → `pandoc -t plain` (туршсан, хятад текст зөв гарна; `soffice --convert-to
    txt` шууд хийвэл "???" болдог).
  - `.docx` (10 файл: 高级综合1-ийн L2–11) → `pandoc -t plain` шууд (туршсан, OK).
  Гаралтын санал: `teacher/<book>/lNN.md` (хичээл бүр тусдаа файл — эх нь тийм).
- Сурах бичгүүдийн бусад ур чадварын ном (口语/听力/阅读/读写/写作), PPT, mp3, 试题.
- zhongji-zonghe-2-answers-ийн дутуу 4 хичээлийн гарчиг (overrides-оор гараар).
- Хэвлэсэн хуудасны offset (`docs/hsk-source` шиг) тооцоогүй.
