## Хэрхэн ашиглах

- Хичээл олох: файл дотор `## 第N课` гарчгаар хайна.
- Хуудас бүр `<!-- p.NNN -->` тэмдэгтэй (PDF хуудас, эх номын хэвлэсэн хуудастай
  тохирохгүй байж болно — энэ номын PDF-д хэвлэсэн хуудасны дугаар бага зэрэг
  өөр байршилтай, offset тооцоогүй).
- **Сурах бичиг** (`textbooks/`): хичээл бүр том өнгөт дугаар + гарчгийн зурагтай
  хуудсаар эхэлдэг (OCR энэ зурган дугаарыг уншиж чаддаггүй тул **дараалан
  дугаарласан** — 1-ээс эхэлнэ). Танилт:
  - 初级 (chuji-zonghe-1/2): эхний дэд хэсэг **"语音练习 Phonetic Exercises"**.
  - 中级/高级 (zhongji-, gaoji-zonghe-1/2): эхний дэд хэсэг **"题解"** эсвэл
    **"词语学习"**.
  Хичээл дотор "生词/New Words", "课文/Text", "综合注释/Comprehensive Notes",
  "补充词语/Supplementary Vocabulary" дэд хэсгүүд дараалан ордог.
- **Хариултын ном** (`workbook/*-answers.md`): хичээл бүр **хятад тоогоор**
  ("第一课", "第二课"…) шууд дугаарлагдсан тул найдвартай илрүүлсэн — гэхдээ
  нэг хуудсанд 4–5 хичээлийн хариулт нягт байрладаг тул OCR заримдаа хичээлийн
  дугаарыг алгасдаг (жиш: 16, 24, 25 зарим номонд дутуу) — `.index.json`-ийн
  `expected_lessons`-тэй тулгаж шалга.

## Чанарын анхааруулга

- **Хичээлийн дугаарлалт 100% биш.** Сурах бичгийн дугаар бол OCR-гүй том
  зурган дугаараас гарсан дараалал (automatic, overrides.json-оор засварлана);
  хариултын номонд OCR заримдаа хичээлийн толгойг алгасна (дээрх тайлбар).
  **Эдгээрийг аппад оруулахын өмнө `## 第N课`-ийн агуулгыг номтой тулгаж шалгах
  шаардлагатай.**
- **Пиньиний хөгийн тэмдэг OCR-д маш их алдаатай** (`hǎo` → `hao`/эсвэл бүр
  "UR UF" мэт бүрэн алдаатай уншигдана) — ханзаас дахин гарга.
- Зурагтай хэсэг (алгаар зурсан тоо дохио, хэрэглэгчийн зураг) текст болохгүй —
  санамсаргүй тэмдэгт үлдсэн байж болно.
- Хүснэгт баганууд (生词 жагсаалт) хольж уншигдсан байж болно.
- PDF-ийн хуудасны физик хэмжээ (2014×2732pt, маш том scan) тул 220dpi дээр ч
  зарим жижиг текст тод биш — `docs/hsk-source/`-ийн номуудаас илүү их алдаатай
  гэж тооц.

## Дахин үүсгэх / үргэлжлүүлэх

`_ocr/ocr.py` (PDF → pages/*.txt, дараалал `_ocr/queue.txt`) →
`_ocr/assemble.py <book>` (pages → books/*.md + index.json, дараа нь гараар
`textbooks/`/`workbook/`-руу хуулна). `_ocr/overrides.json`-оор `starts`
(гараар бүх дугаарыг зааж өгөх), `extra_starts`/`exclude_starts` (нэг-нэг
дугаар нэмэх/хасах), `first_lesson` засварлана.

PDF-үүд эх: хэрэглэгчийн Windows PC
`C:\Users\PC\Desktop\Surtsgaay app\Ebooks\Hyatad hel\fazhanhanyu\发展汉语教学PPT课件成人留学生长期对外汉语教学教案第二版资料\`
дотор:
- `发展汉语34本\` — сурах бичиг (综合 + бусад ур чадварын ном, нийт 34).
- `发展汉语答案 （口语阅读综合）\综合（全套）\` — 综合-ийн 参考答案 (6 файл).
- `教案（30本）\综合（全套6本）\` — 教案 (багшийн төлөвлөгөө), хичээл тус бүр
  тусдаа файл. Формат холимог: `.pdf` (зарим TT4 фонт embedding-тэй, pdftotext
  ажиллахгүй — OCR хэрэгтэй), `.doc`/`.docx` (жинхэнэ Word файл — **OCR
  ХЭРЭГГҮЙ**, pandoc/antiword-аар шууд текст гаргаж болно, хамгийн нарийвчлалтай).

## Хамрагдаагүй (дараагийн чатад үргэлжлүүлэх)

- **教案 (багшийн төлөвлөгөө) бүгд хийгдээгүй.** 6 түвшин × 15–30 хичээл, формат
  холимог (pdf/doc/docx) тул тус тусдаа боловсруулалт хэрэгтэй:
  - `.doc`/`.docx` файлууд (中级综合2, 高级综合1-ийн заримд, 高级综合2 бүгд) —
    pandoc/LibreOffice-оор шууд текст рүү хөрвүүлнэ (OCR хэрэггүй, хурдан).
  - `.pdf` файлууд (初级综合1/2, 中级综合1, 高级综合1-ийн заримд) — embedded
    custom font (TT4/Adobe-GB1) тул pdftotext ажиллахгүй, OCR хэрэгтэй боловч
    файл тус бүр жижиг (7 хуудас, A4) тул хурдан (~3с/хуудас).
- Хэрвээ OCR энэ чатад бүрэн дуусаагүй бол — доорх төлөв хэсгийг үз (энэ
  README-г commit хийх үеийн төлөв).
