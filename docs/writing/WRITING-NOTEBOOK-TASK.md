## Why
Every learner gets handwriting homework from their class/teacher (e.g. 15 characters × 5 times). They want to enter those characters into the app and practice exactly like a school notebook: 👀 watch stroke order → ✍️ trace ×N → 🧠 write from memory ×N, with progress, and the characters they got wrong come back via the existing writing SRS.

## 2. Lookup API
`app/api/writing/lookup/route.ts` POST `{ text }` → parse: split on whitespace/punctuation/newlines into tokens; each token of Han chars: if the whole token is an hsk_words entry use it as a word; else greedy longest-match segmentation against hsk_words (max 4 chars) to find words; every Han char becomes an item `{ ch, word (the word it came from, if any), pinyin (char pinyin from gloss; for chars inside a known word, take the word's syllable at that position by splitting the word's pinyin on spaces when syllable count == char count), meaning_mn (word meaning if in a word, else char gloss) }`; dedupe chars preserving first order; return `{ items, unknown: [] }`. Read `data/hsk_words.json` with fs (cache) — add `"/api/writing/**": ["./data/hsk_words.json", "./public/data/hsk_char_gloss.json"]` to `outputFileTracingIncludes` in `next.config.ts` (append to the existing object; do not remove other entries).
`app/api/writing/lesson-words/route.ts` GET `?lessonId=` → `{ items }` built from the lesson's vocabulary through the same lookup logic.
