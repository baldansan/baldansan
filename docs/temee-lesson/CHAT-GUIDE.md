# Тэмээ багшийн хичээл — зэрэг ажиллах чатын заавар

Чи «Бөөндөө Сурцгаая» (Тэмээ багш) аппын нэг номын хичээлүүдийг **багшгүй хүн ойлгохоор** болгож байна.
Эзэн (Baldansan) унтаж байгаа, 10 цагийн дараа харна. **Асуулт асуухгүй, зогсохгүй.** Эргэлзсэн зүйлээ өөрөө шийдээд тайландаа бич.

## 0. Эхлэхээс өмнө
1. Repo `baldansan/baldansan`-г push эрхтэй холбож clone хий. `git push --dry-run origin main` амжилтгүй бол **ЗОГС** —
   «repo-г push эрхтэй холбож дахин нээ» гэж нэг мөр бичээд дуусга. Patch, zip өгөхгүй.
2. Унш (энэ дарааллаар):
   - `docs/temee-lesson/STANDARD.md` — дүрэм, файлын бүтэц, дуу, зураг.
   - `content/temee-lessons/fazhan-chuji1-l01.json` — загвар хичээл (эзэн баталсан). Өнгө аяс, дэлгэцийн урт, шалгалтын хэлбэрийг эндээс ав.
   - `types/temee-lesson.ts` — талбарууд. `docs/baldan/BALDAN-CHARACTER.md` — Балдангийн ярианы өнгө.
   - Skill: `buunduu-dev`, `hsk-lesson` (орчуулгын чанар).
3. `npm ci` (шалгалт, build-д хэрэгтэй). Playwright: `pip install playwright --break-system-packages && playwright install chromium`.

## 1. Хичээл бүрд (нэг нэгээр, дуусгаад дараагийнх)
**А. Шалга.** Live хичээлийг унш: `https://surtsgaay.buunduu.mn/lessons/<lessonId>/watch` (HTML дотор өгөгдөл нь бий) эсвэл repo-ийн эх:
`content/fazhan-packages/<id>/` (+ `_build/source.md`), `content/xinhsk1-packages/<id>/`, `content/hsk-source/hsk1/`, `content/hsk4-packages/` гэх мэт.
Одоогийн дасгал, сорилын асуулт бүрийг «хаана заагдсан бэ» гэж тулга. Номд байгаа ч аппд дутууг тэмдэглэ.

**Б. Зохио.** `content/temee-lessons/<lessonId>.json`, заавал `"status": "draft"`.
- `teach`: хичээлийн гол зүйл бүрийг (шинэ хэллэг, дүрмийн цэг бүр, авиа, хэрэглээ) дэлгэц дэлгэцээр. Нэг дэлгэцэд нэг санаа, Балдангийн 2–4 богино өгүүлбэр.
  Заах дараалал: юу гэсэн үг → яаж хэлэх → яагаад ингэж хэлдэг/монголоос юугаараа өөр → хэзээ, хэнд хэлэх → жижиг шалгалт.
- `replacesGrammar: true` тавьсан бол хуучин «Дүрэм» үеийн **бүх** цэг шинэ дэлгэцүүдэд орсон байх ёстой. Нэгийг ч орхихгүй.
- `practice` 6–10, `quiz` 12–20 — зөвхөн заасан зүйлээр, асуулт бүр `taught`-тай. Номын дасгалыг суурь болго; зураг шаарддаг бол нөхцөл байдлыг `scene`-д бич.
- Анхан шатны номд (初级 I, HSK1, xinhsk1) хичээлийн шинэ авиаг `sounds` үед тусад нь заа (номын 语音 хэсэг). Дээд түвшинд `sounds` хэрэггүй.
- `vocabKeep`: нэр томьёоны «үг»-ийг (声母, 横 гэх мэт) хасах шаардлагатай үед л. Жинхэнэ үгсийг бүгдийг үлдээ.
- Номын бичвэрийг хуулахгүй — өөрийн тайлбар, жишээ. Ханзаас утга таамаглахгүй; номын тайлбар, эх бичвэртэй тулга.
- Монгол авиатай харьцуулсан тайлбарт итгэлгүй бол бичихгүй, эсвэл тайландаа «шалгуулах» гэж тэмдэглэ.

**В. Дуу, зураг.**
- Дуу: `syl:` (үе), `word:` (үг). Хэллэг хэрэгтэй бол L1-ийнх шиг ffmpeg-ээр угсарч `public/temee-lesson/<lessonId>/`-д. AI хоолой хэрэглэхгүй.
  Хий ялгах асуултад 4-р хөгийн бичлэг. `scripts/temee-lesson/audio-bad.json`-д байгаа бичлэгийг хэрэглэхгүй.
- Зураг: хичээл бүрд **дээд тал нь 4** шинэ зураг (Higgsfield `gpt_image_2_6`, 3:2, quality medium, тус бүр 1 кредит). Өмнөх хичээлийн зургийг дахин ашигла
  (`public/temee-lesson/fazhan-chuji1-l01/img/`: students, teacher-student, class, elders, neighbor, fingers). Зурагт бичиг үсэг байхгүй. Татаж аваад өөрөө харж шалга, 960px webp болго.
  Higgsfield байхгүй, эсвэл кредит дууссан бол зураггүйгээр (Балдангийн төрх + кодоор зурдаг дүрслэл) үргэлжлүүл.

**Г. Шалга, нийтэл (ноорог хэвээр).**
```
npm run temee:check          # алдаа 0 болтол
npx tsc --noEmit
git pull --rebase origin main && git add content/temee-lessons/<lessonId>.json public/temee-lesson/<lessonId> && git commit && git -c push.negotiate=true push origin main
# ~3 минут хүлээгээд (Vercel deploy):
python3 scripts/temee-lesson/walk.py <lessonId> /tmp/shots-<lessonId> --draft
```
`walk.py` «АСУУДАЛ: байхгүй», «ERRS: байхгүй» гэж гарах ёстой. Дараа нь зургуудаас дор хаяж 8-ыг (заах дэлгэц, шалгалт, дасгал, сорил, нүүр)
өөрөө нээж хар. Муу бол засаад дахин. Ноорог хичээл сурагчид харагдахгүй тул main руу push хийхэд аюулгүй.

## 2. Хориотой
- `"status": "live"` болгохгүй — эзэн өөрөө батална.
- Өөрийн номоос бусад хичээлийн файл, тоглуулагчийн код (`components/`, `lib/`, `app/`), DB-г хөндөхгүй. SQL бичихгүй.
  Шинэ төрлийн дүрслэл хэрэгтэй санагдвал байгаа төрлөөр шийд, хүсэлтээ тайландаа бич.
- `git push --force` хэрэглэхгүй. Push татгалзвал `git pull --rebase origin main` хийгээд дахин.
- Нэг хичээлийг чанаргүй хурдан хийхээс цөөн хичээлийг сайн хий. Гарц: «танихгүй хүн багшгүйгээр ойлгох уу».

## 3. Тайлан (хичээл бүрийн дараа шинэчил)
Project doc `claude/TEMEE-<COURSE>-PROGRESS.md` (өөрийн номын нэрээр; бусад чатын баримтыг хөндөхгүй):
| Хичээл | Төлөв | Шалгах холбоос | Дэлгэц / дасгал / сорил | Шинэ зураг | Эзэн шалгах зүйл |
Холбоос: `https://surtsgaay.buunduu.mn/lessons/<lessonId>/watch?temee=1`.
Төгсгөлд: хэдэн хичээл хийсэн, хаана зогссон, зарцуулсан кредит, тоглуулагчид хэрэгтэй санагдсан өөрчлөлт, дараагийн чатын эхний мессеж.
