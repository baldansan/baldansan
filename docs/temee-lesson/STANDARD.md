# «Тэмээ багшийн хичээл» — стандарт

Зорилго: хичээл бүрийг **багшгүй хүн ойлгохоор** болгох. Ном бидэнд бий; бидний нэмэх зүйл бол номд байхгүй,
багш ангид амаар заадаг хэсэг. Загвар хичээл: `content/temee-lessons/fazhan-chuji1-l01.json` (发展汉语 初级 I, 1-р хичээл «你好»).

## 1. Гурван дүрэм (зөрчвөл нийтлэхгүй)
1. **Дасгал, сорилд гарах БҮХ зүйл өмнө нь заагдсан байна.** Асуулт бүр `taught` талбарт аль дэлгэцэд заасныг бичнэ.
   `npm run temee:check` үүнийг (мөн ханз бүр заагдсан эсэхийг) шалгана. Алдаатай бол push хийхгүй.
2. **Нэг дэлгэцэд нэг санаа.** Балдангийн үг 2–4 богино өгүүлбэр. Урт тайлбар хэрэгтэй бол хоёр дэлгэц болго.
3. **Сурагч уншиж чадахгүй ханзаар нэр томьёо хэлэхгүй.** «Хөг», «эхлэх авиа», «төгсгөх авиа», «хэвтээ зураас» гэх мэт монголоор.
   (声母, 韵母, 声调, 横 竖 撇 捺 гэж бичихгүй.)

## 2. Хичээл бүрд хийх дөрвөн алхам
1. **Шалга.** Live хичээлийг утасны хэмжээгээр эхнээс нь дуустал үз. Асуулт бүрийг «хаана заагдсан бэ» гэж тулга.
   Номын эхтэй (`content/*-packages/<lesson>/_build/source.md`, `docs/fazhan/…`) харьцуулж, номд байгаа ч аппд дутууг жагсаа.
2. **Ноорог.** Дэлгэц бүрээр текстэн ноорог (зураггүй). Ном бүрийн 1-р хичээлийн ноорогийг эзэн батална; үлдсэн нь стандартаар.
3. **Бүтээ.** JSON файл (`"status": "draft"`), дуу, зураг. Бүртгэл шаардлагагүй — файл нэрээрээ автоматаар олдоно.
   Ноорог хичээл сурагчид харагдахгүй; шалгах холбоос: `/lessons/<lessonId>/watch?temee=1`. Эзэн баталсны дараа `"live"` болгоно.
4. **Нүдээр шалга.** `npm run temee:check` → `npx tsc --noEmit` → build → Playwright-аар iPhone 13 хэмжээгээр
   дэлгэц бүрийн зургийг авч өөрөө харна (цайвар, харанхуй) → push → live дээр дахин.

## 3. «Багшийн заадаг зүйл» түвшин бүрд өөр
| Түвшин | Тэмээ багш юу заах вэ |
|---|---|
| Анхан (发展汉语 初级 I, HSK1, xinhsk1, YCT) | Авиа, хөг, амны байрлал (монгол авиатай харьцуулж), ханз яагаад ийм хэлбэртэй, хэнд/хэзээ хэлэх, яаж хариулах |
| HSK2–3 | Өгүүлбэрийн бүтэц монголоос юугаараа өөр, үгийн дараалал, түгээмэл алдаа, ойролцоо үгсийн ялгаа |
| HSK4–6, 中级/高级 | «Яагаад ингэж хэлдэг», ойролцоо үгсийн нарийн ялгаа, бичгийн/ярианы хэв, хэзээ хэрэглэхгүй, соёлын дэвсгэр |

Аль ч түвшинд: дүрмийн нэрийг биш, **хэрэглээг** заа. Жишээ → тайлбар → жижиг шалгалт.

## 4. Файлын бүтэц (`types/temee-lesson.ts`)
- `intro_mn` — 1-р үеийн 2–3 өгүүлбэр оршил. `vocabKeep` — үгийн картад үлдэх жинхэнэ үгс (нэр томьёо орохгүй).
- `teach` — «Тэмээ багшийн хичээл» үе (Шинэ үгсийн өмнө). Хэсгүүд (`parts`) → дэлгэцүүд (`screens`).
- `sounds` — нэмэлт үе (Эх бичвэрийн дараа): авианы дасгал зэрэг. Заавал биш.
- `practice` — дасгал. `quiz` — сорил (хуучин DB-ийн сорилыг орлоно). Хоёуланд `taught` заавал.
- `replacesGrammar: true` бол хуучин «Дүрэм» үе нуугдана.
- Дэлгэцийн дүрслэл (`visual.kind`): `hanzi`, `syllable`, `tone`, `tones4`, `compose`, `columns`, `dialog`, `image`,
  `pose`, `grid`, `pair`, `blend`, `strokes`, `order`. Шинэ төрөл хэрэгтэй бол `components/lesson/temee/temee-visual.tsx`-д нэм
  (зэрэг ажиллаж буй бусад чатад саад болохгүйн тулд энэ файлыг өөрчлөхөөс өмнө `git pull` хий).

## 5. Балдангийн өнгө (`docs/baldan/BALDAN-CHARACTER.md`)
Богино. Тайван. Хуурай хошигнол. Анхаарлын тэмдэг бараг үгүй. «Гайхалтай», «Мундаг» гэж хэлэхгүй.
Монгол хүний мэддэг зүйлээр тайлбарла: 2-р хөг = гайхаж «Аан?» гэх; `-ng` = «хаан» гэхэд төгсгөлд гардаг авиа.
Орчуулгын дүрэм: `hsk-lesson` skill (калька үгүй, урт өгүүлбэрийг хуваа, чангаар уншиж шалга).

## 6. Дуу
- **Нэг үе** (`syl:ma1`): хүний бичлэг, repo дотор `public/open/audio-cmn/syllables/` (1,700 орчим файл). Хөг заахад AI хоолойноос найдвартай.
- **Нэг үг** (`word:老师`): audio-cmn үгийн бичлэг (CDN, аппын бусад хэсэг мөн ашигладаг).
- **Хэллэг, яриа** (`file:x.mp3`): `public/temee-lesson/<lessonId>/`. L1-д бичлэгүүдийг ffmpeg-ээр угсарсан
  (чимээгүй хэсгийг тайрч, 60мс завсартай залгасан). Эзэн сонсоод тасалдалтай санагдвал AI хоолойгоор солино.
- Роботон (төхөөрөмжийн) уншигч хэрэглэхгүй.
- **Бичлэгийн чанар (2026-11-28-нд эзэн чихээрээ олсон алдаа):** зарим үеийн бичлэг нэртэйгээ таардаггүй — «pa1», «pao1» хийгүй,
  «ba», «bao» шиг сонсогддог. `python3 scripts/temee-lesson/audio_qc.py` нь 1,679 бичлэгийг хэмжиж сэжигтэй 110-ыг
  `scripts/temee-lesson/audio-bad.json`-д бичсэн; `npm run temee:check` тэр жагсаалтын бичлэг хэрэглэсэн хичээлийг зогсооно.
- **Хий ялгах асуулт (b–p, d–t, g–k, z–c, zh–ch, j–q)-д 4-р хөгийн бичлэг хэрэглэ** (bà/pà, dà/tà, bào/pào). 4-р хөгийн бичлэгүүд
  хэмжилтээр тогтвортой ялгардаг; 1-р хөгийнх найдваргүй.
- Дууг тоглуулагч өөрөө урьдчилан татдаг (одоогийн ба дараагийн дэлгэц) — файл жижиг (≤20KB) байх ёстой.

## 7. Зураг

- Нөхцөл байдлын зураг (хэн хэнд хэлж байгаа): Higgsfield `gpt_image_2_6`, 3:2, medium, 1 кредит.
  Хэв: хавтгай 2D, нимгэн хар бор хүрээ, хатуу сүүдэр, цайвар ягаан дэвсгэр, **зурагт бичиг үсэг огт байхгүй**.
  960px webp болгож `public/temee-lesson/<lessonId>/img/`-д хийнэ. Нэг зургийг дэлгэц, дасгал хоёуланд дахин ашигла.
- Хөгийн шугам, ханзны задаргаа, зураасны дарааллыг кодоор зурна — зураг үүсгэхгүй.
- Гар, хурууны дохио зэрэг «буруу байвал буруу заах» зургийг заавал өөрөө харж шалга.

## 8. Зэрэг ажиллах чатуудын дүрэм
- Нэг чат = нэг ном. Зөвхөн өөрийн номын `content/temee-lessons/<course>-lNN.json`, `public/temee-lesson/<lessonId>/`-г хөндөнө.
- Нийтлэг бүртгэлийн файл байхгүй. Push хийхийн өмнө `git pull --rebase origin main`.
- Тоглуулагчийн код (`components/lesson/temee/`, `lib/lesson/build-lesson-path.ts`)-ыг зөвхөн шаардлагатай үед, жижиг commit-оор.
- Хичээл бүрийн төгсгөлд `claude/TEMEE-<COURSE>-PROGRESS.md` project doc-д нэг мөр: хичээл, commit, анхаарах зүйл.
- Загвар: нэг хичээл = Sonnet чат/subagent; ном бүрийн 1-р хичээл ба эцсийн шалгалт = хамгийн чадалтай загвар.

## 9. Дээд түвшний загвар (HSK4–6, 中级/高级)
Загвар хичээл: `content/temee-lessons/hsk4-l01.json` («简单的爱情», ноорог — эзэн баталсны дараа жишиг болно).
Энэ түвшний сурагч пиньинь, хөг, энгийн өгүүлбэрээ мэднэ. Түүнд дутагддаг зүйл нь **«орчуулгыг нь мэднэ, хэрэглэж чадахгүй»**.
Тиймээс авиа, хөг, ханзны задаргаа заахгүй; `sounds` үе, `syl:` дуу хэрэглэхгүй.

### 9.1 Дүрмийн цэг бүрд дөрвөн асуулт (нэг асуулт = нэг дэлгэц)
| Асуулт | Юу бичих вэ | hsk4-l01 дэх жишээ |
|---|---|---|
| **Юу гэсэн үг вэ** | Нэг өөрийн жишээ өгүүлбэр + монгол дүйцэл. Бүтэн орчуулга биш, монгол хүний хэлдэг үг | `b1` 不仅 = «…төдийгүй»; `d1` 刚 = «дөнгөж» |
| **Яагаад ингэж хэлдэг вэ** | Үгийн дотоод логик: ханз бүр юу гэсэн үг, яагаад тэр байранд суудаг | `c1` 从 «-аас» + 来 «ирэх» = «тэртээгээс наашаа»; `b4` 不仅 ардаа байгаа зүйлээ заадаг тул эзэн өөр бол эзний өмнө |
| **Монголоос юугаараа өөр вэ** | Монгол толгойгоор бодоход гардаг алдааг нэрлэж хэл | `c3` монгол «хэзээ ч» ирээдүйд явдаг, 从来 явдаггүй (→ 永远); `e2` монгол «ч» эхний хэсэгт, хятад 也 хоёр дахь хэсэгт; `g7` 我对他印象很深 — эзэн нь эсрэгээрээ |
| **Ойролцоо үгсээс ялгаа** | Хоёр багана (`columns`), тус бүрд нэг жишээ. Ялгах **шалгуур**-ыг өг | `d4` 刚 «дөнгөж» / 刚才 «түрүүн» — монголоор орлуулж шалгана; `e3` 虽然 «болсон» / 即使 «төсөөлөл»; `g1` 适合 ардаа хүн авна / 合适 авахгүй |
| **Хэзээ хэлэхгүй вэ** | Хэллэг бүрийн сүүлийн дэлгэц. «Болохгүй» жишээг зөв хувилбартай нь зэрэгцүүл | `b6` сайн+муу хоёрыг 不仅-ээр холбохгүй; `e5` 即使…但是 гэсэн хос байхгүй; `f5` хүний ард 上 орохгүй |

Нэг хэллэгт 4–6 дэлгэц. Хуучин «Дүрэм» үеийн `common_mistakes`, `teacher_notes`-ийн цэг бүр эдгээрийн аль нэгэнд орсон байх ёстой (`replacesGrammar: true`).

### 9.2 Монгол дүйцлийг эхэлж хай
Хамгийн сайн тайлбар бол монгол хэлэнд яг адил ажилладаг хос үг олох. Олдвол дүрмийн жагсаалт цээжлүүлэх хэрэггүй болно.
- 刚 / 刚才 = «дөнгөж» / «түрүүн». «Түрүүн чи яагаад хэлээгүй юм» гэдэг, «дөнгөж хэлээгүй» гэдэггүй — хятадад яг адил.
- 本来 = «уг нь»; 正好 = «яг таарлаа»; 几乎 = «…х шахсан» (hsk4-l02, l03).
- Дүйцэл нь **худлаа найз** бол түүнийг нь тусад нь дэлгэц болго: 羡慕 ≠ монгол «атаархах» (`g2`), 正好 ≠ «зөв».
Итгэлгүй дүйцлийг бичихгүй; тайландаа «шалгуулах» гэж тэмдэглэ.

### 9.3 Үгийн нарийн ялгаа (хичээл бүрд тусдаа хэсэг)
Шинэ үгсээс 6–9-ийг сонгож тус бүрд нэг дэлгэц. Сонгох шалгуур: орчуулгыг нь мэдсэн ч буруу хэрэглэдэг үг.
- Ойролцоо хос: 适合/合适, 高兴/快乐/幸福, 适应/习惯, 符合/适合.
- Салдаг үйл үг: 开玩笑 (跟他开玩笑, 开玩笑他 биш), 交朋友.
- Олон утгатай: 最好 («хамгийн сайн» / «…сан нь дээр»), 麻烦, 紧张.
- Тогтсон хэвшил: 对…印象很深, 对…有信心, 给…留下印象.
- Эх бичвэрийн хэлц: 没红过脸 — үгчилсэн ба жинхэнэ утга.
Номын «比一比», «扩展» хэсгийг эндээ заавал оруул.

### 9.4 Өмнөх хичээлтэй холбо
Ойролцоо холбоосууд хэдэн хичээлд тарж ирдэг. Шинийг заахдаа өмнөхтэй нь нэг хүснэгтэд тавь:
即使 (l01, төсөөлөл → 也) · 尽管 (l02, болсон зүйл → 还是) · 不管 (l03, олон боломж → 都).
`npm run temee:check` өмнөх хичээлд заасан ханзыг тооцдог тул өмнөх хичээлийн жишээг дахин ашиглаж болно.

### 9.5 Бичгийн ба ярианы өнгө
HSK4-өөс бичгийн үг орж ирнэ. Үг бүрд «хаана хэлэх, хаана хэлэхгүй»-г нэг өгүүлбэрээр хэл:
不仅 (арай бичгийн) / 不但 (ярианы); 而, 与 (бичгийн — найзтайгаа ярихад хэлэхгүй); 挺…的, 俩, 咱们 (ярианы — албан бичигт хэлэхгүй).

### 9.6 Дасгал, сорил, дуу, зураг
- Жижиг шалгалт, дасгал, сорил бүгд **сонголт шаардсан** байна: «аль нь зөв бэ», «аль үг орох вэ», «энэ нөхцөлд аль нь». Утга асуусан асуулт 20%-иас хэтрэхгүй.
  Буруу сонголт нь заасан ялгаагаа шалгасан байх (刚 / 刚才, 即使 / 虽然), санамсаргүй үг биш. Хоёр сонголт хоёулаа зөв байж болох асуулт тавихгүй.
- Дасгал 10, сорил 18–20. `scene`-д нөхцөл байдлыг бич — хэн, хэзээ, болсон уу болоогүй юу (即使/虽然-г ялгахад шийдвэрлэх мэдээлэл).
- Дуу: зөвхөн түлхүүр үгийн `word:` бичлэг. Урт өгүүлбэрийг үеэр угсрахгүй (тасалдалтай сонсогдоно); эх бичвэрийн дуу «Эх бичвэр» үед бий.
  `word:` бичлэг CDN-д байгаа эсэхийг шалга (жнь 够 байхгүй).
- Зураг 3–4: жишээ өгүүлбэрийн нөхцөл байдал (хэн юу хийж байгаа), соёлын дэлгэц. Дүрмийн хүснэгтэд зураг хэрэггүй.
- Соёлын дэвсгэр: хичээлийн төгсгөлд нэг дэлгэц, номын 文化 хэсгээс. Монгол зүйр үг, ёстой дүйвэл хамт хэл.

### 9.7 Дэлгэцийн хэлбэр (тоглуулагчийн одоогийн байдлаар)
- `columns`: гарчиг (`head`) ханз бол том, `sub` жижиг; гарчиг монгол бол эсрэгээр — `sub` том гарна. Гурван багана утсан дээр 2+1 болж хугарна.
- `grid`: 5-аас дээш бол 3 багана — шошго 2–3 тэмдэгтээс урт бол хугарна (不仅…也… биш, 不仅 гэж бич).
- `dialog`: нэг жишээ өгүүлбэрт `who: "Жишээ"`. `compose`: үгийг ханзаар задлахад (从 + 来).
- Зөв хариултыг үргэлж эхний сонголтод тавихгүй — байрыг нь тараа.
