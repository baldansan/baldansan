## 2. Цээжлэхэд амар багцлалт — юу нэмэгдсэн
| Хэсэг | Юу | Файл |
|---|---|---|
| 🧬 Ханзны гэр бүл (字族) | Цээжлэх зам дээр «Сэдвээр / Ханзны гэр бүл» таб. Нэг ханз = 5–12 үгтэй багц (学 → 学生·学习·学校·同学·大学…), доод түвшний мэдэх үгсийг «Мэдэх үгс:» гэж харуулна. Түвшин бүрд: HSK1 51, HSK2 29, HSK3 91, HSK4 241, HSK5 383, HSK6 429, HSK7-9 1272 гэр бүл (том нь 12-оор хуваагдана). | `public/data/hsk_char_families.json`, `lib/hsk/word-themes.ts` (`getCharFamilyGroups`, id `fam-<ханз>-<хэсэг>`), `components/review/hanzi-memorize-client.tsx` |
| 🧩 Утга задаргаа (构词) | Үгийн карт (SRS/цээжлэх) болон хичээлийн үг дарахад: **电** цахилгаан + **话** яриа. 2–4 ханзтай үг бүрд, ханз бүрийн морфемийн утга. | `public/data/hsk_char_gloss.json` (3,088 ханз: пиньинь + богино монгол утга; 1,843 нь одоо байгаа датанаас, 1,306 Claude ноорог), `components/review/word-parts-line.tsx` |
| Сэдэвчилсэн бүлэг шинэчлэл | Шинэ 839 үгийг 22 сэдэвт хуваарилж, бүлгүүдийг 25–30 үгээр дахин хуваасан. | `public/data/hsk_word_themes.json` |

Дараагийн алхам (батлагдсан санал, дарааллаар): ↔️ хос үг (反义/近义), 🔗 хэллэг (搭配 — zhongdex өгүүлбэрээс), 🎬 мини-сцен (8–10 үг + 5 өгүүлбэр + тоглоом).
