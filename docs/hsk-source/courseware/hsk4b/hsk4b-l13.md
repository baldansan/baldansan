如广东省的人爱喝的“凉茶”，它的味道稍微有点儿苦，其实

语言点

程度副词：稍、稍微

“稍 / 稍微”，程度副词，表示程度轻、数量少或时间短。“稍”多用于书面语或较正式的场合，后面常跟单音节词语；“稍微”多用于口语，后面所接的动词或形容词如果是单音节的，通常需与“一点儿”“一些”“一下”等搭配使用。常用格式为：
● 稍 + 形容词 / 动词
● 稍微 + 形容词 + 一点儿 / 一些
● 稍微 + 有点儿 + 形容词
● 稍微 + 动词 + 一下
例如：
（1）A：王女士吗？有您的快递，麻烦您下楼签收一下。
　　B：好的，您稍等，我马上下来。
（2）你可以说得稍微慢一点儿吗？我听得不太清楚。
（3）今天的天气稍微有点儿冷，出门记得多穿一件衣服。

语言点

介词：由（引出时间、处所）

“由”，介词，用于引出动作或状态在时间、空间上的起点或经由的路径。语义与“从”“自”相近，但更强调起点、来源或路径的明确性，多用于书面语或较正式的说明性语境。常用格式为：
● 由 + 时间词 + 起 / 开始
● 由 + 处所词 + 动词（出发 / 流）
● 由 + 处所 / 范围 + 到 / 向 + 处所 / 范围
例如：
（1）由明天起，学校图书馆的开放时间会增加一个小时，方便大家考前复习。
（2）今年暑假，我们计划由上海出发，坐火车一路向西，去美丽的新疆看看。
（3） 班车由小区门口到市中心，每天早上六点开始发车，二十分钟一趟，方便大家日常
出行。

## Слайд 52

语言点

固定格式：X 也得 X，不 X 也得 X

“ X 也得 X，不 X 也得 X”，表示没有别的选择、必须这样做，强调在某种情况下，动作或行为一定要发生，没有例外。多用于说明规定、责任、必须完成的事。语气肯定、坚决。常用格式为“ X 也得 X，不 X 也得 X，（后续说明 / 结果）”。其中“X”通常为动词或动词短语。例如：

（1）吃也得吃，不吃也得吃，工作再忙，也要好好照顾身体。
（2）公司有规定，这个任务干也得干，不干也得干，你一定要认真完成。
（3）A：这药太苦了，我实在喝不下去。
　　B：想要身体快点儿好，喝也得喝，不喝也得喝。来，一口气喝完吧。
