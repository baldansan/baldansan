## Слайд 26

课文（三）

安娜向马克介绍去丽江旅行的经验

马克：这么多照片，都是你这次去丽江旅行时照的？那里的自然
            风景可真美！

安娜：是啊，小城四季的风景都很美，而且环境保护得也很好，
            因此每年都吸引着成千上万的游客去那儿旅游。

马克：这张照片上和你干杯的那个人是少数民族吗？她打扮得真漂亮。

安娜：他是我们的导游，不是少数民族。一路上她给我们讲了很多
            有趣的笑话。有一次我把存包的钥匙丢了，最后还是他帮我
            找到的。这张照片就是找到钥匙后，我们一起照的。

马克：明年我有机会也去那儿看看，到时把你的导游介绍给我吧。
            究竟哪个季节去丽江旅游比较好呢？

安娜：那儿最美的季节是春天和秋天，不过那时候人比较多。稍微
            好一点儿的时间是每年12月到第二年3月。这段时间去丽江
            的话，无论交通还是吃、住都很便宜。

## Слайд 50

语言点

小数、分数的表示法

小数：汉语用“点”来表示小数点。
读法：整数部分照常读，小数点读作“点”，小数部分按单个数字依次读出。“0”在小数点后读作“零”，末尾的“0”不读出。例如：
● 0.5 → 零点五
● 3.14 → 三点一四
● 25.08 → 二十五点零八
● 7.90 → 七点九


## Слайд 51

语言点

小数、分数的表示法

分数：用“X 分之 Y”表示。“分之”是分数符号“/”的读法，Y 是分子，X 是分母。
读法：分母 + 分之 + 分子。
例如：
● 1/2 → 二分之一
● 3/4 → 四分之三
● 2/5 → 五分之二
注意：百分数（%）是特殊的分数，读作“百分之X”。
例如：
● 50% → 百分之五十
● 100% → 百分之（一）百

## Слайд 53

语言点

固定格式：（没）有什么（好）X 的

“（没）有什么（好）X 的”，用来表示某事不值得、没必要，或者劝别人不要有某种情绪（如害怕、难过、担心）。说话人常常觉得对方“想多了”或者“反应过度了”，语气比较轻松、直接。
●“有什么好 X 的？”是反问句，但表达否定的意思，意思是“不用 X”“不值得 X”。
●“没什么好 X 的”是陈述句，直接表达看法。
例如：
（1）这里很安全，晚上一个人走也没什么好害怕的。
（2）这次没考好没关系，有什么好难过的？下次努力就好。
（3）A：我明天要去医院体检，有点儿紧张。
　　B：只是普通检查，你身体一直很好，有什么好担心的？
