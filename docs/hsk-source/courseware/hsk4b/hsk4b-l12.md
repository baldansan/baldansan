## Слайд 41

课文（五）

无论做什么事情，都要注意方法，学习尤其是这样。使用
正确的方法，我们做起事来能“事半功倍”，也就是说，能节
约时间，用较少的力气，取得更好的效果。相反，如果方法不
对，可能花五倍甚至十倍的时间都不能完成任务，结果变成“
事倍功半”。有一点需要提醒大家，别人的方法也许很有效，
但是并不一定适合自己。因此，我们应该在听取别人意见的同
事，仔细考虑一下，再根据不同的情况选择不同的方法，这样
才能达到最好的效果。

## Слайд 48

语言点

“把”字句 2：主语 + 把 + 宾语 + 动词 + 动量补语 / 时量补语

“主语 + 把 + 宾语 + 动词 + 动量补语 / 时量补语”，用于强调对人或事物进行处置，并说明动作的次数（动量补语）或时间长短（时量补语），突出动作的结果与状态。动量补语表示动作进行的次数（如：一遍、两次、一下），时量补语表示动作持续的时间（如：一会儿、两个小时、三天）。例如：
（1）妈妈把旅行计划推迟了三天。
（2）老师，请您把这个词语解释一下，我不太明白。
（3）A：下个星期就期末考试了，你复习得怎么样？
　　B：差不多了，这几天再把重点内容看两遍就行了。

## Слайд 50

语言点

数词 + 形容词 + 量词

“数词 + 形容词 + 量词”，用于描述事物的数量和其外部性状特征（如大小、长短、厚薄、粗细等）。这个结构强调的不仅是“有多少”，更是“它们是什么样的”。形容词通常是单音节的，用来描述后面量词或名词的形状、尺寸等属性。常用格式为“数词 + 形容词 + 量词 +（名词）”。例如：

（1）今天天气特别热，他一回到家就一口气喝了一大杯冰水。
（2）妈妈给我买了一长条巧克力，要求我每天只能吃一小块。
（3）A：新买的衣服很容易掉色，有什么好办法吗？
　　B：在洗衣服的水里加一小勺盐，这样洗出来的衣服就不容易掉色。

## Слайд 52

语言点

固定格式：X 是 X，Y 是 Y

“ X 是 X，Y 是 Y”，用来对比、区分两种相关但不相同的人或事物。表示 X 和 Y 虽然有关系，但本质不一样、界限清楚，不能混在一起看待。常用来讲道理、劝说别人、表达立场，后面可以补充说明理
由或观点。常用格式为“X 是 X，Y 是 Y，（后续说明/评论）”。例如：
（1）过去是过去，现在是现在，我们不能总用以前的眼光看他。
（2） 知道是知道，做到是做到。你看了那么多健身视频，如果不真的去运动，还是没什么效果。
（3）A：咱们是好朋友，有事好商量，不用算得那么清楚。
　　B：朋友是朋友，生意是生意，还是把事情都说明白，为了以后少些麻烦。
