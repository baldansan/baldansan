## Слайд 32

课文（四）

不仅社会上的人与人之间有竞争，森林里的各种植物
之间也有竞争，这一点儿也不奇怪。植物会为了阳光、空
气和水而竞争。一些高大的植物往往能获得更多的阳光、
空气和水，而剩下的一些比较低矮的植物就只能长在这些
高大植物的下面。由于气候条件不同，世界各地植物叶子
的样子也很不相同。在暖和、水分比较多的地方，叶子往
往长得又大又厚；在阳光特别厉害、水分少的地方，叶子
就会长得又细又长。

## Слайд 48

语言点

可能补语：动词 + 得 / 不 + 了 (liǎo)

“动词 + 得 / 不 + 了”，表示主客观条件是否允许实现某个结果或完成某个动作，强调实现动作的可能性本身，而不是动作的意愿或能力。其否定形式“动词 + 不了”比“不能 + 动词”在口语中更常见。
● 肯定形式：动词 + 得了（表示能够完成、可以实现、来得及）
● 否定形式：动词 + 不了（表示不能完成、无法实现、来不及）
● 疑问形式：动词 + 得了吗？ / 动词 + 得了 + 动词 + 不了？
例如：
（1）抱歉，明天的同学聚会我去不了了，刚接到通知，得去外地出差。
（2）别人帮得了你一时，帮不了你一世，遇到困难要想办法自己解决。
（3）A：这些西红柿很新鲜，咱们顺便买几斤吧，女儿爱吃。
　　B：今天买的东西太多了，你拿得了吗？

## Слайд 50

兼语句：主语 + 收 / 选 + 宾语 1+ 做 / 当 / 为 + 宾语 2

“主语 + 收 / 选 + 宾语 1+ 做 / 当 / 为 + 宾语 2”，表称谓或认定义的兼语句，用来表示选择、推举、接收、认定某人或某物担任某种身份、角色或称号。前一动词的宾语，同时充当后一成分的主语，动作带有确定身份的意义。常用格式为“主语 + 选 / 收 / 认 + 人 / 物 + 做 / 当 / 为 + 身份 / 角色”。例如：

## Слайд 52

语言点

固定格式：让 / 叫你 X 你就 X

“让 / 叫你 X 你就 X”是口语中常用的固定格式，表示听从要求、服从安排、按照指示行动，语气直接、有礼貌，多用于长辈对晚辈、上级对下级、老师对学生或公共场合遵守规则的场景，强调“照着做就可以”。常用格式为“让 / 叫你 + 动词 + 你就 + 动词”。例如：
（1）大家都支持你，让你当班长你就当吧，好好为班级服务。
（2）医生让你休息你就好好休息，别总想着工作，身体健康才是最重要的。
（3）A：奶奶，这个红包我真的不能要。
　　B：孩子，叫你拿着你就拿着，这是奶奶的一点儿心意，别不好意思。
