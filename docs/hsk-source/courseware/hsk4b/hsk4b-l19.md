## Слайд 28

课文（三）

安娜帮助马克练习舞蹈动作

            清楚。

马克：刚才我在旁边看到你条中国舞了，没看出来你跳得这么好！
            难道你以前在你们国家就学过中国舞蹈吗？

安娜：我小时候妈妈叫我跳过两年的舞，所以稍微有点儿基础。再
            说，舞蹈不仅是一门艺术，也是一种“语言”，这种语言与
            国籍无关，无论哪个国家的人都能看懂。

马克：太好了！我刚学习跳这种舞没多久，我帮你看看，我的这个
            动作对不对。

安娜：你这个动作做得还是不太标准，我给你跳一遍。你仔细看着
            ，应该像我这样：先抬胳膊，然后抬腿，最后头再向右转一

“……X 是 X，就是 / 不过……”，转折复句，表示“虽然 X 确实是这样，但是有另一个问题 / 情况”。前一分句先承认、肯定事实 X，后一分句用“就是 / 不过”引出转折、不足或不同情况。整体语气比“虽
然……但是……”更口语化。例如：
（1）这份工作工资高是高，就是经常要加班，太累了。
（2）A：你不觉得这家饭馆儿的菜价格太贵吗？
　　B：贵是贵了点儿，不过菜的味道确实不错。
（3）A：听说你搬家了？我觉得你原来的房子挺好的呀。
　　B：好是好，就是离公司太远，上下班不方便。

## Слайд 51

语言点

用“前后”表示概数

“前后”，用于表示时间概数，指在某个特定时间点（如节日、日期、钟点）稍早或稍晚的一段时间，相当于“左右”，但只用于时点，不用于时段、年龄或数量。常用格式为“时间点 + 前后”。例如：
（1）春节前后，很多中国人都会回家和家人一起过年，机票也会贵一些。
（2）公司要求我们下周一前后交这个月的工作报告，你最好提前做好准备。
（3）A：你一般晚上几点睡觉？太晚睡对身体不好。
　　  B： 我习惯 11 点前后休息，不过要是第二天有考试或者工作没做完，可能会晚一点儿，但一般不会超过 12 点。

## Слайд 53

语言点

固定格式：X 就 X（点儿）吧

“X 就 X（点儿）吧”是口语里常用的让步句式，用来表达勉强容忍、妥协的态度。指说话人不太满意、不太情愿，但只能接受眼前的情况。常用格式为“动词 + 就 + 动词 + 吧”“形容词 +（点儿）+ 就 + 形容词+（点儿）+ 吧”。例如：
（1）A：打车比坐公交车贵不少，要不我们再等等公交？
　　B：贵就贵点儿吧，上班都快迟到了，别再浪费时间了。
（2）A：现在路上堵车堵得厉害，我估计要比平时晚一个小时才能到家。
　　B：晚点儿就晚点儿吧，不用着急，路上慢点儿开，注意安全。
（3）A：经理突然说今晚要加班把这个表格做完，可我本来约了朋友吃饭。
　　B：计划赶不上变化。加班就加班吧，跟朋友解释一下，改天再约。
