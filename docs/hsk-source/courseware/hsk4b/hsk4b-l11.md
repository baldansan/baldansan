## Слайд 39

课文（五）

“读书好（hǎo），读好（hǎo）书，好（hào）读书”
。虽然这句话只用了三个相同的汉字，但是不同的顺序表示了
不同的意思。首先，“读书好”说的是读书有很多好处；其次
，每个人的时间都是有限的，不可能把世界上每一本书都读完
，所以要读好的书；最后，“好读书”就是要养成阅读的习惯
，使读书真正成为自己的兴趣爱好。阅读有许多好处，它能丰
富你的知识，让你找到解决问题的办法；同时，它还会丰富你
的情感，是你的生活更精彩。所以，让阅读成为你的习惯吧！

## Слайд 45

语言点

假设复句：要是……，（就）……，否则……

“要是……，（就）……，否则……”用于提出假设，前半句用“要是”引出假设情况，中间用“就”说明在这种情况下会出现的结果，后半句用“否则”引出如果不这样做，会出现的相反结果。常用格式为“要是 + 情况，（就）+ 结果，否则 + 相反结果”。例如：

（1）要是怕堵车，就得坐地铁，否则上班会迟到。
（2）要是不会游泳，就别直接跳下水，否则不仅帮不了别人，自己也会有危险。
（3）A：我总觉得自己口语说得不流利，该怎么办呢？
　  　B：要是多开口练习口语，就会越来越好，否则很难说得流利。

“数词 + 来 + 量词”，表示概数，用来估计大概的数量，指比前面的数词稍微多一点儿、接近这个数目。多用于十、百等整数后面，口语中常用。常用格式为“数词 + 来 + 量词 + 名词”。例如：

（1）他身高一米七五左右，体重一百三十来斤，看起来很健康。
（2）我爸妈结婚二十来年了，每天晚上还一起散步、聊天儿，感情一直很
          好。
（3）A：早来一会儿就好了，那辆车刚走，咱们只能等下一辆了。
　　  B：没关系，用不了多久，估计十来分钟就会来的。

## Слайд 49

语言点

固定格式：在……方面

“在……方面”是介词结构，用于指出讨论的范围、领域、内容，说明在某件事、某个领域、某种情况里怎么样。中间插入名词、动词或小句，整体结构一般在句中做状语。例如：

（1） 如果你在法律方面有什么问题，我可以给你介绍一位律师，他会给你一些专业性的
意见。
（2） 成功的语言学习者，在学习态度方面往往都是积极主动的，他们愿意主动和别人交流练
习，并且请别人帮助他们改错。
（3）A：你有没有张教授的微信？我想问问他在语法学习方面有什么好建议。
　　B：有，我这就把他的微信推给你，你直接跟他联系就行。
