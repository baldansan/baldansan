王静和孙月讨论表扬孩子的方法

　　　，每次打针都哭得特别厉害。

　　　，女儿听了以后马上就不哭了。

## Слайд 33

课文（四）

有的孩子在得不到自己想要的东西的时候，会通过哭、
扔东西或者故意敲打来引起父母的注意。在这种情况下，
建议父母先不要生气，应该停下手中的事情，陪孩子整理
整理东西，和他们聊聊天儿，弄清楚他们的问题。父母的
关心，可以让孩子心情愉快起来。教育孩子应该选择合适
的教育方法，最好不要为了解决问题而骗孩子，这是因为
儿童缺少判断能力，看到父母骗人，他们也会学着说假话。

## Слайд 41

课文（五）

七岁左右的儿童普遍好动，坐不住，所以老师在教这个
年龄段的孩子时，一定要想办法引起他们的兴趣。只有让他
们觉得你教的内容有趣，他们才会愿意努力学习。当孩子不
明白是，应该多鼓励他，不要用“懒”“笨”“粗心”这种
词批评他，这样对他们的正常发展不好。而且，对不同性格
的孩子要使用不同的教育方法。如果孩子比较骄傲，应该让
他明白还有很多知识需要学习；要是孩子性格有些害羞，就
要经常鼓励他说出自己的看法，这样才能让每一个孩子都健
康地发展。

## Слайд 48

语言点

被动句：主语 + 叫 / 让 + 宾语 + 动词 + 其他成分

“主语 + 叫 / 让 + 宾语 + 动词 + 其他成分”是汉语中表示被动的常用句式，句义和“被”字句基本相同，但多用于口语，且通常表示不如意、不希望发生的事情。“叫”和“让”在这个句式里是介词，引出
动作的发出者（施事）。例如：
（1）桌子上的那盒巧克力叫儿子一个人吃光了。
（2）我的笔记本让同桌不小心拿走了，暂时没法儿记笔记。
（3）A：你怎么这么着急？找什么呢？
　　B：我公司的门卡可能叫我弄丢了，没有它我明天就进不去办公室了。

## Слайд 50

语言点

紧缩复句：无标记

紧缩复句是一种结构紧凑的句式，它将两个在意义上有条件、假设、因果、连贯等关系的分句压缩在一起，中间没有语音停顿，也不用“如果……就……”“因为……所以……”等关联词语连接，但分句间的逻辑关系依然存在。多用于口语，表达简洁明了。理解句子含义时，需要结合语境与生活常识，判断内在逻辑。常用格式为“主语 1+ 动词 1/ 形容词 1 +（就 / 也） + 主语 2+ 动词 2/ 形容词 2”，主语常承前省略。例如：

（1）你有事你先走。（如果你有事，你就先走。）
（2）你不怕我怕。（虽然你不害怕，但是我觉得害怕。）
（3）有问题尽管问我。（无论你有什么问题，都可以问我。）

## Слайд 52

语言点

固定格式：还 X 呢

“还 X 呢”，口语句式，用于反驳、讽刺或表达不满。意思是对方实际的言行与他 / 她提到的身份、能力或状态（X）不相符，甚至相反。说话者用这个句式来指出这种矛盾，带有强烈的调侃或批评意味。
例如：
（1）A：从明天起，我每天早起跑步！
　　B：又来了，还每天呢，能坚持三天就算你厉害。
（2）A：我们组长也太粗心了，会议资料都没准备好。
　　B：还说别人呢，你上次做的会议文件，里面好几页都是空的。
（3）A：我这个月肯定能减肥成功。
　　B：还减肥成功呢，冰箱里的蛋糕昨天都让你吃完了。
