## Слайд 16

李老师和高老师在聊电脑和互联网技术的发展

李老师：现在的大学生一遇到不明白的问题，可以马上在网上查找

                多了。

高老师：现在的人们，尤其是大学生开始普遍使用电脑，他们的生
                活已经离不开电脑。据调查，70%的人遇到问题是，首先
                想到的就是上网找答案。

李老师：电脑和互联网技术的发展使学生们的学习方式发生了很多
                变化，不过天天对着电脑看，眼睛实在受不了。

高老师：不仅是学习方式，而且连生活方式也发生了很大改变。现
                在越来越多的学生喜欢在网上写日记，他们说现在可以让
                朋友及时了解自己的生活。

李老师：这个办法不错，既能方便大家的交流，还能节约用纸，保     
                护环境。但是如果别人都能看到我的日记的话，多不安全
                啊！

高老师：放心吧，可以给网上的日记加密码，那样只有得到了允许
                ，别人才能看到。

## Слайд 26

王静和孙月再聊关于梦的情况

王静：我昨天晚上做了一个特别奇怪的梦，梦到自己正在一座桥上
            走，走着走着，突然开过来一辆车，非常危险，接着又梦见
            我跳到车上，跟警察一起抓住了一个坏人。

孙月：奇怪，你怎么总能记住自己做了什么梦？我好像从来没做过   
            梦。

            得梦里的事情，有的人却记不清楚了。你之所以觉得从来没
            做过梦，只不过是忘记了。

孙月：你说的有道理，我一般都是一觉睡到天亮。很多人认为做梦
            是上天要告诉他们将来会发生的一些事情，可能上天不想让
            我知道吧。

            商店买矿泉水。

现代人的生活已经越来越离不开手机了。

## Слайд 48

语言点

介词：将

“将”，介词，用于引出受事（动作的对象），其作用是把宾语提前，强调对人或事物的处置、安排或影响。词义和用法同“把”，但语气更正式，在书面语中更常用。常用格式为“主语 + 将 + 受事宾语 + 动词 + 其他成分（结果 / 处所）”。例如：
（1）会议结束后，请将您的意见和建议写在这张纸上。
（2）保护环境可以从小事做起，例如少用塑料袋，将垃圾丢进垃圾桶。
（3）以前人们将茶当作药物，后来随着对茶的了解不断加深，才将茶当作健康的饮料。

## Слайд 50

语言点

时间副词：将、将要

“将 / 将要”，时间副词，用于表示动作或情况在不久的将来会发生，相当于“快要”“就要”。主要用于书面语或正式场合（如新闻、通知、计划），在口语中更常用“要……了”或“快……了”来表达。常用格式为“主语 + 将 + 动词（+ 宾语）”。例如：
（1）只要在本店购买家具，无论价格高低、距离远近，我们都将免费为您送货上门。
（2） 受冷空气影响，我市明天将出现大风降温，部分地区有中到大雨，出行交通会受影响，请大
家注意安全。
（3） 对每一个将要离开大学校园的人来说，大家的心情都很复杂。首先，他们很兴奋，因为
将要开始全新的生活；其次，会因为要离开熟悉的老师和同学而难过。

## Слайд 52

语言点

固定格式：说什么 / 怎么（着）也得 X

“说什么 / 怎么（着）也得 X”是口语中常用的固定格式，表示无论如何、不管怎样都必须做某事。多用于劝说、承诺、表态、人情往来等场景。常用格式为“说什么也得 + 动词”“怎么（着）也得 + 动词”。
例如：
（1）你帮了我这么大的忙，今天这顿饭说什么也得我请。
（2）明天是孩子比赛的日子，我怎么着也得请假去现场给他加油。
（3）A：你最近加班这么累，要不今晚的聚会就别去了？
　　B：不行，老同学从国外回来，说什么也得去见一面。
