## Слайд 34

课文（四）

塑料袋给人们的生活带来方便，受到人们的普遍欢迎，
可是，它的大量使用也带来了严重的环境污染问题。于是，
一些国家规定，超市、商场不能为顾客提供免费塑料袋，
并且鼓励大家购买可以多次使用的购物袋，或者购物时
自备购物袋，甚至拒绝使用塑料袋。虽然这是一件很小的
事，但这样做可以减少塑料袋的使用数量，对环境保护有
很大的作用。

## Слайд 47

语言点

兼语句：主语 + 表扬 / 批评 + 宾语 1+ 动词 + 宾语 2

“主语 + 表扬 / 批评 + 宾语 1+ 动词 + 宾语 2”，用于评价他人的言行举止。句中的宾语 1 兼具双重语法身份：既是主语“表扬 / 批评”的支配对象，也是后面动作的发出者。后半部分“动词 + 宾语 2”，用来具体说明被评价人值得表扬或受到批评的行为。常用格式为“主语 + 表扬 / 批评 + 人 / 物 + 做某事”。例如：
（1）老师表扬班长帮助同学。（老师表扬班长，班长帮助同学。）
（2）爸爸批评我大声说话打扰别人。（爸爸批评我，我打扰别人。）
（3）A：儿子，我发现你今天放学回家很高兴，是不是遇到什么好事了？
　　  B：今天老师表扬我主动打扫教室，我特别开心。（老师表扬我，我打扫教室。）

## Слайд 49

语言点

介词：自（引出时间、处所）

“自”，介词，用来引出动作、状态开始的时间或来源、出处，后面常与“起”“以来”“以后”等词搭配，或直接加表示处所的名词。意思同“从”，多用于书面语或较正式的场合。常用格式为：
● 自 + 时间词 + 起 / 以来 / 以后（时间起点）
● 自 + 处所词 + 动词、动词 + 自 + 处所词（空间起点）
例如：
（1）自明天起，超市将不再提供免费的塑料袋。
（2）自去年九月到中国以来，我的汉语水平提高得很快。
（3） 我们这种矿泉水取自雪山，不仅很好喝，用它来洗脸对皮肤也很有好处，所以价格要比
其他矿泉水贵一些。

## Слайд 51

语言点

固定格式：X 就是了

“ X 就是了”，表示不用犹豫，不用担心，就这样做就行。用于安慰、建议或说明简单可行的做法，语气轻松、委婉。常用格式为“动词 / 动词短语 + 就是了”。其中“X”通常为动词或动词短语。例如：

（1）如果想节约用电，夏天把空调温度调高两度就是了，非常简单。
（2）不想开车就别开，骑电动车出门就是了，还不会污染空气。
（3）A：我不知道应该怎么拒绝他送我的贵重礼物。
　　B：这有什么难的，你直接告诉他你的想法，谢谢他的好意就是了。
