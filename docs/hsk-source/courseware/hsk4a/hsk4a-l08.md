## Слайд 47

语言点

并列复句：一方面……，另一方面……

“一方面……，另一方面……”表示同一事物的两个并列方面、两种相关情况、两点理由或两种做法，常用于解释、说明、议论。常用格式为“主语 + 一方面 + A（小句），另一方面 + B（小句）”。例如：
（1）运动一方面可以锻炼身体，另一方面可以放松心情。
（2）举办文化节活动，一方面能让各国学生更好地了解中国，另一方面 
          也能为学生们提供互相交流和学习的机会。
（3）A：这个月空调怎么卖了这么多？差不多是上个月的两倍。
　 　 B：一方面是因为天气太热了，另一方面是我们最近推出了“以旧   
                换新”的活动，吸引了很多顾客。

## Слайд 49

语言点

双重否定句：用双重否定表示强调

双重否定，用两个否定词放在一起，表示非常肯定的意思，用来加强语气、强调事实、澄清想法、表达态度，比直接说肯定句语气更重、更明确，多用于口语和日常交际。常用格式为“不是不……”“不能没有……”“没有不……”等。
例如：
（1）人的一生可以什么也没有，但不能没有健康的身体。

## Слайд 51

语言点

固定格式：再也不 / 没……

“再也不 / 没……”，表示从过去某一时间起，一直不再做某事，强调态度坚决、情况不再重复，语气肯定、明确，多用于口语，表达决心、变化或回忆。常用格式为：
● 主语 + 再也不 + 动词 / 动词短语（表示今后不会再做，表达决心、变化）
● 主语 + 再也没 + 动词 / 动词短语（表示从过去的某个时间点开始到现在一直没做，表达回忆）
例如：
（1）上次打折我买了很多没用的东西，现在特别后悔，我以后再也不乱买东西了。
（2）大学毕业后，我离开北京，去了南方，再也没见过北方的雪。
（3）A：你怎么不去那家店买鞋了？
　　  B：上次在那家店买的皮鞋穿了一周就坏了，我再也不去那儿买鞋了。
