## Слайд 53

语言点

并列复句：不是……，而是……

“不是……，而是……”表示否定一种情况、肯定另一种情况，用于澄清事实、纠正误解、说明真相，语气明确、肯定。常用格式为“主语 + 不是 +A（动词 / 名词 / 小句），而是 +B（动词 / 名词 / 小句）”。例如：
（1）友谊不是暂时的陪伴，而是长久的互相理解。
（2）广东人爱喝的“凉茶”不是茶，而是一种用中药做成的饮料。

## Слайд 55

## Слайд 57

语言点

固定格式：一 + 量词 + 比 + 一 + 量词

“一 + 量词 + 比 + 一 + 量词”，表示同类事物依次比较，程度逐渐递增或递减，强调“越来越……”，属于递进性比较结构，常用来描述变化、趋势。常用格式为“一 + 量词 + 比 + 一 + 量词 + 形容词 / 心理
动词”。例如：

（1）我们班同学都很努力，大家一个比一个认真，成绩也越来越好。
（2）虽然现在有点儿辛苦，但我一直努力工作，希望生活一年比一年好。
（3）A：你来中国学习也有一段时间了，现在的生活和学习都还习惯吗？
　　  B：我已经慢慢适应了，而且一天比一天喜欢这里的生活。
