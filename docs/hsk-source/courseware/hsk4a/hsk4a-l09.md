语言点

让步复句：就是……，也……

“就是……，也……”表示让步关系，先承认某种假设、困难或情况，再说明结果不会因此改变，语气坚定，常用于鼓励、表态、讲道理。常用格式为“就是 + 情况 / 困难 / 假设，也 + 结果 / 做法”。例如：

（1）就是遇到再多的困难和失败，我也不会放弃自己的梦想。
（2）A：每天不吃零食、坚持运动，真的太辛苦了。
　　  B：是啊，就是再辛苦，我也会坚持减肥，我想变得更健康。
（3）A：你一个人在国外学习，肯定会遇到很多问题吧？
　　  B：当然会，就是遇到再多麻烦，我也会努力解决，不会让家人担心。

## Слайд 52

语言点

反问句 2：由疑问代词构成的反问句

用“谁、哪儿、怎么”等疑问代词构成反问句，只问不答，用疑问的语气表达明确的肯定或否定，语气比陈述句更强，常用于讲道理、劝说、鼓励，多用于口语。常用格式为“疑问代词（谁 / 哪儿 / 怎么）
+……？”。例如：

（1）他今天一句话也没说就走了。他去哪儿，我怎么会知道呢？
（2）今天的作业这么多，我还要复习明天的考试，哪儿有时间出去玩？
（3）A：你知道长城在中国的哪个城市吗？
　　B：北京啊，这么简单的问题，谁不知道？

## Слайд 54

语言点

固定格式：怎么都 / 也 + 不 / 没……

“怎么都 / 也 + 不 / 没……”，表示无论用什么方法、做多少次，结果都一样，强调“没办法、做不到、一直不”，语气坚决，多用于口语。常用格式为“怎么都不 + 动词”“怎么都没 + 动词”“怎么也不 + 动词”“怎么也没 + 动词”。例如：

（1）昨天晚上我一直在想今天的考试，心里有点儿紧张，怎么也睡不着。
（2）她为这次比赛准备了很久，花了很多时间练习，怎么都没想到自己会失败。
（3）A：这句话太难了，我怎么都说不好。
  　　B：确实不容易，你多练习几遍就会越来越好。
