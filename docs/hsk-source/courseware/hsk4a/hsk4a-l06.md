## Слайд 44

语言点

“把”字句：主语 + 把 + 宾语 + 状语 + 动词

该句式用于强调动作的方式、程度、时间，状语多为表示状态、方法的词语（如“认真地、提前、都”等），宾语是双方已知的特定事物。常用格式为“主语 + 把 + 宾语 + 状语 + 动词”。例如：

（1）旅游前把计划都提前想好，这样旅游时才会更轻松。
（2）小王，你把这些材料按照时间顺序放好，下班前交给我就行。
（3）A：咱们把床往后搬一下，这样看电视更舒服些。
　　  B：别开玩笑了，我们俩搬不动，等你爸回来再说吧。

## Слайд 46

语言点

连词：加上

“加上”，连词，表示递进关系，在已有原因、条件或情况的基础上，再补充一个原因或条件，常用来说明理由、做选择。常用格式为“……，加上……”。例如：

（1）这项工作时间很紧，加上人手不够，按时完成会非常困难。
（2）这家超市的东西很新鲜，加上价格也很便宜，附近的人都喜欢来这里买。
（3）A：这两条裤子不是一样的吗？你为什么要买两条啊？
　　  B：它穿着很舒服，加上现在有第二条半价的活动，所以我就多买了一条。

## Слайд 48

语言点

固定短语：不怎么

“不怎么”，用在动词或形容词前面，表示动作发生的次数少，或者性质、状态的程度低，意思相当于“不太”。语气委婉、客气，是口语中常用的否定表达方式。常用格式为“不怎么 + 动词 / 形容词”。
例如：

（1）他平时工作很忙，周末不怎么出门，一般都在家休息。
（2）我不打算买这件外套了，今年不怎么流行这个颜色。
（3）A：听说你感冒了，要不要我陪你去医院？
　　B：不用，我吃了药，睡了一觉，现在好多了，头也不怎么疼了。

用“不怎么”完成句子或对话

1. 我刚搬来一个星期，对周围的环境还______________。

不怎么熟悉。

2. 她平时很安静，___________________________，但很愿意帮助别人。

不怎么喜欢热闹 / 不怎么爱说话

3. A：你喜欢喝奶茶吗？很多朋友都特别喜欢喝。
     B：我_____________________________，我平时只喝白开水或者茶。

不怎么喝饮料 / 不怎么喝奶茶
