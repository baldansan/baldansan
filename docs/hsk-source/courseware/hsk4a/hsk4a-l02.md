## Слайд 56

人的一生可以什么也没有，但不能没有朋友，而且必须要有自己真正的朋友。什么是真正的朋友？不同的人会有不同的理解。有些人觉得朋友就是能和自己一起快乐的人；有些人觉得朋友应该像镜子，能帮自己看到缺点。而我的理解是：当你遇到困难的时候，真正的朋友会站出来，及时给你帮助；当你无聊或者难过的时候，真正的朋友会陪在你身边，想办法让你感到幸福。

## Слайд 63

语言点

选择复句：不是……，就是……

“不是……，就是……”表示在两种情况或事物中二者择一，没有其他可能性，常用来描述经常性、习惯性的情况，语气较肯定。常用格式为“主语 + 不是 +A（动词 / 名词 / 小句），就是 +B（动词 / 名词 /
小句）”。例如：

（1）冬天这里不是下雪，就是刮大风。
（2）在北京租房子真不容易，不是离公司太远，就是价格太贵。
（3）A：周末你一般做什么？
          B：我不是在家看书，就是出去散步。

## Слайд 65

语言点

动量词：场、顿、趟

“场”（cháng），动量词，用于计量持续一段时间、有完整发展进程的动作、现象、事态，侧重动作或事件从发生到结束的整个过程。常见搭配有“雨、雪、风、病”等。常用结构为“动词 + 数词 + 场 + 宾语”，数词为“一”时可省略。例如：
（1）她生了一场大病，在医院住了一个月才出院。
（2）早上下了场大雨，很难打到出租车。

“顿”，动量词，主要用于饮食行为，也可用于训斥、责骂等一次性、较完整的动作。常用结构为“动词 + 数词 + 顿 + 宾语”，数词为“一”时可省略。例如：
（1）周末的时候，我们一起去饭店吃了顿火锅。
（2）为了身体健康，我们每天应该按时吃三顿正餐。

“趟”，动量词，用于表示来回一次的行程，强调“去了并返回”的完整过程。常用结构为“去 / 跑 /走 / 回 + 数词 + 趟 + 处所”，数词为“一”时可省略。例如：
（1）我们去趟超市吧，明天出去玩得买点儿水果和面包。
（2）我今天出门很早，走到半路发现忘带课本了，又回了趟宿舍去拿。
