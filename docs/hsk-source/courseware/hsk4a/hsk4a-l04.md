比较句：A 不如 B（+ 形容词）

## Слайд 64

语言点

语气副词：差（一）点儿

“差一点儿”，语气副词，在句子中做状语，用来修饰动词或动词短语，表示动作或情况快要发生，但最后没有发生，可以表达庆幸、可惜、惊险等语气。“一”可以省略，意思不变。常用格式为“差（一）
点儿 + 动词 / 动词短语（迟到、忘记、说错等）”。
注意：用于否定形式时，“差（一）点儿 + 没 + 动词”表示动作或情况不容易发生，最后还是发生了。
例如：
（1）今天下午单位有重要会议，我差一点儿忘了带会议资料。
（2）今天早上路上特别堵，我下车后一路跑到单位，差点儿迟到。
（3）A：老同学，好久不见！你还记得我是谁吗？
          B：哎呀，原来是你啊！这么多年没见，我差点儿没认出来。

## Слайд 66

语言点

固定短语：有的是

“有的是”，用于强调人或事物的数量非常多，应有尽有，语气肯定、强烈，口语性强，可单独做谓语或在句中做动宾成分。常用格式为“有的是 + 名词”或者“名词 + 有的是”。例如：

（1）我们学校的图书馆有的是中文书，想学习汉语的话，一定能找到合适的书。
（2）毕业以后的工作机会有的是，只要我们认真学习，一定能找到不错的工作。
（3）A：真不好意思，我今天不能陪你去逛街了。
          B：没关系，我们以后有的是时间一起出去，你先忙你的事情吧。
