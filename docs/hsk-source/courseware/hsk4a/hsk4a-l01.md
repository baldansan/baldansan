## Слайд 59

语言点

借用名量词：脸、手、盒、屋子、桌子

借用名词“脸”做量词，表示整张脸上布满某种事物或呈现某种状态、神情。常用格式为“一 + 脸 +名词 / 形容词（多为液体、表情类）”。例如：
（1）看你这一脸汗，打球累了吧？快去洗洗脸，吃饭。
（2）她结婚以后每天都过得很快乐，总是一脸幸福的样子。

借用名词“手”做量词，表示某种手艺、技能、功夫。常用格式为“一 + 手 + 名词”。例如：
（3）妈妈做的菜太好吃了！我也希望能像她一样做一手好菜。
（4）女儿画得一手好画，参加过很多比赛，她希望长大以后能当画家。

借用名词“盒”做量词，用于计量能装在盒子里的物品，表示一盒的量。常用格式为“数词 / 指示代
词 + 盒 + 名词”。例如：
（5）我买了两盒牛奶，你要喝吗？
（6）桌子上的那盒巧克力被弟弟吃光了。


## Слайд 60

语言点

借用名量词：脸、手、盒、屋子、桌子

借用名词“屋子”做量词，用于计量屋子里的人或事物，强调数量多、充满整个屋子。常用格式为“一 + 屋子 + 名词”。例如：
（7）我生日那天，家里来了一屋子人，特别热闹。
（8）他爱看书，也爱买书，有一屋子书。

借用名词“桌子”做量词，用于计量摆在一张桌子上的东西或围桌就座的人。常用格式为“数词 +桌子 + 名词”。例如：
（9）每次放假回家，妈妈都会做一桌子好吃的菜。
（10）过年聚餐，一桌子人说说笑笑，热闹极了。

## Слайд 62

语言点

频率副词：老

“老”，频率副词，表示动作、行为屡次发生或持续不断，相当于“经常”“总是”。常用格式为“老 +动词 / 动词短语”。例如：
（1）你不要因为一点儿小事就老发脾气。
（2）哥哥很幽默，老爱跟朋友开玩笑，大家都愿意跟他一起玩。
（3）妈妈老为我结婚的事情着急，但是我觉得自己还很年轻，不想这么早结婚。
