## Хэрхэн ашиглах

- Хичээл олох: файл дотор `## 第N课` гарчгаар хайна (HSK4B 11–20, HSK5B 19–36, HSK6B 21–40 гэж дугаарласан — номынхтой ижил).
- Хуудас бүр `<!-- p.NNN · хэвлэсэн х. M -->` тэмдэгтэй — номоос шалгахад PDF/хэвлэсэн хуудсыг шууд олно.
- **Багшийн ном** (`teacher/`): HSK1–4 хичээл бүр `教学目标` (зорилго) → 教学步骤 (заах алхам, дүрмийн задлан тайлбар, нэмэлт жишээ) → `本课小结`; HSK5 багшийн ном хичээл бүр гарчгийн хуудас + 主题/语言点 хүснэгтээр эхэлж `小结与布置作业`-аар төгсдөг (дасгалын номын хариулт хавсралтгүй). Номын сүүлд `## Хавсралт · 第N课` — дасгалын номын сонсголын бичвэр, хариулт (зарим хичээлийн гарчиг OCR-д гарахгүй үлдсэн бол хуудсаараа ойролцоох хичээлээс ол).
- **Дасгалын ном** (`workbook/`): хичээл бүр гарчгийн хуудсаар (пиньинь + ханз + англи гарчиг) эхэлнэ. HSK1–2: 一、听力 Listening → 二、阅读 Reading → 三、语音 Pronunciation → 四、汉字 Characters (HSK1-ийн 1–2-р хичээл 朗读 дасгалаар эхэлдэг); HSK3: 听力 → 阅读 → 书写 (+ Review); HSK4–6: 一、听力 → 二、阅读 → 三、书写 (HSK шалгалтын хэлбэр). Хичээлийн дараа `## Хавсралт` — HSK загвар тест, шалгалтын танилцуулга (хичээлд тооцохгүй). **HSK5B-ийн PDF-д «听力文本与参考答案» товхимол наалттай** (PDF х. 161–220): `## Хавсралт · 第N课` гарчгаар хичээл бүрийн сонсголын бичвэр, хариулт (энэ хэсгийн хуудсанд хэвлэсэн дугаар тавиагүй — товхимол өөрийн дугаартай). Бусад номын сонсголын бичвэр/хариулт багшийн номын хавсралтад бий (HSK1–4).
- **`workbook/hsk1-workbook-answers.md`** — HSK1 дасгалын номын хариулт (baulchino.com, англи тайлбартай), `## 第N课` гарчгийг «Lesson N — …» мөрөөр тавьсан (L2 PDF х. 8-ын дундаас эхэлдэг). Загвар тестийн хариулт PDF х. 92-оос.
- Хичээлийн бүтэц сурах бичигт: 热身 Warm-up → 课文 Text (+ 生词 New Words) → 注释 Notes (дүрэм) → 练习 Exercises → 汉字 Characters (HSK1–3) → 运用 Application.

## Чанарын анхааруулга

- **Пиньиний хөгийн тэмдэг OCR-д алдаатай** (`hǎo` → `hao`/`hdo`). Пиньинийг ханзаас `pypinyin`-аар дахин гарга, эсвэл `hsk_words` толиос ав.
- Зурагтай хэсэг (热身-ийн зургууд, ханзны зурлага) текст болохгүй — санамсаргүй тэмдэгт үлдсэн байж болно.
- Хүснэгт (生词 New Words) нь багана хольж уншигдсан байж болно — үг бүрийг толиос баталгаажуул.
- Хичээлийн эхлэлийг автоматаар таньсан (сурах бичиг: 热身/Warm-up; багшийн ном: 教学目标/本课小结; дасгалын ном: толгойд «听力/Listening/朗读» эсвэл 1-ээс эхэлсэн «第1-5题», Pronunciation/Characters/Review дэд хэсэг ба «标准教程…练习册» гүйдэг толгойтой хуудсыг хасна, «附录/模拟试卷/HSK介绍»-оос хойш хавсралт). Зөрсөн газрыг `overrides.json`-оор гараар зассан (дасгалын номд зөвхөн `first_lesson`). Бүх ном хүлээгдсэн хичээлийн тоотой таарсан; дасгалын номын эхлэлүүдийг номын гарчгийн (目录) хуудастай тулгаж шалгасан.
