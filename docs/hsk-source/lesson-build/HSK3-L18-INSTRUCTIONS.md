**注释 — 2 дүрэм (х. 154, `L18/img/textbook_p170.png`):**
1. 只要……就…… (The Structure “只要……，就……”) — «只要……就……» нөхцөлт нийлмэл өгүүлбэрийн хоёр хэсгийг холбоно: «只要»-ийн ард зайлшгүй нөхцөл, «就»-ийн ард үр дүн. Өгүүлэгч «只要»-ийн өмнө ч, ард ч байж болно. Хоёр дахь өгүүлэгч байвал «就»-ийн ӨМНӨ тавина.
   Жишээ: (1) 只要我有时间，就一定跟你去旅游。 (2) 我只要喜欢，就一定会买。 (3) 只要你想去，我就跟你去。 (4) 只要你给我买，我就能照顾好它。 (4 = яриа 2, номд улаанаар.)
   练一练 (完成对话): (1) A: 你对大家都这么好啊？ B: 是啊！我觉得只要我对别人好，＿＿。 (2) A: 妈妈，你来跟我们一起玩儿吧。 B: 你们玩儿吧，只要你们玩儿得高兴，＿＿。 (3) A: 只要你努力学习，＿＿。 B: 老师，我一定会努力的。
   Багшийн ном (х. 118–119, `L18/img/teacher_p125.png`, `p126.png`): 导入 — 热身 2-ын хүснэгтийн үгсийг уншуулна; «教师：什么时候你会出去玩儿？ 学生：天气好的时候，我会出去玩儿。 教师引导学生说出目标句：只要天气好，我就出去玩儿。» 操练 — 热身 2-ыг ашиглан бие биенээсээ асууж хариулна. 注意: «主语可以放在"只要"前，也可以放在"只要"后，如果后边的分句有第二个主语，要放在"就"的前边。»
2. 介词“关于” (The Preposition “关于”; сурах бичгийн гарчигт «介语“关于”» гэж хэвлэсэн — доорх «Эргэлзээтэй»-г үз) — «关于»-ийн ард нэр үг ирж, ярьж буй/хамаатай зүйлийг (对象) оруулна. Багшийн номын томьёо: «关于 + 对象».
   Жишээ: (1) 我最近看了一些关于中国文化的电影。 (2) 关于这件事，我们还没有决定呢。 (3) 关于出国学习的事，妈妈已经同意了。 (4) 关于这个工作，还有什么问题吗？ (4 = яриа 3, номд улаанаар.)
   练一练 (完成句子): (1) 我想去图书馆借一些＿＿的书。 (2) 今天没有时间回答了，＿＿，我下次告诉你吧。 (3) 你去问问体育老师吧，他能告诉你一些＿＿的方法。
   Багшийн ном (х. 119, `L18/img/teacher_p126.png`): 导入 — «情景：我看了一个中国电影，这个电影是讲中国历史的。 目标句：我看了一个关于中国历史的电影。» 操练 (үгийн хэллэгээс өгүүлбэр): 这件事，我不知道——关于这件事，我不知道。/看了一本书，中国文化——我看了一本关于中国文化的书。/学习汉语，介绍方法——老师给我们介绍了一些关于学习汉语的方法。/出国的事，爸爸同意了——关于出国的事，爸爸已经同意了。 扩展 (бодит байдлаар хариулах; хариултгүй): 你喜欢看什么书？/你常常看什么电影？/你以后想做什么样的工作？

## Бичих дүрэм

- Апп-ын хэл: **монгол** (кирилл), багшийн тайлбар ярианы хэлээр, найрсаг, тодорхой. Хятад жишээ бүрт монгол орчуулга. Пиньиньд хөгийн тэмдэг ЗААВАЛ (xiàng, zhǐyào, búdàn……érqiě……, xiāngxìn, guānyú, qíguài…), OCR-ийн тэмдэггүй пиньинийг хуулж болохгүй.
- Хятад бичвэр дэх цэг таслал бүтэн өргөнтэй (，。？！：) байна.
- Юу ч ЗОХИОХГҮЙ: сурах бичиг, багшийн ном, дасгалын номд байхгүй дасгал, хариулт, баримт бичихгүй. Багшийн номын нэмэлт жишээ өгүүлбэрүүдийг ашиглаж болно. Өөрийн зохиосон нэмэлт жишээ өгүүлбэр (заах зорилгоор) зөвхөн энэ хичээл + HSK1–2 үгсийн санд багтсан үгсээр, зөв дүрэмтэй байх.
- 1-р хичээлийн текстийг ХУУЛАХГҮЙ — зөвхөн бүтцийг нь дага.
- Дүрэм 1-ийг монголоор «只要……就……: …л бол, … (зайлшгүй нөхцөл → үр дүн)» гэж нэрлэ. Нөхцөлийг «…л бол / …л юм бол / …вал л» гэж, үр дүнг «…» (就 — «тэгвэл, л») гэж орчуул: 只要我有，就一定会借给你的 → «Надад л байвал заавал зээлнэ»; 只要你给我买，我就能照顾好它 → «Чи л надад авч өгвөл би түүнийг сайн асарч чадна»; 只要我愿意，我相信他们就会同意的 → «Би л хүсвэл тэд зөвшөөрнө гэдэгт итгэж байна»; 只要经过一段时间，就会慢慢地习惯 → «Хэсэг хугацаа л өнгөрвөл аажмаар дасна». Өгүүлэгчийн байрлал: 只要我有时间 / 我只要喜欢 — хоёулаа зөв; хоёр дахь өгүүлэгч заавал 就-ийн ӨМНӨ (只要你想去，我就跟你去 — «我就», «就我» биш). Өмнө сурсан 如果……就…… («хэрэв … бол») нь ерөнхий таамаг нөхцөл, 只要……就…… нь «энэ л нөхцөл хангагдвал хангалттай» гэдгийг онцолдог — ялгааг тайлбарт товч хэлж болно.
- Дүрэм 2-ыг монголоор «关于 угтвар үг: 关于 + нэр үг (…-ийн тухай, …-тай холбоотой)» гэж нэрлэ. Хоёр байрлал: (а) тодотгол — 关于 + N + 的 + нэр үг: 一些关于中国文化的电影 → «Хятадын соёлын тухай хэдэн кино»; (б) өгүүлбэрийн эхэнд, таслалтай — 关于这件事，我们还没有决定呢 → «Энэ асуудлын тухайд бид хараахан шийдээгүй байна»; 关于这个工作，还有什么问题吗？ → «Энэ ажлын талаар өөр асуулт байна уу?». Номын гарчиг сурах бичигт «介语“关于”» гэж хэвлэгдсэн — апп-д «介词“关于”» (угтвар үг) гэж бич (доорх «Эргэлзээтэй»-г үз).
- 地 (生词 17) — «тэмдэг нэр / давхарласан тэмдэг нэр + 地 + үйл үг» — үйлдэл хэрхэн болж буйг заана: 慢慢地习惯 → «аажмаар дасах», 认真地学习 → «хичээнгүйлэн сурах», 着急地说 → «сандран хэлэх», 热情地回答 → «халуун дотноор хариулах», 奇怪地看着我 → «гайхсан янзтай над руу харах», 生气地回房间了 → «уурласаар өрөөндөө орчихов». Гурван «de»-ийн ялгааг товч дурдаж болно: 的 — нэр үгийн өмнө (我的书), 地 — үйл үгийн өмнө (慢慢地走), 得 — үйл үгийн ард (走得很慢). Уншлага бүгд «de» (хөнгөн).
- 向 → «…руу / …-аас / …-д» (утгаар): 想向你借点儿钱 → «чамаас жаахан мөнгө зээлмээр байна»; 向外看 → «гадагш харах»; 向左走 → «зүүн тийш явах»; 向她问好 → «түүнд мэнд хүргэх»; 向小丽学习 → «Сяо Лигээс суралцах (түүнээс үлгэр авах)». «…руу» гэж шууд калька хийхгүй — монгол хэлээр зөв тийн ялгалаар.
- 万 → «түм, арван мянга»: 5万块钱 → «50 000 юань» / «тавин мянган юань»; 三万块 → «30 000 юань». «5 түм» гэж үлдээж болохгүй — монгол уншигчид тоогоор ойлгомжтой бич.
- 钱下午打给你 → «Мөнгийг үдээс хойш чам руу шилжүүлье» (打 энд — мөнгө шилжүүлэх; «цохих» биш). 还差多少？ → «Хэд дутаж байна?». 买房 → «байр/орон сууц авах». 那你以后去医院就方便了 → «Тэгвэл чи цаашдаа эмнэлэг рүүгээ явахад эвтэйхэн болно» (朋友 эмнэлэгт ажилладаг — «我们医院»).
- 贵公司 → «танай компани» (эелдэг хэлбэр; «үнэтэй компани» гэж калька хийхгүй). 外地 → «өөр хот, орон нутаг»; 外地人 → «өөр газрын хүн». 上班 → «ажилдаа гарах».
- 只 (тооны нэр) — монголд тооны нэр байхгүй тул орчуулгад гээнэ: 那只狗 → «тэр нохой»; 一只小猫 → «нэг зулзага». 段 — 这段时间 → «энэ хугацаанд / сүүлийн үед»; 一段时间 → «хэсэг хугацаа». 种 — 一种文化 → «нэгэн соёл»; 这种药 → «энэ төрлийн эм»; 哪种茶 → «ямар (төрлийн) цай».
- 眼睛大大的，嘴小小的 — ТЭМДЭГ НЭРИЙН давхарлалт (AA的; L17-ын «高高的»-тай адил) → «нүд нь бүлтгэр том, ам нь жижигхэн». Энэ хичээлийн дүрэм биш — хольж тайлбарлахгүй. 买回去 / 买回家去 → «авч харих / гэртээ авч харих» (нийлмэл чиглэлийн нөхөц). 你能照顾好它吗？ → «Чи түүнийг сайн асарч чадах уу?».
- 什么都很新鲜 → «бүх юм шинэлэг» (L17-ын асуух төлөөний үгийн уян хэрэглээ 3). 人名 → «(хүний) нэр», 姓 → «овог»: 有些国家的人名写在姓前面 → «Зарим улсад нэрээ овгийнхоо өмнө бичдэг». 有点(儿)奇怪 → «жаахан хачин санагдах».
- 奇怪 → «хачин, сонин» (тэмдэг нэр) / «гайхах» (我很奇怪，他为什么不生气 → «Тэр яагаад уурлахгүй байгааг би их гайхаж байна»); 真奇怪 → «Үнэхээр хачин юм». 相信 → «итгэх»: 我相信他们会同意的 → «Тэд зөвшөөрнө гэдэгт би итгэж байна». 同意 → «зөвшөөрөх» (хүсэлтийг) / «санал нийлэх» (санааг): 我同意 → «Би санал нийлж байна».
- 不但……而且…… → «…төдийгүй бас …»: 贵公司不但很有名，而且工作环境好 → «Танай компани алдартай төдийгүй ажлын орчин нь бас сайн». Пиньинь заавал «búdàn……érqiě……» (不 → bú, 4-р аялгын өмнө).
- 小明 → «Сяо Мин»; 周明 → «Жоу Мин»; 老周 → «Лао Жоу» (нас тэнцүү найзууд овгоор нь «老+овог» гэж дотночлон дууддаг — тайлбарт хэлж болно); 经理 → «менежер»; 学生 → «оюутан» (энд ажилд орох гэж буй залуу). Дасгалын номын 小云、小丽、小刚、小周、黄老师、马可 → «Сяо Юнь», «Сяо Ли», «Сяо Ган», «Сяо Жоу», «Хуан багш», «Марко»; 《动物世界》 → «"Амьтны ертөнц"»; 大熊猫 → «аварга панда».
- 旧字新词: 动物园 → «амьтны хүрээлэн», 人名 → «хүний нэр», 自信 → «өөртөө итгэлтэй» (тэмдэг нэр). 见怪不怪 → «Хачин юманд дассан хүн гайхахаа больдог» (үгчлэн: «хачныг харсаар хачирхахаа байх»).

## Эргэлзээтэй / анхаарах зүйлс

- **Дасгалын номын хариулт бичвэртэй тохирсон** — Part 1–4, 21–50, 复习 1–2-ыг сонсголын бичвэр / уншлагын бичвэр / сурах бичгийн ярианы бичвэртэй нэг бүрчлэн тулгасан; илт хэвлэлийн алдаа ОЛДООГҮЙ (ШИЙДВЭР шаардлагагүй). Тэмдэглэл: 8 (√) — «除了春节以外，别的我都不了解» → зөвхөн 春节-ийг мэднэ; 15 (B 吃得很饱) — «吃太少，我晚上睡不着觉» гэснээс дүгнэлт; 32 (C) — A «是旅游公司的经理» одоо цаг, бичвэрт «以前我是» тул буруу; 35 (A) — бичвэрт «大家都很喜欢她».
- **生词 7 ба яриа 3-ын пиньинь «ěrqiě»** — сурах бичгийн 生词 хүснэгт (`textbook_p168.png`) ба 拼音课文-ийн яриа 3 (`textbook_p169.png`) «búdàn……ěrqiě……» / «ěrqiě» гэж хэвлэсэн (220 dpi-аар томруулж шалгасан); яриа 4-ийн 拼音课文 «érqiě». Хэвлэлийн алдаа. ШИЙДВЭР: **érqiě** (стандарт) гэж бич.
- **Яриа 4: «有点奇怪» vs «yǒudiǎnr qíguài»** — ханзад 儿 байхгүй, 拼音课文-д «yǒudiǎnr»; багшийн номын хариулт «还会有点儿奇怪». ШИЙДВЭР: ханзыг сурах бичгээр «有点», пиньинийг ханзтай тааруулж «yǒudiǎn» гэж бич (аудиогоор 儿 сонсогдвол эзэн «有点儿 / yǒudiǎnr» болгож засна — сонсож шалгаагүй).
- **Дүрэм 2-ын гарчиг «介语“关于”»** — сурах бичигт (`textbook_p170.png`, 500 dpi-аар шалгасан) «介语» гэж хэвлэсэн, англи «The Preposition “关于”»; стандарт нэр томьёо «介词». ШИЙДВЭР: апп-д «介词“关于”» гэж бич.
- **Хүйс, яриа 3** — багшийн ном 经理-г «女的», 学生-ийг «男的» гэж нэрлэсэн; сурах бичигт хүйс заагаагүй. Орчуулгад багшийн номыг дага (эсвэл хүйс тодотгохгүй). 复习 2-т 学生-ийг «他» гэж бичсэн.
- **Яриа 2, асуулт ③ «小明的妈妈同意小明的要求了吗？»** — бичвэр ээжийн эцсийн шийдвэрээр дуусаагүй; багшийн номын хариулт «不同意，她觉得小明不会照顾它» — үүнийг ашигла.
- **热身 1 D зураг** — «10000» тоог гараараа барьсан тул эхний «1» нь «7» шиг харагдана (`textbook_p167.png`, 220 dpi) — 万-ын зураг (хариулт ⑥D).
- **生词 7 «不但……而且……»** — 生词 хүснэгтэд дугаар 7 нь хоёр хэсэгтэй холбоос үг; vocabulary.json-д нэг үг болгож бич (hanzi «不但……而且……», pinyin «búdàn……érqiě……»).
- **Дасгалын номд 51–54 (用下边的汉字组词) хэсэг БАЙХГҮЙ** — нийт 50 асуулт + 复习 2 (L14-тэй адил, L17-оос ялгаатай). Энэ хичээлд 汉字知识 хэсэг ч БАЙХГҮЙ — зөвхөн 旧字新词.
- **Дасгалын ном Part 3–4** — асуулт (问) дасгалын номд хэвлээгүй, зөвхөн сонголтууд; асуултыг хавсралтын сонсголын бичвэрээс ав (дээр бичсэн).
- Багшийн номын 补充课堂活动-ийн 参考词语-д «像» орсон — энэ хичээлийн 生词 биш (номд байгаагаар; апп-д ашиглахгүй байж болно).
- Сурах бичгийн 练一练 (дүрэм 1: 3 харилцан яриа, дүрэм 2: 3 гүйцээх өгүүлбэр), 练习 2–3, 热身 2 (连线), 运用 1–2 болон багшийн номын 扩展-ийн хариулт эх сурвалжид байхгүй. 练习 2-ын хоосон зай бүрт сангаас нэг л үг тохирох боловч номд хэвлээгүй — ашиглах эсэхийг эзэн шийднэ.
- Энэ хичээлд 专有名词, 文化 хэсгүүд БАЙХГҮЙ — зохиохгүй. * тэмдэгтэй үг 1 (15 特点).
- Яриа 4-т гарчиг байхгүй (номд зөвхөн «4»). Яриа 1-ийн 前面 «qiánmian» (хөнгөн), яриа 4-ийн 前面/后面 «qiánmiàn / hòumiàn» (тэмдэгтэй) — номд байгаагаар нь.
- 朗读 (1805)-ийн сүүлийн өгүүлбэр «就会慢慢地习惯的» (的-тэй), яриа 4 «就会慢慢地习惯» (的-гүй) — тус бүрийг номоор.
- 注释 1-ийн (4) «只要你给我买，我就能照顾好它。» (яриа 2) ба 注释 2-ын (4) «关于这个工作，还有什么问题吗？» (яриа 3) — номд улаанаар.
