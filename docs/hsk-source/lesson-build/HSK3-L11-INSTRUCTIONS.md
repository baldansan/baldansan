1. “把”字句1：A把B+V+…… (The Ba-Sentence 1: A把B + V + ……) — тодорхой хүн эсвэл тодорхой юманд харгалзах үйлдэл хийж, түүнийг «шийдвэрлэх/боловсруулах»-ыг илэрхийлэхэд 把 өгүүлбэр хэрэглэнэ; бүтэц «A把B+V+……». 2. 概数的表达2：左右 (Expression of Approximate Numbers 2: 左右) — 左右 тооны ард ирж ойролцоо тоог заана: 三点左右 (гурван цагийн орчим), 五个左右 (тав орчим), 十年左右 (арав орчим жил). ## Бичих дүрэм

- Апп-ын хэл: **монгол** (кирилл), багшийн тайлбар ярианы хэлээр, найрсаг, тодорхой. Хятад жишээ бүрт монгол орчуулга. Пиньиньд хөгийн тэмдэг ЗААВАЛ (kōngtiáo, wàngjì, kuàizi…), OCR-ийн тэмдэггүй пиньинийг хуулж болохгүй.
- Хятад бичвэр дэх цэг таслал бүтэн өргөнтэй (，。？！：) байна.
- Юу ч ЗОХИОХГҮЙ: сурах бичиг, багшийн ном, дасгалын номд байхгүй дасгал, хариулт, баримт бичихгүй. Багшийн номын нэмэлт жишээ өгүүлбэрүүдийг ашиглаж болно. Өөрийн зохиосон нэмэлт жишээ өгүүлбэр (заах зорилгоор) зөвхөн энэ хичээл + HSK1–2 үгсийн санд багтсан үгсээр, зөв дүрэмтэй байх.
- 1-р хичээлийн текстийг ХУУЛАХГҮЙ — зөвхөн бүтцийг нь дага.
- Дүрэм 1-ийг монголоор «把 өгүүлбэр 1: A 把 B + V + … — тодорхой юманд үйлдэл хийхийг хүсэх, тушаах» гэж нэрлэ. 把 нь B-г (тодорхой, мэдэгдэж буй объект) үйл үгийн ӨМНӨ гаргана; монголоор B нь ихэвчлэн заах тийн ялгал (-ыг/-ийг/-г) эсвэл «…-аа/-ээ» хамаатуулах дагавартай: 你把灯关了吧 → «Гэрлээ унтраачих»; 帮我把这本词典还了吧 → «Энэ толь бичгийг минь буцааж өгчихөөч»; 别忘了把空调关了 → «Агааржуулагчаа унтраахаа бүү мартаарай»; 我把爸爸的生日忘了 → «Би аавын төрсөн өдрийг мартчихаж». Үйл үгийн ард ихэвчлэн 了 (хамгийн энгийн «бусад гишүүн») — дангаар «把灯关» гэж болохгүй гэдгийг онцол. 没/别/不能/可以 зэрэг нь 把-ийн ӨМНӨ (你别把手机忘了, 你没把书给我); 把-ийн ард биш.
- Дүрэм 2-ыг монголоор «ойролцоо тоо 2: тоо + 左右 (…орчим)» гэж нэрлэ. 左右 заавал тооны/тоо нэрийн АРД: 两点左右 → «хоёр цагийн орчимд», 五千块左右 → «таван мянга орчим юань», 五百人左右 → «таван зуу орчим хүн», 十年左右 → «арав орчим жил». «Зүүн баруун» гэж шууд орчуулахгүй.
- 还 энэ хичээлд ХОЁР дуудлагатай: 还 huán (буцааж өгөх — шинэ үг: 还书, 帮我还他) ба 还 hái (бас, одоо ч, дутуу: 还差一双筷子 «нэг хос савх дутуу байна», 还没结束). Пиньиньд андуурахгүй.
- 口 — тоо нэр «балга»: 一口酒都不能喝 → «ганц балга ч архи ууж болохгүй» (一…都不 — «ганц … ч …-гүй»). 酒 → «архи» (согтууруулах ундаа), 啤酒 → «шар айраг».
- 笔记本（电脑）→ «зөөврийн компьютер»; харин дасгалын номын 21–25 C «把你的笔记本借我看看吧» (ангид ирээгүй хүн) → «тэмдэглэлийн дэвтэр».
- 电子邮件 → «цахим шуудан» (и-мэйл).
- 关 → гэрэл/агааржуулагч/компьютер/зурагт-д «унтраах», хаалга/цонхонд «хаах».
- 借 — «зээлэх» (өөрөө авах) ба «зээлүүлэх» (бусдад өгөх) хоёулаа: 我去图书馆借本书 → «номын сангаас ном зээлнэ»; 借我用用 → «надад жаахан хэрэглүүлээч».
