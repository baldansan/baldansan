**注释 — 3 дүрэм (х. 138–139, `L16/img/textbook_p154.png`, `p155.png`):**
1. 如果……（的话），（S）就…… (The Structure “如果……（的话），（S）就……”) — «如果»-ийн араах өгүүлбэр нь ТААМАГЛАЛ, «就»-ийн араах өгүүлбэр нь тэр таамагласан нөхцөлд гарах ҮР ДҮН. **Анхаар: хоёр дахь өгүүлбэрийн эзэн (S) «就»-ийн ӨМНӨ байрлана.**
   Жишээ: (1) 如果你太累了，就休息一会儿。 (2) 如果你喜欢，我就给你买。 (3) 如果有钱的话，我就去旅游。 (4) 如果不舒服，就去医院检查一下吧。 (4 = яриа 3, номд улаанаар.)
   练一练 (完成句子): (1) 如果明天下雨的话，＿＿。 (2) 如果考试考得很好的话，＿＿。 (3) ＿＿，我就跟朋友去踢足球。
   Багшийн ном (х. 104–105) **注意:** «第二个分句如果有主语，主语要放在"就"的前边。»
2. 复杂的状态补语 (Complex Complements of State) — хятад хэлэнд «得»-ээр байдлын нөхбөр үүсгэж ямар нэг байдлыг дүрсэлнэ. «得»-ийн өмнө ихэвчлэн тэмдэг нэр эсвэл үйл үг, «得»-ийн хойно ихэвчлэн ҮЙЛ ҮГИЙН ХЭЛЛЭГ ирнэ.
   Жишээ: (1) 孩子们玩儿得不想回家。 (2) 弟弟高兴得跳了起来。 (3) 儿子累得下了班就睡觉了。 (4) 人们忙得没时间跟别人见面。 (4 = яриа 4-өөс, номд улаанаар.)
   练一练 (完成句子): (1) 我牙疼得＿＿。 (2) 今天天气热得＿＿。 (3) 看了这个电影，她笑得＿＿。
   Багшийн ном (х. 105–106): томьёо «形容词＋得＋动词词组». **注意 (х. 106):** «复杂状态补语中，"得"后边的成分是复杂的形式，而不是简单形式。"笑得很开心"是一个简单状态补语。»

   Жишээ: (1) 你送的花红红的，我很喜欢。 (2) 这些草绿绿的，真漂亮。 (3) 他鼻子小小的，长得像谁？ (4) 你女儿长得白白的、胖胖的，真可爱！ (4 = яриа 2, номд улаанаар.)

## Бичих дүрэм

- Апп-ын хэл: **монгол** (кирилл), багшийн тайлбар ярианы хэлээр, найрсаг, тодорхой. Хятад жишээ бүрт монгол орчуулга. Пиньиньд хөгийн тэмдэг ЗААВАЛ (chéngshì, rúguǒ, píxié, jiǎnchá…), OCR-ийн тэмдэггүй пиньинийг хуулж болохгүй.
- Хятад бичвэр дэх цэг таслал бүтэн өргөнтэй (，。？！：) байна.
- Юу ч ЗОХИОХГҮЙ: сурах бичиг, багшийн ном, дасгалын номд байхгүй дасгал, хариулт, баримт бичихгүй. Багшийн номын нэмэлт жишээ өгүүлбэрүүдийг ашиглаж болно. Өөрийн зохиосон нэмэлт жишээ өгүүлбэр (заах зорилгоор) зөвхөн энэ хичээл + HSK1–2 үгсийн санд багтсан үгсээр, зөв дүрэмтэй байх.
- 1-р хичээлийн текстийг ХУУЛАХГҮЙ — зөвхөн бүтцийг нь дага.
- Дүрэм 1-ийг монголоор «таамаглал ба үр дүн: 如果……（的话），（S）就…… — хэрэв …бол, …» гэж нэрлэ. 的话 заавал биш (如果有钱的话 = 如果有钱). **Хоёр дахь өгүүлбэрийн эзэн 就-гийн ӨМНӨ**: 如果你喜欢，我就给你买 (✗ 就我给你买) → «Чамд таалагдвал би авч өгье»; 如果不舒服，就去医院检查一下吧 → «Бие чинь тавгүй байвал эмнэлэгт очиж үзүүлээч»; 如果你太累了，就休息一会儿 → «Хэт ядарсан бол жаахан амар». Монголоор ихэвчлэн «…бол/…вал/…вэл» нөхцөлийн нөхцөлт үйл үгээр орчуулна.
- Дүрэм 2-ыг монголоор «нийлмэл байдлын нөхбөр: Adj/V + 得 + үйл үгийн хэллэг — …тлаа/…тэл/…сандаа» гэж нэрлэ (状态补语 = «байдлын нөхбөр»). 得-ийн араас энгийн тэмдэг нэр (笑得很开心 — энгийн) биш, бүтэн үйл үгийн хэллэг ирдэг: 我现在累得下了班就想睡觉 → «Би одоо ажлаа тараад л унтмаар санагдтал ядардаг»; 她爸爸高兴得一个晚上都没睡着 → «Аав нь баярласандаа бүтэн шөнөжин унтаж чадаагүй»; 孩子们玩儿得不想回家 → «Хүүхдүүд гэртээ харимааргүй болтлоо тоглосон»; 人们忙得没时间跟别人见面 → «Хүмүүс бусадтай уулзах ч завгүй болтлоо ажил ихтэй». Өмнө (HSK2) сурсан энгийн байдлын нөхбөртэй (跑得很快) холбож тайлбарла.
- Дүрэм 3-ыг монголоор «нэг үет тэмдэг нэрийн давхарлалт: AA的 — шинжийг тод, хүчтэй илэрхийлэх» гэж нэрлэ. Монгол хэлний эрчимжүүлэх давхарлалттай харьцуул: 白白的 → «цав цагаан», 黑黑的 → «хав хар», 红红的 → «час улаан», 绿绿的 → «нов ногоон», 小小的 → «жижигхэн», 胖胖的 → «махлаг/булцгар», 高高的 → «өндөр өндөр/гозгор», 大大的 → «том том», 冷冷的 (харилцаа) → «хүйтэн хөндий». **AA-ийн ард 的 заавал** (багшийн ном: 要加上一个"的"字，才能进入句子).
- 长 — **zhǎng** (өсөх; 长得 — төрх байдал: 长得像谁 → «хэнтэй адилхан бэ», 长大了 → «томорсон», 长高了 → «өндөр болсон») ба **cháng** (урт: 头发长长的 chángcháng de → «үс нь урт урт», 长头发 → «урт үс») — пиньинийг андуурахгүй.

- 认为 → «гэж үзэх, гэж бодох» (我认为…… → «миний бодлоор …»). 关系 → «харилцаа»; 别人 → «бусад хүн»; 词语 → «үг хэллэг».
- 趋向补语-ыг монголоор «ирэх/явах чиглэлийн нөхбөр» гэж нэрлэ (өмнөх хичээлүүдтэй нэг нэр томьёо); 来 = өгүүлэгч рүү, 去 = өгүүлэгчээс хол (энэ хичээлд: 跳了起来/跳起来, 出去玩儿, 过去看看).
- 小丽 → «Сяо Ли»; 周明 → «Жоу Мин» (дасгалын номд 周经理 → «менежер Жоу»); 小刚 → «Сяо Ган». Дасгалын номын нэрс: 常医生 → «Чан эмч», 常月 → «Чан Юэ», 乐乐 → «Лэлэ», 老高 → «Лао Гао», 高山 → «Гао Шань», 高静 → «Гао Жин», 周新 → «Жоу Шинь», 常亮 → «Чан Лян», 小白 → «Сяо Бай», 小方 → «Сяо Фан», 周秘书 → «нарийн бичгийн дарга Жоу», 白小姐 → «Бай авхай».

## Эргэлзээтэй / анхаарах зүйлс

- **Дасгалын номын 复习 1 — хэвлэлийн алдаа (дээр дэлгэрэнгүй):** номын хариулт 如果、就 нь хэвлэгдсэн өгүүлбэр («如果那时候没有钱，他就去旅游了») дотор яриа 1-ийн утгатай зөрнө. **ШИЙДВЭР: бичвэрийн утгыг дага** — өгүүлбэрийг «……那时候有钱……» гэж засаж хариулт 城市、如果、就、没时间、累得 хэвээр, тайлбарт алдааг дурд.
- **Бусад бүх хариулт (Part 1–4, 21–50, 复习 2)** сонсголын бичвэр / уншлагын бичвэр / сурах бичгийн ярианы бичвэртэй нэг бүрчлэн тулгасан — илт хэвлэлийн алдаа ОЛДООГҮЙ.
- **Сонсгол 17 (номын хариулт C «没想到男的这么瘦»)** — эмэгтэй эхлээд «请问您是？» гэж таньсангүй тул A «不认识男的» ч мэт санагдана; гэвч нэрийг нь сонсоод таньж, «瘦得我都不认识你了» гэж гайхсан — асуулт эмэгтэйн тухай, гол санаа нь «ийм туранхай болсныг санаагүй». Илт алдаа биш — **номын хариулт C-г дага**; B «变瘦了» нь эрэгтэйн тухай.
- **Сонсгол 20 (B «人很好»)** — «如果这个地方有地铁，那就更好了» нь метро БАЙХГҮЙ гэсэн утга (A буруу); «安静» гэсэн тул C буруу.
- **Сонсгол 6 (√)** — «不知道长胖一点儿没有» = тарган/туранхай болсныг мэдэхгүй → √.
- **注释 3 жишээ (3) «他鼻子小小的，长得像谁？»** — сурах бичигт «他» гэж хэвлэгдсэн (яриа 2-т «你看她鼻子小小的»). Хэвээр нь (жишээ өгүүлбэр тусдаа).
- **拼音课文 яриа 2 «Xièxiè»** — хоёр дахь үе нь тэмдэгтэй хэвлэгдсэн (ихэвчлэн xièxie); яриа 4-т «xièxie». Номд байгаагаар.
- 朗读 ④ «你去医院检查一下吧» ба яриа 3 «如果不舒服，就去医院检查一下吧» — тус бүрийг эх бичвэрээр нь. 朗读 ③ «她长得像谁？» (яриа 2: «长得像谁？»).
- Сурах бичгийн 练一练 (3 дүрэм × 3 өгүүлбэр), 练习 2–3, 热身 2, 运用 1–2 болон багшийн номын 操练/扩展-ийн хариулт эх сурвалжид байхгүй (运用 1-д зөвхөн жишээ «如果有钱，我就买一辆车。»). 练习 2-ын хоосон зай бүрт сангаас нэг л үг тохирох боловч номд хэвлээгүй — ашиглах эсэхийг эзэн шийднэ.
- 练习 3 (c) зураг — костюмтэй залуу гараараа «T» (завсарлага/зогс) дохио үзүүлж байна; харилцан ярианы хоосон зайн хариулт номд байхгүй — зохиохгүй.
- Дасгалын номд 51–54 (组词) хэсэг БАЙХГҮЙ — нийт 50 асуулт + 复习 2. Бусад хичээлээс хуулж 51–54 нэмэхгүй.
- Энэ хичээлд 专有名词, 汉字知识, 文化 хэсгүүд БАЙХГҮЙ — зохиохгүй. * тэмдэгтэй (HSK3-аас гадуурх) үг: зөвхөн 16 词语.
- Яриа 4-т гарчиг байхгүй (номд зөвхөн «4»); өгүүлэгчийн хүйс заагаагүй — орчуулгад хүйс тодотгохгүй.
- 生词 13 刷牙 «shuā yá» — номд зайтай бичсэн (салгаж хэрэглэдэг үг); хэвээр нь. 生词 7 可爱 «kě'ài» — номд апостроф (kě’ài).
- Сурах бичгийн аудио: 1602 (67 с) нь 1601-ээс бага зэрэг богино, 1603 (36 с) хамгийн богино — бичвэрийн урттай тохирно; клипүүд аль хэдийн хуваагдсан.
