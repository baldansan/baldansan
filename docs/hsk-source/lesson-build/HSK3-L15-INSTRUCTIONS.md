1. 除了……以外，都/还/也…… (The Structure “除了……以外，都/还/也……”)
   - «除了……以外，都……» (all…except…) — тодорхой хүрээнээс нэг хэсгийг ХАСААД, бусад нь бүгд ижил байдалтай гэдгийг илэрхийлнэ. «以外»-г орхиж болно.
     Жишээ: (1) 除了这个汉字以外，别的汉字我都认识。 (2) 除了我以外，大家都听懂了。 (3) 除了这个句子意思有些不清楚外，其他都没什么问题。 (4) 除了小云，其他人都来了。 (3 = яриа 1, 4 = яриа 2, номд улаанаар.)
   - «除了……以外，还/也……» (besides…) — дурдсан хэсгээс гадна БАСАА бусад зүйл байгааг НЭМЖ хэлнэ. Өгүүлэгдэхүүн өгүүлбэрийн эхэнд эсвэл «还/也»-ийн яг өмнө ирнэ.
     Жишээ: (5) 除了唱歌以外，他还喜欢跳舞。 (6) 除了汉语以外，我还会说英语。 (7) 上网除了看新闻，还可以听音乐。 (8) 除了春节、中秋节以外，啤酒节也是这里很重要的一个节日。 (8 = яриа 4, номд улаанаар.)
   练一练 (改写句子): 例如：春节很重要，中秋节也是很重要的节日。——除了春节以外，中秋节也是很重要的节日。 (1) 我喜欢春天，也喜欢夏天。 (2) 我们班只有王老师是中国人，其他人都是外国人。 (3) 我只想吃西瓜，其他水果都不想吃。
   Багшийн ном (х. 97–98) **注意:** «其中"以外"可以完全省略或省略成"外"。» (жишээ нь яриа 1-ийн «除了……不清楚外»).
2. 疑问代词活用2 (Flexible Use of Interrogative Pronouns 2) — хятад хэлэнд «什么» нь заах төлөөний үгийн үүрэг гүйцэтгэж, ТОДОРХОЙ БУС хүн, юмыг орлоно; аялга нь илүү ЭЕЛДЭГ болдог. «什么»-г хасахад өгүүлбэрийн утга өөрчлөгдөхгүй.
   Жишээ: (1) 这个饭馆有没有什么特别好吃的菜？ (2) 周末你有没有什么打算？ (3) 你写得很好，没什么问题。 (4) 以后有什么不明白的地方，可以给我打电话或者发电子邮件。 (4 = яриа 1, номд улаанаар.)
   练一练 (完成对话): (1) A: ＿＿。 B: 周末我跟朋友打算去爬山。 (2) A: ＿＿ B: 对不起，我很少看电影，不知道哪个好看。 (3) A: ＿＿ B: 没有了，老师，我都懂了。
3. 程度的表达：极了 (“极了” Used to Indicate Degree) — хамгийн өндөр зэргийг «形容词/心理动词+极了» (тэмдэг нэр / сэтгэлийн үйл үг + 极了)-аар илэрхийлнэ.
   Жишээ: (1) 我的小狗可爱极了。 (2) 今天天气冷极了。 (3) 那件衣服我喜欢极了。 (4) 他满意极了。 (4 = яриа 3, номд улаанаар.)

**文化 (х. 134, `L15/img/textbook_p150.png`):** 中国人过生日吃什么 (What Food Chinese People Eat on Their Birthdays) — «西方人过生日都要吃生日蛋糕，中国人的习俗是吃面条。面条长长的，表示"长寿"的意思。因此，生日面也叫长寿面。在你们国家，人们过生日时吃什么呢？» (Барууныхан төрсөн өдрөөрөө бялуу иддэг бол хятадууд уламжлалаар гоймон иддэг; урт гоймон «урт наслах»-ыг бэлгэддэг тул төрсөн өдрийн гоймонг «урт насны гоймон» гэдэг.) Зураг: улаан хятад хувцастай хүү савхаар аяганаас гоймон идэж байна. Багшийн ном (х. 102, `L15/img/teacher_p109.png`) 文化点解析: ① «古代中国人认为脸长寿命就长，"脸"就是"面"，因此长长的面条就表示长长的脸，寓意长寿。除了长寿面，还有寿桃等，也寓意长寿。» ② «中国人过生日的时候还有吃鸡蛋的习俗，寓意平安和健康。» Заах арга: багш урт насны гоймон, 寿桃 (урт насны тоор), өндөг идэх заншлыг танилцуулна; суралцагчид өөрийн оронд төрсөн өдрөөр юу иддэг, яагаад гэдгийг ярина.

## Бичих дүрэм

- Апп-ын хэл: **монгол** (кирилл), багшийн тайлбар ярианы хэлээр, найрсаг, тодорхой. Хятад жишээ бүрт монгол орчуулга. Пиньиньд хөгийн тэмдэг ЗААВАЛ (shuǐpíng, qítā, jiēdào…), OCR-ийн тэмдэггүй пиньинийг хуулж болохгүй.
- Хятад бичвэр дэх цэг таслал бүтэн өргөнтэй (，。？！：) байна.
- Юу ч ЗОХИОХГҮЙ: сурах бичиг, багшийн ном, дасгалын номд байхгүй дасгал, хариулт, баримт бичихгүй. Багшийн номын нэмэлт жишээ өгүүлбэрүүдийг ашиглаж болно. Өөрийн зохиосон нэмэлт жишээ өгүүлбэр (заах зорилгоор) зөвхөн энэ хичээл + HSK1–2 үгсийн санд багтсан үгсээр, зөв дүрэмтэй байх.
- 1-р хичээлийн текстийг ХУУЛАХГҮЙ — зөвхөн бүтцийг нь дага.
- Дүрэм 1-ийг монголоор «除了……以外，都/还/也…… — …-аас бусад нь бүгд / …-аас гадна бас» гэж нэрлэ. ХОЁР утгыг заавал ялга: **都 → хасах** (дурдсан хэсгийг хасаад бусад нь ижил: 除了小云，其他人都来了 → «Сяо Юниас бусад нь бүгд ирсэн»; 除了我以外，大家都听懂了 → «Надаас бусад нь бүгд ойлгосон»); **还/也 → нэмэх** (дурдсан зүйлээс гадна бас: 除了唱歌以外，他还喜欢跳舞 → «Тэр дуулахаас гадна бас бүжиглэх дуртай»; 除了春节、中秋节以外，啤酒节也是这里很重要的一个节日 → «Хаврын баяр, Сарны баяраас гадна шар айрагны баяр бас энд их чухал баяр»). «以外»-г орхиж (除了小云，…) эсвэл «外» болгож (除了这个句子意思有些不清楚外，…) болно. 还/也-тэй хэлбэрт өгүүлэгдэхүүн өгүүлбэрийн эхэнд (上网除了看新闻，还可以听音乐) эсвэл 还/也-ийн яг өмнө (除了汉语以外，我还会说英语) ирнэ.
- Дүрэм 2-ыг монголоор «асуух төлөөний үгийн өргөтгөсөн хэрэглээ 2: 什么 = "ямар нэг, ямар ч" (тодорхой бус)» гэж нэрлэ (1-ийг 8-р хичээлд «疑问代词+就+疑问代词» гэж үзсэн). Энд 什么 асуулт биш — «ямар нэг, онц» гэсэн утгатай, аялгыг зөөлрүүлнэ: 没什么问题 → «онц асуудал алга / ямар ч асуудалгүй»; 以后有什么不明白的地方 → «цаашид ойлгохгүй ямар нэг зүйл байвал»; 周末你有没有什么打算？→ «Амралтын өдөр ямар нэг төлөвлөгөө байгаа юу?». 什么-г хасахад утга өөрчлөгдөхгүй. Ийм өгүүлбэр асуулт бол «吗» эсвэл «有没有» ордог (这个饭馆儿有什么好吃的菜吗？).
- Дүрэм 3-ыг монголоор «зэргийн илэрхийлэл: тэмдэг нэр / сэтгэлийн үйл үг + 极了 (туйлын, аймаар, үнэхээр их)» гэж нэрлэ: 我的小狗可爱极了 → «Миний гөлөг үнэхээр өхөөрдөм»; 今天天气冷极了 → «Өнөөдөр аймаар хүйтэн байна»; 那件衣服我喜欢极了 → «Тэр хувцсанд би үнэхээр их дуртай»; 他满意极了 → «Тэр туйлын сэтгэл хангалуун байна». 极了 нь тэмдэг нэр/үйл үгийн АРД ирнэ, өмнө нь 很/非常 давхар орохгүй.
- 其他 ба 别的 — багшийн ном хоёрыг харьцуулж заана (其他人、其他问题 / 别的汉字); монголоор хоёулаа «бусад, өөр». 其他都没什么问题 → «Бусад нь ямар ч асуудалгүй».
- 花 (энэ хичээлд) = «зарцуулах, үрэх» (花钱 — мөнгө зарах, 花时间 — цаг зарцуулах, 这个月我的钱都花完了 → «Энэ сард мөнгөө бүгдийг нь зараад дуусгачихлаа»); «цэцэг» гэсэн 花 биш.
- 发 → «илгээх» (发电子邮件 — имэйл илгээх); 上网 → «интернэтэд орох» (上一会儿网 — хэсэг интернэтэд суух); 新闻 → «мэдээ»; 留学 → «гадаадад суралцах» (我来中国留学两年了 → «Би Хятадад сурахаар ирээд хоёр жил болж байна»); 提高得一点儿也不快 → «огт хурдан ахихгүй байна».
- 节日 → «баяр»; 春节 → «Хаврын баяр (Хятадын шинэ жил)»; 中秋节 → «Сарны баяр (Намрын дунд сарын баяр)»; 啤酒节 → «шар айрагны баяр»; 电影节 → «кино наадам»; 文化节 → «соёлын наадам»; 春节晚会 → «Хаврын баярын үдэшлэг (телевизийн)»; 歌舞 → «дуу бүжиг»; 长寿面 → «урт насны гоймон»; 寿桃 → «урт насны тоор». 一是一，二是二 → «Нэг нь нэг, хоёр нь хоёр» (байгаа байдлаар нь шударга хэлэх).
- 大山 → «Дашань»; 小云 → «Сяо Юнь»; 小刚 → «Сяо Ган»; 老师 (яриа 1, эмэгтэй) → «багш»; 同事 → «хамт ажиллагч». Дасгалын номын 马可 → «Марко», 方朋 → «Фан Пэн», 常笑 → «Чан Сяо», 笑笑 → «Сяосяо», 大明 → «Да Мин», 老方 → «Лао Фан», 周经理 → «Жоу менежер», 王美 (运用 1) → «Ван Мэй».
