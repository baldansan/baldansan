# Даалгавар: HSK хичээл N-ийн ЭХ СУРВАЛЖИЙН JSON (`L0N/source.json`)

Зорилго: номд (сурах бичиг + багшийн ном + дасгалын ном) тухайн хичээлийн талаар байгаа
**БҮХ** мэдээллийг, **номд байгаа хэлбэрээр нь** (хятад, пиньинь, англи), нэг JSON-д цуглуулах.
Энэ бол эх сурвалжийн сан — дараа нь заах арга барил, хичээл үүнээс гарна.

## Хатуу дүрэм

1. **Монгол орчуулга, тайлбар, заах санаа, зохиомол жишээ/дасгал/хариулт БИЧИХГҮЙ.** Зөвхөн ном.
2. **Юу ч орхихгүй.** 热身 бүр, 课文 бүрийн мөр бүр, 生词 бүр, 注释 бүрийн тайлбар + жишээ бүр + 练一练 бүр,
   练习 бүр (朗读 мөрүүд, 选词填空 сан + өгүүлбэр бүр, 描述图片 өгүүлбэрүүд, 回答问题 асуулт бүр), 汉字, 运用, 俗语/文化;
   багшийн номын 教学目标, 教学步骤 хэсэг бүр, 注意/辨析, 热身/课文 асуулт-хариулт, 本课小结; дасгалын номын
   听力/阅读/书写/复习 асуулт бүр (сонголт, бичвэр, хариулт).
3. **Хариулт зөвхөн номд хэвлэгдсэн бол** (`answer` + `answer_ref`). Хэвлэгдээгүй бол `answer` талбар байхгүй.
4. **OCR-д итгэхгүй — зураг бүрийг Read-ээр хар.** Пиньиний хөгийн тэмдэг, 生词 хүснэгт, хариултын хуудсыг заавал зургаар.
   Жижиг бол `pdftoppm -f P -l P -r 220 -png -singlefile <pdf> out` гээд томруул. Хятад бичвэрийн цэг таслал бүтэн өргөнтэй.
5. **Номын өөрийн алдаа/зөрүү** (пиньинь ↔ ханз зөрөх, багшийн ном ↔ сурах бичиг зөрөх, хариулт ↔ бичвэр зөрөх) —
   номд байгаагаар нь бичээд `unclear[]`-д тэмдэглэ. Засахгүй, таахгүй.
6. Бүтэц: `/home/claude/repo/types/hsk-source-lesson.ts` — `HskSourceLesson`. Талбарын нэрийг яг тэр дагуу.
   Нэмэлт мэдээлэл багтахгүй бол хамгийн ойрын талбарт `_zh` текстээр оруул, түлхүүр зохиохгүй.
