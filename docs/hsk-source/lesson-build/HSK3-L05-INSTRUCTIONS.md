**汉字 (х. 43, `L05/img/textbook_p59.png`):**
- 汉字知识 · 会意字 (Associative Compounds) — эрт үеийн хятадууд хоёр ба түүнээс дээш бие даасан (独体字) ханзыг нийлүүлж нэг ханз бүтээдэг байсан; бүрэлдэхүүн ханзуудын утгыг нэмбэл бүхэл ханзын утга гарна. Хүснэгт: 明 — 太阳和月亮在一起，光明。 (нар + сар = гэгээ, гэрэлтэй) / 休 — 人靠在树上休息。 (хүн модонд түшиж амарна) / 从 — 一个人跟着另一个人。 (нэг хүн нөгөөгийнхөө араас дагана) / 看 — 手放在眼睛上，看远方。 (гараа нүдэн дээрээ тавьж хол харах). Багшийн ном: 明 = 日+月, 休 = 人+树 («人靠在树边休息»), 从 = 人+人, 看 = 手+目; үг бүтээх жишээ: 明天、聪明 / 休息 / 从八点到十点、从中国到日本 / 看见、看电视.
- 旧字新词 (Word Game): 听 + 说 → 听说 (сонссон, …гэж дуулсан; «听别人说»); 有 + 一点儿 → 有点儿 (жаахан, бага зэрэг; «有点儿» = «有一点儿»); 草 + 地方 → 草地 (өвстэй газар, зүлэг; «比较大的有草的地方»). - Апп-ын хэл: **монгол** (кирилл), багшийн тайлбар ярианы хэлээр, найрсаг, тодорхой. Хятад жишээ бүрт монгол орчуулга. Пиньиньд хөгийн тэмдэг ЗААВАЛ (zhàogù, qúnzi, lǜ…), OCR-ийн тэмдэггүй пиньинийг хуулж болохгүй.
- Хятад бичвэр дэх цэг таслал бүтэн өргөнтэй (，。？！：) байна.
- Юу ч ЗОХИОХГҮЙ: сурах бичиг, багшийн ном, дасгалын номд байхгүй дасгал, хариулт, баримт бичихгүй. Багшийн номын нэмэлт жишээ өгүүлбэрүүдийг ашиглаж болно. Өөрийн зохиосон нэмэлт жишээ өгүүлбэр (заах зорилгоор) зөвхөн энэ хичээл + HSK1–2 үгсийн санд багтсан үгсээр, зөв дүрэмтэй байх.
- 1-р хичээлийн текстийг ХУУЛАХГҮЙ — зөвхөн бүтцийг нь дага.
- Дүрэм 1-ийг монголоор «өөрчлөлтийн 了 (өгүүлбэрийн төгсгөлийн 了)» гэж нэрлэ: өмнө нь өөр байсан, одоо өөрчлөгдсөн / шинэ нөхцөл үүссэн («…болсон», «…болж байна», «одоо …»). HSK2-ын үйл үгийн ард ирдэг гүйцэтгэлийн 了 (昨天吃了感冒药 — «уусан»)-аас ЗААВАЛ ялга; яриа 2-т хоёулаа бий: 我儿子生病了 (өөрчлөлт — «өвдчихлөө») ба 吃了感冒药 (гүйцэтгэл). 不…了 → «…хэрэггүй боллоо / больсон» (不喝茶了 — «цай уухаа больё», 不那么冷了 — «тийм хүйтэн байхаа больсон»).
- Дүрэм 2-ыг монголоор «越来越 + тэмдэг нэр / сэтгэлийн үйл үг — улам бүр …» гэж нэрлэ (цаг хугацааны явцад зэрэг нэмэгдэх/өөрчлөгдөх). 越来越-ийн ард 很、非常、太 зэрэг зэргийн дайвар үг ОРОХГҮЙ (越来越很热 ✗). 越来越 + сэтгэлийн үйл үг: 喜欢、想 г.м.
- 为 wèi (4-р аялга, «…-д зориулж») — 因为 yīnwèi, 为什么 wèi shénme-тэй холбож тайлбарлаж болно; 为 + хүн + үйл үг бүтцийг тэмдэглэ (为你买的绿茶 → «чамд зориулж авсан ногоон цай»).
- 用 энэ хичээлд «хэрэгтэй байх» (to need) — ихэвчлэн 不用 + V «…-х хэрэггүй» хэлбэрээр (不用去医院 — «эмнэлэгт очих хэрэггүй»). «Хэрэглэх» утгатай 用 (HSK3) -тэй хольж болохгүй.
- 最近-г номд adv. гэж өгсөн — «сүүлийн үед» гэж орчуул; өгүүлэгдэхүүний өмнө ч, ард ч ирж болно (我最近… / 最近天气…).

## Эргэлзээтэй / анхаарах зүйлс

- 热身 1-ийн ① 感冒-ийн хариулт номд «B/F» (хоёулаа зөв) — хоёр зургийн аль алиныг зөв гэж хүлээн авах, эсвэл B/F гэж үлдээ; ② 发烧 = B.
- 注释-д ЗӨВХӨН 2 дүрэм (L03-т 3 байсан) — 3 дахь дүрэм зохиохгүй.
- Дасгалын номд 51–54 (用下边的汉字组词) хэсэг бий — нийт 54 асуулт (L01-ийн адил); 51–54-ийн хариулт 参考答案 (өөр зөв хувилбар байж болно).
- 汉字知识-ийн 休 тайлбар: сурах бичиг «人靠在树上休息», багшийн ном «人靠在树边休息» — сурах бичгийнхийг ашигла.
- Яриа 3 ба 4 хоёулаа «在小刚家 / At Xiaogang's home» гарчигтай — номд байгаагаар нь үлдээ (texts.json-д давхардал гэж засахгүй).
- Сурах бичгийн 练习 2–4, 练一练, 运用-ийн хариулт эх сурвалжид байхгүй — зохиохгүй (练习 4-т багшийн номын 课文 асуулт-хариултыг ашиглаж болно).
- Дасгалын номын 32-т «越来越不爱运动» — 越来越 + 不 + сэтгэлийн үйл үг хэлбэр; номд тусгай дүрэм байхгүй тул нэмэлт дүрэм болгож бичихгүй, зөвхөн бичвэр хэвээр.
- Сонсголын 20-ийн «能不胖吗？» — L02-ын эсрэг асуулт (能…吗) — «Таргалахгүй яах вэ дээ?» гэж орчуул.
