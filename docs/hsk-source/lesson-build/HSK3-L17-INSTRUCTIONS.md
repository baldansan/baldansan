Орчуулга: 谁都喜欢小丽 → «Сяо Лид хүн бүр дуртай»; 小刚什么都喜欢吃 → «Сяо Ган юуг ч идэх дуртай»; 我们怎么去公园都可以 → «Цэцэрлэгт хүрээлэн рүү яаж ч явсан болно»; 最近我觉得哪儿都不舒服 → «Сүүлийн үед бие минь хаа сайгүй эвгүй байна»; 谁都有办法看好你的“病” → «Хэн ч чиний "өвчин"-ийг эдгээж чадна»; 什么都会 → «юуг ч чадна». Үгүйсгэлд «хэн ч … -гүй»: 我刚到这里，谁都不认识 → «Би саяхан ирсэн, хэнийг ч танихгүй».
- 看好 (看好你的“病”) — энд «(өвчин) эдгээх, эмчилж анагаах» (看病 — эмчид үзүүлэх/өвчин эмчлэх + 好 үр дүнгийн нөхбөр); «сайн харах» гэж калька хийхгүй. «病» хашилтанд — жинхэнэ өвчин биш, хөдөлгөөн дутсанаас болсон «өвчин» гэдгийг тайлбарт хэл.
- 请假 → «чөлөө хүсэх / чөлөө авах» (ажил, хичээлээс); 请病假 → «өвчний чөлөө авах», 请事假 → «хувийн хэргээр чөлөө авах», 婚假 → «хуримын чөлөө». 请 энд «урих» биш.
- 后来 → «дараа нь, сүүлд нь» — зөвхөн ӨНГӨРСӨН үйл явдлын дараалалд (我们过去是邻居，后来是大学同学 → «Бид урьд нь хөрш байсан, дараа нь их сургуульд хамт сурсан»); ирээдүйд 以后 хэрэглэнэ.
- 为了 → «…-ийн төлөө, …-ийн тулд» (为了健康 → «эрүүл мэндийнхээ төлөө»); 从明天起 → «маргаашнаас эхлэн»; 吃饱了就睡 → «цадтал идчихээд л унтдаг»; 多久没运动了 → «хэр удаан дасгал хөдөлгөөн хийгээгүй байна вэ»; 一般来说 → «ерөнхийдөө»; 口渴 → «ам цангах»; 长跑 → «холын зайн гүйлт».
- 老朋友 → «хуучин найз» («хөгшин найз» биш); 周经理 → «Жоу менежер» (яриа 1-д 小丽 周明-ийг ингэж дууддаг — нэг хүн); 丈夫 → «нөхөр»; 小丽 → «Сяо Ли»; 周明 → «Жоу Мин»; 周太太 → «Жоу хатагтай». Дасгалын номын 冬冬、小雨、月月 → «Дундун», «Сяо Юй», «Юэюэ»; 《小狗笑笑》 → «"Сяосяо гөлөг"».
- 形声字3-ыг монголоор «дүрс-авианы ханз 3 (дотор-гадна бүтэц)» гэж нэрлэ: 外形内声 — «утгын хэсэг гадна, авианы хэсэг дотор» (园、病), 内形外声 — «утгын хэсэг дотор, авианы хэсэг гадна» (问、闻); 形旁 — «утгын бүрэлдэхүүн», 声旁 — «авианы бүрэлдэхүүн» (L09/L13-ын 形声字1/2-тэй нэр томьёог нэгтгэ).

## Эргэлзээтэй / анхаарах зүйлс

- **Дасгалын номын хариулт бичвэртэй тохирсон** — Part 1–4, 21–54, 复习 1–2-ыг сонсголын бичвэр / уншлагын бичвэр / сурах бичгийн ярианы бичвэртэй нэг бүрчлэн тулгасан; илт хэвлэлийн алдаа ОЛДООГҮЙ (ШИЙДВЭР шаардлагагүй).
- **Багшийн ном vs сурах бичиг (яриа 1)** — багшийн номын 课文1 хариулт «她的一个老朋友下个星期结婚，她们两年没见了» гэж бичсэн ч сурах бичиг «我的一个老朋友结婚，我跟他两年没见了» (найз нь эрэгтэй — 他). ШИЙДВЭР: сурах бичгийн бичвэрийг дага; найзын хүйсийг «他»-оор (эсвэл хүйс тодотгохгүй) орчуул.
- **51–54 组词 хариулт** — 52 «有病» (ярианд «галзуу юм уу» гэсэн доромжилсон утгатай ч болдог) ба 54 «听闻» (бичгийн хэл, HSK3 үг биш) нь хавсралтын 参考答案 — номд байгаагаар нь бич; багшийн номын 汉字练习-ийн 组词 (病 → 生病、看病; 问 → 问题、请问; 闻 → 新闻) нь өөр зөв хувилбар — тайлбарт нэмж болно.
- **Сонсгол 10** — дасгалын номд «★有三个同学要介绍自己», хавсралтад «★有3个同学…» — утга ижил, хариулт × (шинээр 2 сурагч ирсэн).
- Багшийн номын 汉字 (`teacher_p122.png`) «教师展示更多内形外声的汉字…，如：闷» — ханз жижиг хэвлэгдсэн, 闷 бололтой (зургаар шалга — teacher_p122). Багшийн номд 声旁-ийн пиньинь «yuan / bing / men» тэмдэггүй — сурах бичгийн yuán / bǐng / mén-ийг ашигла.
- Сурах бичгийн 练一练 (дүрэм 1: 3 гүйцээх өгүүлбэр, дүрэм 2: 3 харилцан яриа), 练习 2–3, 热身 2, 运用 1–2 болон багшийн номын 扩展-ийн хариулт эх сурвалжид байхгүй. 练习 2-ын хоосон зай бүрт сангаас нэг л үг тохирох боловч номд хэвлээгүй — ашиглах эсэхийг эзэн шийднэ.
- Дасгалын номд 51–54 (用下边的汉字组词) хэсэг БИЙ — нийт 54 асуулт + 复习 2 (L09/L13-ын адил, L14-өөс ялгаатай).
- Энэ хичээлд 专有名词, 文化 хэсгүүд БАЙХГҮЙ — зохиохгүй. 汉字知识 (形声字3) БАЙГАА. * тэмдэгтэй үг 1 (14 情况).
- Яриа 1 ба 2 хоёулаа «在公司 / In the company» гарчигтай; яриа 4-т гарчиг байхгүй (номд зөвхөн «4»), өгүүлэгчийн хүйс заагаагүй — орчуулгад хүйс тодотгохгүй. Яриа 2-ын 同事-ийн хүйс номд заагаагүй.
- 注释 1-ийн (4) «我真应该多锻炼锻炼了» ба 注释 2-ын (4) «最近我觉得哪儿都不舒服» — яриа 3-аас, номд улаанаар.
- 生词 1 请假 «qǐng jià» — номд зайтай бичсэн (салгаж хэрэглэдэг үг: 请几天假); 11 冬(天) «dōng (tiān)» — хаалттай; хэвээр нь. 热身-д 冬天 «dōngtiān».
- 复习 2-т 周明-ийг «周经理» гэж нэрлэсэн — нэг хүн (яриа 1-ийн 周经理 = 周明).
