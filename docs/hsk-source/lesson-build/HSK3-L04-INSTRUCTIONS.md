## Бичих дүрэм

- Апп-ын хэл: **монгол** (кирилл), багшийн тайлбар ярианы хэлээр, найрсаг, тодорхой. Хятад жишээ бүрт монгол орчуулга. Пиньиньд хөгийн тэмдэг ЗААВАЛ (zǒngshì, nǔlì…), OCR-ийн тэмдэггүй пиньинийг хуулж болохгүй.
- Хятад бичвэр дэх цэг таслал бүтэн өргөнтэй (，。？！：) байна.
- Юу ч ЗОХИОХГҮЙ: сурах бичиг, багшийн ном, дасгалын номд байхгүй дасгал, хариулт, баримт бичихгүй. Багшийн номын нэмэлт жишээ өгүүлбэрүүдийг ашиглаж болно. Өөрийн зохиосон нэмэлт жишээ өгүүлбэр (заах зорилгоор) зөвхөн энэ хичээл + HSK1–2 үгсийн санд багтсан үгсээр, зөв дүрэмтэй байх.
- 1-р хичээлийн текстийг ХУУЛАХГҮЙ — зөвхөн бүтцийг нь дага.
- Дүрэм 1-ийг монголоор «又…又… — хоёр шинжийг зэрэг илэрхийлэх» гэж нэрлэ; орчуулга «…бас …» / «…ч …, …ч …» (又高又漂亮 → «өндөр бас хөөрхөн»). Энэ 又 нь HSK2-ын «дахиад» (他又来了) гэсэн 又-оос өөр — ялгааг тэмдэглэ. Хоёр шинж зөрчилгүй байх ёстой (今天又冷又暖和 — буруу).
- Дүрэм 2-ыг монголоор «дагалдах үйлдэл: V1着(O1) + V2(O2)» гэж нэрлэ; V1着 = V2-ийг ямар байдлаар/юу хийнгээ хийж байгааг заана, гол үйлдэл нь V2. Монголоор нөхцөл үйл үгээр орчуул: 笑着说话 → «инээмсэглэн ярих», 站着聊天儿 → «зогсоогоороо ярилцах», 吃着蛋糕看电视 → «бялуу идэнгээ зурагт үзэх», 拿着书笑 → «ном барьчихаад инээх». 3-р хичээлийн оршихуйн «Байршил + V着 + NP»-ээс ялга (энд 着 хоёр үйл үгийг холбоно).
- 客人-г нөхцөлөөр нь орчуул: ресторан/дэлгүүрт → «үйлчлүүлэгч», гэрт (家里来客人、做客) → «зочин».
- 年级: бага/дунд сургуульд «анги» (二年级 — 2-р анги), их сургуульд «курс» (大学三年级 — 3-р курс).
- 元/角/分: номын зүүлтээр 2.99元 = 2元9角9分; 块 (蛋糕-ийн тоо нэр «нэг зүсэм/хэсэг») — яриа 3-т 一块蛋糕.
