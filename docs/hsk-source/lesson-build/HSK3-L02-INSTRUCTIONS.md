**注释 — 3 дүрэм:**
1. 简单趋向补语 — V + 来/去 (上/下/进/出/回/过/起 + 来/去; 买来、带来、搬去). Газрын нэр объект бол 来/去-ийн ӨМНӨ (小狗下楼来了 / 老师进教室来了 / 朋友回家去了 / 我上楼去); эд юмсын объект бол өмнө ч, хойно ч болно (明天要带作业来 / 帮我买来点儿面包 / 你搬这把椅子去吧 / 这次旅游，我想带去这本书). Жишээ: 我们在楼上等你呢，你上来吧。／谁在外边？你出去看看吧。／汉语书你带来了吗？／那边树多，我们过去坐一下吧。 练一练: (1) 你怎么还没＿＿？我都在楼下等你半小时了。 (2) 已经10点半了，快点儿＿＿，别睡了。 (3) 明天去朋友家，我想＿＿。
2. 两个动作连续发生 — V1了…就V2 (我下了课就吃饭 / 妈妈起了床就做早饭 / 小刚拿了伞就下来 / 你每天晚上吃了饭就睡觉). Хоёр өгүүлэгдэхүүнтэй бол 2 дахь нь 就-ийн өмнө (你下了课我们就去书店 / 老师进了教室我们就对她说“生日快乐” / 爸爸回来了我们就吃饭 / 他到了办公室我就告诉他). 练一练: 完成对话 (1) A: 你什么时候给妈妈打电话？ B: 我打算＿＿。(回家) (2) A: 你怎么＿＿？(下课，回家) B: 我太累了。 (3) A: 你什么时候走？ B: 他来了＿＿。
3. 反问的表达 — 能……吗？ Дотор нь батлах хэлбэр бол утга нь үгүйсгэл, үгүйсгэл бол батлах: 你不做作业，也不练习，能学好吗？(不能学好) / 你每天晚上吃了饭就睡觉，也不出去走走，能不胖吗？(会胖). 练一练 (完成对话, 3 асуулт): (1) A: 我怎么这么累啊？ B: ＿＿(OCR эвдэрсэн — `img/textbook_p32.png`-оос унш)？ (2) A: ＿＿(зургаар унш)。 B: 天气这么冷，你穿得这么少，＿＿？ (3) A: 你怎么打篮球打得这么好？ B: 我每天都练习，＿＿？
   (练一练-ийн дутуу хэсгийг зургаар шалга: `img/textbook_p30.png`, `p31.png`, `p32.png`.)

## Бичих дүрэм

- Апп-ын хэл: **монгол** (кирилл), багшийн тайлбар ярианы хэлээр, найрсаг, тодорхой. Хятад жишээ бүрт монгол орчуулга. Пиньиньд хөгийн тэмдэг ЗААВАЛ (tuǐ, téng…), OCR-ийн тэмдэггүй пиньинийг хуулж болохгүй.
- Хятад бичвэр дэх цэг таслал бүтэн өргөнтэй (，。？！：) байна.
- Юу ч ЗОХИОХГҮЙ: сурах бичиг, багшийн ном, дасгалын номд байхгүй дасгал, хариулт, баримт бичихгүй. Багшийн номын нэмэлт жишээ өгүүлбэрүүдийг ашиглаж болно. Өөрийн зохиосон нэмэлт жишээ өгүүлбэр (заах зорилгоор) зөвхөн энэ хичээл + HSK1–2 үгсийн санд багтсан үгсээр, зөв дүрэмтэй байх.
- 1-р хичээлийн текстийг ХУУЛАХГҮЙ — зөвхөн бүтцийг нь дага.
- Эсрэг асуулт 能…吗-г монголоор «…чадах уу?» биш, «яаж … байх билээ?» / «…гүй яах вэ?» гэсэн эсрэг асуултын аялгаар орчуул (能不胖吗？ → «Таргалахгүй яах вэ дээ?»).
- 趋向补语-ыг монголоор «ирэх/явах чиглэлийн нөхбөр» гэж нэрлэ; 来 = өгүүлэгч рүү, 去 = өгүүлэгчээс хол.

- 办 bàn (办事 — хэрэг бүтээх) нь энэ хичээлийн дугаарласан шинэ үг БИШ (HSK3 үг, яриан дотор гардаг) — тайлбарлаж болно, гэхдээ vocabulary.json-д 18 үг + 2 тусгай нэрээс гадуур оруулахгүй.
