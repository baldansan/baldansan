## Хичээлийн баримт (баталгаатай — үүнийг л ашигла)

**Гарчиг:** 你没看出来吗 · Nǐ méi kàn chulai ma · «Чи танисангүй юу?» (англи: Didn’t you recognise him) (`L19/img/textbook_p175.png`; 看出来 — харж таних, ялгаж мэдэх; «гарч ирэхийг харсангүй юу» гэж калька хийхгүй)
**Сэдэв:** чиглэлийн нөхбөрийн шилжмэл утга — V + 出来 (бий болох / таних, ялгах), Adj/V + 下来 (хөдөлгөөнөөс тайван, хүчтэйгээс сул, хурднаас удаан болох), V + 起来 (санаж олох); 看起来 / 看上去 («харахад … харагдах»); 使 / 叫 / 让 + хүн + V/Adj (үйлдүүлэх — «…-ыг …болгох, …-д …мэдрэмж төрүүлэх»); өдөр тутмын яриа — охин нь үсээ чихнийхээ ард хавчуулдаг болж өөрчлөгдсөн тухай эцэг эхийн яриа, морин уралдааны зураг дээр Сяо Ганг таньсангүй (спорт хувцас түүнийг залуу харагдуулдаг), найзын нэг настай охинд бэлэг (аав нь шувуу дуурайхад л нам болдог), аялалд Хуанхэ мөрнийг завиар үзэж, зургаа найзууддаа илгээх.

- Апп-ын хэл: **монгол** (кирилл), багшийн тайлбар ярианы хэлээр, найрсаг, тодорхой. Хятад жишээ бүрт монгол орчуулга. Пиньиньд хөгийн тэмдэг ЗААВАЛ (ěrduo, liǎn, duǎn, zhāng, jīngguò, Huáng Hé…), OCR-ийн тэмдэггүй пиньинийг хуулж болохгүй.
- Хятад бичвэр дэх цэг таслал бүтэн өргөнтэй (，。？！：) байна.
- Юу ч ЗОХИОХГҮЙ: сурах бичиг, багшийн ном, дасгалын номд байхгүй дасгал, хариулт, баримт бичихгүй. Багшийн номын нэмэлт жишээ өгүүлбэрүүдийг ашиглаж болно. Өөрийн зохиосон нэмэлт жишээ өгүүлбэр (заах зорилгоор) зөвхөн энэ хичээл + HSK1–2 үгсийн санд багтсан үгсээр, зөв дүрэмтэй байх.
- 1-р хичээлийн текстийг ХУУЛАХГҮЙ — зөвхөн бүтцийг нь дага.
- Дүрэм 1-ийг монголоор «чиглэлийн нөхбөрийн шилжмэл утга: 出来 / 下来 / 起来» гэж нэрлэ (L02/L13-ын «ирэх/явах чиглэлийн нөхбөр», «нийлмэл чиглэлийн нөхбөр»-тэй нэг нэр томьёо; тэнд үйлдлийн БОДИТ чиглэл, энд ШИЛЖМЭЛ утга гэдгийг холбож тайлбарла). Утга ба орчуулга:
  - V + 出来 (бий болох, «…ж гаргах/олох»): 写出来 → «бичиж гаргах»; 想出来一个好办法 → «сайн арга бодож олох»; 一会儿就画出来了 → «хэсэг зуурын дараа л зурж дуусгачихлаа»; 照片我选了几张洗出来了 → «Зургуудаас хэдийг нь сонгож угаалгачихлаа (хэвлүүлчихлээ)».
  - V + 出来 (ялгаж таних, «…ж таних/мэдэх»): 你没看出来吗？他是小刚啊 → «Чи танисангүй юу? Тэр чинь Сяо Ган шүү дээ»; 你听出来了吗？这是谁的声音？ → «Чи сонсоод таньсан уу? Энэ хэний дуу вэ?»; 我喝不出来这两杯咖啡有什么不一样 → «Энэ хоёр аяга кофе юугаараа ялгаатайг би амтлаад ялгаж чадахгүй нь». Боломжийн хэлбэр: V + 得/不 + 出来.
  - Adj/V + 下来 (хөдөлгөөнөөс тайван, хүчтэйгээс сул, хурднаас удаан): 停下来了 → «зогслоо»; 天黑下来了 → «харанхуй болж байна»; 时间能慢下来 → «цаг хугацаа удааширч»; 她马上就安静下来了 → «тэр даруй намдчихдаг/нам болчихдог».
  - V + 起来 (санаж олох): 我也想起来了 → «Би ч бас санаж байна (санаанд орлоо)»; 你记起来我是谁了吗？ → «Намайг хэн болохыг санав уу?»; 我想不起来你的名字了 → «Би таны нэрийг санахгүй байна».
  - 看起来 / 看上去 — «харахад …харагдах, …юм шиг харагдах» (санах утгагүй): 看上去像40多岁 → «40 гаран настай юм шиг харагдана»; 看起来很好吃 → «амттай харагдаж байна»; 可以使脸看上去漂亮一些 → «нүүрийг арай хөөрхөн харагдуулдаг».
  - Нөхбөр 出来/下来/起来/上去 хөнгөн аялгатай (kàn chulai, ānjìng xialai, xiǎng qilai, kàn shangqu).
- Дүрэм 2-ыг монголоор «使 / 叫 / 让 — үйлдүүлэх утга: A + 使/叫/让 + B + V/Adj ("A нь B-г …болгох, B-д …мэдрэмж төрүүлэх")» гэж нэрлэ. 使 — бичгийн хэл, 叫 — ярианы хэл, 让 — хоёуланд нь. Монголоор шууд «…-ыг …болгодог» гэж калька хийхгүй — үйлдүүлэх (-уул/-үүл, -га/-гэ) дагавар эсвэл «…-д …санагддаг/…-аар …болдог» бүтцээр байгалийн орчуулга хий: 读书使我快乐 → «Ном унших надад баяр баясал авчирдаг»; 考试让我很紧张 → «Шалгалт намайг их сандаргадаг»; 穿运动服让他更年轻 → «Спорт хувцас өмсөхөөр тэр илүү залуу харагддаг»; 叫朋友们也高兴高兴 → «найзуудаа ч бас баярлуулъя»; 每个地方都让我非常难忘 → «Газар бүр надад мартагдашгүй сэтгэгдэл үлдээсэн»; 这样可以使她的脸看上去漂亮一些 → «Ингэхэд нүүр нь арай хөөрхөн харагддаг»; 去公园让我很高兴 → «Цэцэрлэгт хүрээлэнд очих надад их таалагддаг/баярлуулдаг». HSK2-т сурсан 让 («…-д …хийлгэх, …-г …хий гэх»: 让我再睡一会儿) — хэн нэгнийг үйлдэл хийлгэх; энэ хичээлийн 让/使/叫 — сэтгэл хөдлөл, байдал өөрчлөгдөхөд хүргэх.
- **叫-ийн гурван утгыг хольж болохгүй:** (1) 叫 = «нэрлэгдэх, дуудах» (我叫…); (2) 学鸟叫 / 学小鸟叫 — энд 叫 нь амьтны «жиргэх, дуугарах» (шувууны дууг дуурайх); (3) 叫朋友们也高兴高兴 — үйлдүүлэх «叫» (= 让). Яриа 3 ба 4-т хоёулаа гардаг — тайлбарт тодорхой ялга.
- 高兴高兴 — тэмдэг нэрийг ABAB хэлбэрээр давхарлаж үйл үг мэт «(бусдыг) баярлуулах, сэтгэл сэргээх» утгаар хэрэглэсэн (L17-ын хоёр үетэй үйл үгийн давхарлалт ABAB-тэй холбож болно); энэ хичээлийн шинэ дүрэм биш.
- 洗照片 / 洗出来 → «зураг угаах, угаалгах (хэвлүүлэх)» — «угааж цэвэрлэх» гэж бүү ойлгуул; 洗脸 → «нүүрээ угаах» (хоёр өөр утга).
- 过 (生词 9) → «өнгөрүүлэх, тэмдэглэх» (过生日 → «төрсөн өдрөө тэмдэглэх», 过节 → «баяр тэмдэглэх», 过冬 → «өвөлжих»); туршлагын 过 (去过) болон 经过/路过-оос ялга. 经过 → «дайрч өнгөрөх, хажуугаар нь өнгөрөх»; 路过 → «замдаа дайрах».
- 张 / 位 — тоо ноогдол: 几张照片 → «хэдэн зураг»; 这位 → «энэ хүн/эрхэм» (хүндэтгэлтэй); 您几位？ → «Хэдүүлээ вэ?» (ресторан, зочид буудалд).
- 你都有女儿了？ → «Чи охинтой болчихсон юм уу?» (都 = «аль хэдийн»; «бүгд» биш). 刚过完一岁生日 → «нэг насны төрсөн өдрөө саяхан тэмдэглэсэн». 这个礼物我没办法送 → «Энэ бэлгийг би өгөх арга алга» (шоглосон төгсгөл — аавынх нь шувуу дуурайхыг бэлэг болгож чадахгүй). 还是穿运动服让他更年轻 → «Спорт хувцас өмсөх нь түүнийг илүү залуу харагдуулдаг юм байна» (还是 — харьцуулаад дүгнэх). 一路上 → «замдаа». 像男孩子一样 → «хүү хүүхэд шиг». 慢慢地开始像个女孩子了 → «аажмаар охин хүүхэд шиг болж эхэлж байна». 骑马比赛 → «морин уралдаан». 西服 → «костюм», 衬衫 → «цамц», 运动服 → «спорт хувцас».
- 黄河 → «Хуанхэ мөрөн» (эхний удаа «Хуанхэ (Шар мөрөн)» гэж тайлбарла); 小丽 → «Сяо Ли»; 小刚 → «Сяо Ган». Дасгалын номын 小雨、小冬、小红、大卫 → «Сяо Юй», «Сяо Дун», «Сяо Хун», «Дэвид».
