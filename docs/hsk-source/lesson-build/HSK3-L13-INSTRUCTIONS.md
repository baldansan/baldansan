**注释 — 2 дүрэм (х. 110–111, `L13/img/textbook_p126.png`, `p127.png`):**
1. 复合趋向补语 (Compound Complements of Direction) — 趋向动词 «上、下、进、出、回、过、起» зэргийн ард энгийн чиглэлийн нөхбөр «来»«去» залгаснаар бусад үйл үгийн нөхбөр болж, үйлдлийн чиглэлийг заана — нийлмэл чиглэлийн нөхбөр үүсч, үйлдлийг тодорхой дүрсэлнэ. Түгээмэл нийлмэл чиглэлийн нөхбөр (хүснэгт): 来 — 上来 下来 进来 出来 回来 过来 起来; 去 — 上去 下去 进去 出去 回去 过去 …… (起去 байхгүй — хүснэгтэд «……»).
   Жишээ: (1) 老师拿出一本书来。 (2) 小狗从房间跑出来。 (3) 我给你拿过去吧。 (4) 坐久了还可以站起来休息一会儿。 (4 = яриа 3, номд улаанаар.)
   Тусагдахуун нь БАЙР (газар) бол «来»«去»-гийн ӨМНӨ: (5) 老师走进教室来。 (6) 周太太走进咖啡店去。
   Энгийн эд юмс тусагдахуун бол «来»«去»-гийн өмнө ч, ард ч болно: (7) 哥哥买回一个西瓜来。=哥哥买回来一个西瓜。 (8) 爸爸从国外带回一些礼物来。=爸爸从国外带回来一些礼物。
   注意: Үйлдэл аль хэдийн дуусч биелсэн бол тусагдахуун ихэвчлэн «来/去»-гийн АРД: 哥哥买回来了一个西瓜。/爸爸带回来了一些礼物。

2. 一边……一边…… (The Structure «一边……一边……») — хятад хэлэнд «一边……一边……» нь хоёр үйлдэл нэгэн зэрэг явагдаж буйг илэрхийлнэ; жишээ нь «一边听音乐一边做作业» — «хөгжим сонсох», «даалгавар хийх» хоёр нэгэн зэрэг. «一»-г орхиж болно (边……边……). Жишээ: (1) 妈妈一边唱歌一边做饭。 (2) 老师边说边笑。 (3) 小丽和老同学边喝咖啡边聊天儿。 (4) 我丈夫喜欢一边吃早饭一边看报纸。 (4 = яриа 4, номд улаанаар.)

   Багшийн номын томьёо (х. 85): «一边 + 动词₁ + 一边 + 动词₂». 导入 — 热身2: «学生：老师，您看报纸的时候还做什么？ 教师：看报纸的时候，我还喝茶。» → «老师一边看报纸一边喝茶。» 目标句 (х. 86, `L13/img/teacher_p93.png`): 上大学的时候，老师每天晚上一边做作业，一边吃饭。/老师一边运动一边听音乐。/在机场，老师一边等人一边看报纸。/老师一边爬山一边跟朋友聊天儿。/老师喜欢一边看电视一边喝咖啡。 注意: «"一"可以省略，说成"边……边……"».

## Бичих дүрэм

- Апп-ын хэл: **монгол** (кирилл), багшийн тайлбар ярианы хэлээр, найрсаг, тодорхой. Хятад жишээ бүрт монгол орчуулга. Пиньиньд хөгийн тэмдэг ЗААВАЛ (zhōngyú, yùdào, yuànyì, xiàozhǎng…), OCR-ийн тэмдэггүй пиньинийг хуулж болохгүй.
- Хятад бичвэр дэх цэг таслал бүтэн өргөнтэй (，。？！：) байна.
- Юу ч ЗОХИОХГҮЙ: сурах бичиг, багшийн ном, дасгалын номд байхгүй дасгал, хариулт, баримт бичихгүй. Багшийн номын нэмэлт жишээ өгүүлбэрүүдийг ашиглаж болно. Өөрийн зохиосон нэмэлт жишээ өгүүлбэр (заах зорилгоор) зөвхөн энэ хичээл + HSK1–2 үгсийн санд багтсан үгсээр, зөв дүрэмтэй байх.
- 1-р хичээлийн текстийг ХУУЛАХГҮЙ — зөвхөн бүтцийг нь дага.
- Дүрэм 1-ийг монголоор «нийлмэл чиглэлийн нөхбөр (复合趋向补语): V + 上/下/进/出/回/过/起 + 来/去» гэж нэрлэ. 2-р хичээлийн энгийн «ирэх/явах чиглэлийн нөхбөр»-тэй холбо: 来 = өгүүлэгч рүү, 去 = өгүүлэгчээс хол. Монгол утга: 上来/上去 — дээш гарч ирэх/гарч очих; 下来/下去 — доош бууж ирэх/бууж очих; 进来/进去 — орж ирэх/орж очих; 出来/出去 — гарч ирэх/гарч явах; 回来/回去 — буцаж ирэх/буцаж харих; 过来/过去 — наашаа ирэх/цаашаа очих; 起来 — босох, дээш өргөх. Орчуулга: 从哪儿买回来这么多东西 → «Хаанаас ийм их юм худалдаж аваад ирэв ээ?»; 明天我们一起送过去 → «Маргааш хамт аваачиж өгье»; 快拿出来让我看看 → «Хурдан гаргаад надад үзүүлээч»; 我是走回来的 → «Би алхаж ирсэн юм»; 站起来休息一会儿 → «босоод жаахан амрах»; 老师走进教室来 → «Багш анги руу орж ирлээ». Байрны тусагдахуун 来/去-гийн ӨМНӨ (走进教室来, 走进咖啡店去 — «走进来教室» гэж болохгүй); энгийн эд зүйл өмнө ч ард ч (买回一个西瓜来 = 买回来一个西瓜); үйлдэл дууссан бол ихэвчлэн ард (买回来了一个西瓜).
- 过去 энэ хичээлд ХОЁР үүрэгтэй: нэр үг guòqù «өнгөрсөн» (过去的事 — өнгөрсөн явдал; шинэ үг 7) ба чиглэлийн нөхбөр/үйл үг «очих, өнгөрөх» (送过去 sòng guoqu — аваачиж өгөх, 十年过去了 — арван жил өнгөрчээ, 快过去吧 — хурдан очъё). Пиньинь ба орчуулгад андуурахгүй.
- 起来 (шинэ үг 10) — «босох» (站起来 — босож зогсох), «өргөх» (拿起来, 搬起来). 起去 гэж байдаггүй (номын хүснэгтэд «……»).
- Дүрэм 2-ыг монголоор «一边……一边…… — хоёр үйлдлийг нэгэн зэрэг хийх ("…нгаа …")» гэж нэрлэ. Орчуулга: 一边喝咖啡一边说了些过去的事 → «кофе уунгаа өнгөрсөн үеийн юм ярилцсан»; 可以一边吃一边看 → «идэнгээ үзэж болно»; 妈妈一边唱歌一边做饭 → «Ээж дуулангаа хоол хийдэг»; 老师边说边笑 → «Багш ярингаа инээнэ»; 一边开车一边打电话 → «машин жолоодонгоо утсаар ярих». «一»-г орхиж «边……边……» гэж болно (ярианд, богино үйл үгтэй).
- 坏 — тэмдэг нэр «эвдэрсэн» (车坏了, 电梯坏了 — «цахилгаан шат эвдэрсэн»); үйл/тэмдэг үгийн ард зэргийн утга: 累坏了 → «ядарч туйлдах», 我真怕他累坏了 → «Түүнийг хэт ядарчих вий гэж үнэхээр айж байна»; 忙坏了, 饿坏了.
- 一般 → «ихэвчлэн, ерөнхийдөө» (周末你一般……吗？); 经常 → «байнга»; 更愿意 → «илүүд үзэх, илүү дуртай».
- 遇到 → «(санамсаргүй) таарах»; 遇见 (旧字新词) нь 遇到-той бараг ижил.
- 爷爷/奶奶 → «өвөө/эмээ» (аавын талын); 红酒 → «улаан дарс».
- 我不是已经回来了吗？ → «Би өөрөө ирчихлээ биз дээ?» (эсрэг асуулт — «Би л чиний бэлэг» гэсэн хошин утга); 有他在 → «Тэр байгаа болохоор».
- 形声字2-ыг монголоор «дүрс-авианы ханз 2 (дээд-доод бүтэц)» гэж нэрлэ: 上形下声 — «утгын хэсэг дээр, авианы хэсэг доор», 下形上声 — «авианы хэсэг дээр, утгын хэсэг доор»; 形旁 — «утгын бүрэлдэхүүн», 声旁 — «авианы бүрэлдэхүүн» (L09-ийн 形声字1-тэй нэр томьёог нэгтгэ).

- **Дасгалын ном 36 — хэвлэлийн зөрүү:** өгөгдсөн хэсгүүд «一边 聊天儿 走路 我们 一边» (`L13/img/workbook_p94.png`, 220 dpi) — «聊天儿» (儿-тэй), харин 参考答案 (`L13/img/teacher_p181.png`) «我们一边走路一边聊天。» (儿-гүй).
