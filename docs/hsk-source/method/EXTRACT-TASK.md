Зорилго: энэ номыг бичсэн багш нар хичээлийг ХЭРХЭН заадаг вэ — түүнийг аппын дизайнд ашиглахаар бүтэцтэй тайлан болго. **Зөвхөн номд байгаа зүйл.** Өөрийн санаа, зөвлөмж, орчуулгын үг нэмэхгүй. Мэдэгдэл бүрт ишлэл: (L5, х.36) гэх мэт — хичээл + PDF хуудас.

Тайланд (монголоор бич, хятад нэр томьёог хаалтанд/шууд хэвээр үлдээ, жишээг хятадаар нь):

## 1. Хичээлийн бүтэц ба дараалал
Хичээл бүрийн 教学步骤-ийн хэсгүүд ямар дараалалтай вэ (复习旧课 → 热身 → 生词 → 语言点 → 课文 → 语音 → 汉字 → 课堂活动 → 小结 …). Хичээлээс хичээлд ялгаатай бол (жишээ нь эхний хичээлүүд) ялгааг заа. Хэсэг бүрийн цаг заасан бол бич. Хүснэгтээр.

## 2. Хэсэг бүрийн заах техник (гол хэсэг)
Хэсэг бүрт (复习, 热身, 生词, 语言点, 课文, 语音, 汉字, 课堂活动/补充活动, 俗语/文化, 小结, 教学用具):
- Ном ЯМАР техникүүдийг ашигладаг вэ — жагсаа, хэдэн хичээлд тохиолдсоныг тоол (жишээ: «生词快速认读: 教师领读→学生齐读→接龙 — 13/15 хичээлд»).
- Техник бүрт 1–2 бодит жишээ (хятадаар, ишлэлтэй).
- Давтагдах ХЭВ МАЯГ (жишээ: 语言点 үргэлж ①解析 ②导入 ③操练 ④扩展练习 гэсэн 4 алхамтай эсэх; 生词 үргэлж 扩展及常用搭配 хэлбэртэй эсэх; 课文 хэсэгт 听录音→回答问题→跟读→分角色→替换/复述 гэх мэт).
- 语音 ({LEVEL}-д байвал): хичээл бүр ямар дуудлагын сэдэв, ямар дасгал, ямар дарааллаар (эхний хичээлээс сүүлийн хүртэл хүснэгт).
- 汉字: ямар мэдлэг (笔画→笔顺→独体字→偏旁→形近字→旧字新词 …) хэзээ орж ирдэг, ямар дасгал.

## 3. Дасгалын номтой холбоо
«练习册相关练习：…» гэсэн заалтууд ямар хэсгийн дараа, ямар хэв маягтай (хичээлийн аль үед ямар дасгал хийлгэдэг).

## 4. «注意»/notes-д давтагддаг сануулгууд
Багш нарт өгсөн анхааруулгуудын төрлүүд (дуудлага, дүрмийн түгээмэл алдаа, соёл…) — жишээтэй.

## 5. 教学目标-ийн бүтэц
Зорилгын ангилал (重点词语 / 语言点 / 语音 / 汉字 / 功能 …) хичээл бүрт тогтмол эсэх; хэдэн зорилт байдаг.

## 6. Тоон дүн
Хичээл бүрт: 语言点 тоо, 课堂活动 тоо, 语音 сэдвийн тоо, 汉字 (独体字/偏旁) тоо — хүснэгт.

## 7. Аппд шууд хамаатай ажиглалт (зөвхөн номоос гарах)
Номын алхмуудаас аль нь «багш–суралцагч» харилцаа шаарддаг (хос, бүлэг, багшийн асуулт) — аль нь ганцаараа хийж болох — гэдгийг ном өөрөө юу гэж заасныг үндэслэн ангил. Өөрийн санал БҮҮ нэм.
