### 2.3 生词 (L3–L15)

Бүх 13 хичээлд **яг ижил 2 дэд хэсэгтэй**:

**(1) 生词快速认读及正音 — 4 алхамт техник, 13/13 хичээл:**
1. 生词卡片-ийн 拼音+汉字 талаар багш 领读;
2. зөвхөн 汉字 талаар дахин 认读;
3. 请单个学生独自认读2–3个生词;
4. 全体学生再快速认读一遍 (L3, х.13–19; … L15, х.99–105).

Картын загвар: «正面 jiào 叫 ／ 背面 叫» (L3, х.13–19).
Ерөнхий дүрэм: «生词认读过程中教师始终要注意纠正学生的错误发音，学生齐读时要注意纠正学生共性的发音错误，个别认读时要注意纠正学生的个别发音错误。（后课同）» (L3, х.13–19).

**(2) 重点生词扩展及常用搭配 — 13/13 хичээл.** Хэлбэр нь «үг → хоршоо үг → өргөтгөсөн хэллэг → бүтэн өгүүлбэр» гинжин өргөтгөл:

- 有—有朋友—有中国朋友—我有中国朋友。 (L5, х.27–33)

### 2.5 课文

**L1–L2 загвар (2 хичээл):** 教师领读三段课文 → 学生跟读模仿 (语音语调自然流畅) → 两人一组分角色读 → 请个别学生朗读检查 (L1, х.3–7; L2, х.8–12).

**L3 загвар:** 教师领读课文两遍 + 课文图片 → 回答问题 → 教师领说目标句 → 学生单个复述 → 分角色朗读 (3 текст, L3, х.13–19).

**L4–L15 стандарт загвар (36 текст):**
(1) **让学生听两遍录音并回答问题** → (2) 教师**领说目标句 / 变为叙述体的课文** → 请学生单个复述 → (3) 教师领读课文两遍 → 分角色朗读 → (4) 模仿练习 (заримд).
Жишээ: 让学生听两遍录音并回答：他家有几口人？→ 领说：他家有三口人。(L5, х.27–33).

### 7.2 «教师：… 学生：…» гэсэн багшийн асуулт-хариулт шаарддаг алхмууд

- 复习旧课-ийн 简单提问 — L4–L15 (12/12).
- 语言点 ②导入 — бараг бүх хэсэг «教师：…？学生：…。» диалогоор бичигдсэн (жишээ L3, L5, L9, L10, L12, L14, L15).
- 课文: 教师…请学生回答问题 → 教师领说 → 请学生单个复述 (L3–L15).
- 热身: 教师评判正误 (13/13).
- 语言点 操练-ийн «根据实际情况进行问答练习» — ном хэн хэнээс асуухыг ихэнхдээ заагаагүй; зарим нь «教师：…学生：…» хэлбэртэй (L14 了, х.92–131; L15 是……的, х.99–105).

### 7.3 Ном багш удирдан бүх ангиар (集体/齐读) хийлгэхээр заасан алхмууд

### 7.5 Ном ангиас гадуур/бие даан хийхээр заасан алхмууд
