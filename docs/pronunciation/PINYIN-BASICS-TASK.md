## Goal
Exactly how Chinese first-graders learn pinyin (汉语拼音字母表): 6 single finals → initials in groups (taught as syllables «bo po mo fo») → compound finals → nasal finals → whole syllables → rules. Every unit: 👂 listen (human audio, 4 tones) → 👄 how to pronounce (Mongolian tip, comparison with Mongolian sounds) → 🎯 exercises (hear-and-pick, build syllables 拼读) → 🎤 say it (tone feedback) → ✅ mini-test. Works for a 6-year-old (big letters, big buttons, few words) and adults.

## Data: `lib/pronunciation/pinyin-course.ts` (static, typed)
```ts
type CourseItem = { letter: string; syl: string /* chart key with audio, e.g. "bo" */; exampleHanzi: string; examplePinyin: string; exampleMn: string; tip: string /* Mongolian articulation tip */; tipZh?: string };
type CourseUnit = { id: string; order: number; title: string; titleZh: string; emoji: string; intro: string; items: CourseItem[]; blend?: { initials: string[]; finals: string[] } /* 拼读 practice combos available at this point */; pairs?: [string, string][] /* minimal pairs for hear-and-pick, chart keys */ };
```
Units (item letter → audio syllable key → example char from the classic chart):
1. **Дан эгшиг 单韵母** (6): a→"a" 啊 ā «аа — гайхах»; o→"o" 喔 ō; e→"e" 鹅 é «галуу»; i→"yi" 衣 yī «хувцас»; u→"wu" 乌 wū «хэрээ»; ü→"yu" 鱼 yú «загас». Tips: a = монгол «а»-аас ам илүү том, доод эрүү бууна; o = «о» уруул дугуй, «уо» шиг бага зэрэг; e = монгол «э» биш — «ө/э»-ийн дунд, уруул инээмсэглэсэн хэвээр «э» (хэл арагш); i = «и», уруул хажуу тийш татсан; u = «у», уруул хамгийн дугуй, урагш; ü = монгол «ү»-тэй яг адил (монголчуудын давуу тал!). Pairs: (o, e), (wu, yu), (yi, yu).
2. **b p m f** (播 bō 泼 pō 摸 mō 佛 fó): syllables bo po mo fo. Tips: b = агааргүй «б» (гараа амны өмнө барихад салхи гарахгүй); p = «п» + хүчтэй агаар (цаас хөдөлнө); m = «м»; f = дээд шүд доод уруул дээр «ф» (монголд байхгүй — «п» гэж бүү хэл). Blend: initials [b,p,m,f] × finals [a,o,i,u] (skip impossible: bo/po/mo/fo ok; bi pi mi ok; bu pu mu fu ok; fa; skip fi, fo? fo exists). Pairs: (bo,po), (ba,pa), (bi,pi), (mo,fo).
3. **d t n l** (得 dé 特 tè 讷 nè 了 le): de te ne le. Tips: d = агааргүй «д»; t = «т» + агаар; n = «н» хамраар; l = «л» хэлний үзүүр дээд буйланд. Blend [d,t,n,l] × [a,e,i,u, ü(only n/l → nü, lü)]. Pairs: (de,te), (da,ta), (ne,le), (nu,lu), (nü→"nü", lü→"lü" — chart keys are "nü"/"lü" or "nv"/"lv"? check `pinyin_chart.json` keys and use what exists).
4. **g k h** (哥 gē 科 kē 喝 hē): ge ke he. Tips: g = агааргүй «г» (хоолойн гүнд биш, хэлний угаар); k = «к» + агаар; h = монгол «х»-ээс зөөлөн, хоолойгоор үрэлттэй. Blend [g,k,h] × [a,e,u]. Pairs: (ge,ke), (ka,ha), (gu,ku).
5. **j q x** (鸡 jī 气 qì 西 xī): ji qi xi. Tips: хэлний нуруу тагнай руу, хэлний үзүүр ДООД шүдний ард; j = зөөлөн «дз/ж» агааргүй, q = «ч» + агаар (зөөлөн), x = зөөлөн «ш/с» (инээмсэглэсэн). Дараа нь зөвхөн i, ü ирнэ; ü-ийн цэг унана (ju qu xu = jü qü xü!). Blend [j,q,x] × [i, ü(written u), ia? no — keep i,u(=ü), ie? skip] → ji qi xi ju qu xu. Pairs: (ji,qi), (qi,xi), (ju,qu).
6. **zh ch sh r** (知 zhī 吃 chī 狮 shī 日 rì): zhi chi shi ri. Tips: хэл эргэсэн (卷舌) — хэлний үзүүрийг дээш, тагнайн урд хэсэг рүү; zh = «дж» агааргүй, ch = «ч» + агаар, sh = «ш» хэл эргэсэн, r = «ж»-тэй төстэй, үрэлт бага, хоолойгоор. i энд «ы» шиг богино (zhi ≠ «жи»). Blend [zh,ch,sh,r] × [i,a,e,u]. Pairs: (zhi,chi), (shi,ri), (zha,cha), (zhu,shu).
7. **z c s** (字 zì 刺 cì 丝 sī): zi ci si. Tips: хэл тэгш, үзүүр нь дээд шүдний ард; z = «дз» агааргүй, c = «ц» + хүчтэй агаар, s = «с». i энд бас «ы» шиг. Blend [z,c,s] × [i,a,e,u]. Pairs (the hardest for Mongolians): (zi,zhi), (ci,chi), (si,shi), (za,zha), (ca,cha), (sa,sha), (zi,ci).
8. **y w** (医 yī 屋 wū): yi wu. Tips: i, u, ü эхэнд ирвэл y/w болж бичигдэнэ; y = «й», w = «в/у» уруул дугуй. Blend: y×[i,a,e,u=ü] (yi ya ye yu), w×[u,a,o] (wu wa wo).
9. **Давхар эгшиг 复韵母** (9): ai→"ai" 爱 ài; ei→"ei" 诶 éi; ui→"wei" 威 wēi; ao→"ao" 袄 ǎo; ou→"ou" 欧 ōu; iu→"you" 优 yōu; ie→"ye" 耶 yē; üe→"yue" 月 yuè; er→"er" 耳 ěr. Tips: хоёр эгшгийг нэг хөдөлгөөнөөр шилжүүлж хэлнэ (ai = «ай» биш, «а»-гаас «и» рүү зөөлөн); ui = uei (ui-г «уй» биш «уэй»); iu = iou («иу» биш «иоу»); ie = «иэ»; üe = «үэ»; er = хэл эргэсэн «ар» (儿). Blend: [b,p,m,d,t,n,l,g,k,h] × [ai,ei,ao,ou] + [j,q,x] × [ie,üe→"jue" etc.]. Pairs: (ai,ei), (ao,ou), (you,wei), (ye,yue).
10. **Урд хамрын эгшиг 前鼻韵母** (5): an→"an" 安 ān; en→"en" 嗯 ēn; in→"yin" 音 yīn; un→"wen" 温 wēn; ün→"yun" 云 yún. Tips: төгсгөлд хэлний үзүүр дээд буйланд хүрч «н» (монгол «н» шиг). Blend common. Pairs: (an,ang) — no, save for unit 11; (an,en), (yin,yun), (wen,yun).
11. **Хойд хамрын эгшиг 后鼻韵母** (4): ang→"ang" 昂 áng; eng→"eng" 亨-ийн эгшиг; ing→"ying" 鹰 yīng; ong→"weng"? No — ong has no standalone syllable; use "hong" 轰 hōng as the audio key with letter «ong». Tips: төгсгөлд хэлний уг тагнайн ар руу — монгол «нг» (ang = «аң» — хэлний үзүүр хүрэхгүй!). The key contrast for Mongolians: an/ang, en/eng, in/ing. Pairs: (an,ang), (en,eng), (yin,ying), (ban,bang), (fen,feng), (lin,ling).
12. **Бүхэл үе 整体认读音节** (16): zhi chi shi ri zi ci si yi wu yu ye yue yuan yin yun ying — read whole, do not blend. Audio keys exist for all (check "yuan"). Tips: 拼读 хийхгүй, бүхлээр нь цээжилнэ.
13. **Дүрэм 拼写规则** (no audio): tone-mark placement (a > o=e > i/u: whichever comes last, «iu/ui дээр сүүлийнх нь»), ü dots drop after j q x y, y/w spelling, 3rd-tone sandhi (nǐ hǎo → ní hǎo), 一/不 change, 儿化, apostrophe (xī'ān). Present as cards with examples that play audio when possible.

For Chinese-locale users (`locale === "zh"`), show `tipZh` when present else the Mongolian tip (leave tipZh out; Chinese users don't need pinyin tips — but keep unit titles bilingual).
