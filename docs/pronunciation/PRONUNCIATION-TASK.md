## 3. Tone-feedback v2 (rebuild the result view of `components/speech/pronunciation-practice.tsx`)
Keep: mic permission flow, recognition verdict, conflict flag, timeouts. Change the result UI:
1. **Per-syllable verdict chips first** (new `lib/speech/tone-score.ts`): segment the user's voiced samples into N syllables (N = parsed pinyin syllables): split on unvoiced gaps > 120 ms; if the number of voiced segments ≠ N, fall back to splitting the voiced time span into N equal parts. For each segment: convert f0 → semitones, normalize to the speaker's own range over the whole utterance (median ± range → Chao 1..5; if range < 3 semitones treat as flat), resample to 10 points, and score against the 4 templates (`toneContour`) using a combination of (a) Pearson correlation of shapes and (b) slope features: start–end delta, min position (for tone 3 the minimum lies in the middle third). Return `{ tone: expected, detected: 1..4 | null, confidence: 0..1, ok: boolean, hint: string }`. Hints (Mongolian, one line each): T1 not flat → «Тэгш, өндөр барь (ˉ)»; T2 not rising → «Дундаас дээш өгс (ˊ)»; T3 no dip → «Доош буугаад дараа нь бага зэрэг өгс (ˇ)»; T4 not falling → «Дээрээс доош огцом буур (ˋ)»; neutral → «Богино, хөнгөн».
