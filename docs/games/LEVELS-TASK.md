«Тоглоомууд дажгүй ажиллаж байгаа ч дараагийн үе гэж алга. 6 дасгал дуусаад л давтаад байна. Үе давдаг тоглоом шиг болгох хэрэгтэй.» Today each game (`app/games/<slug>/page.tsx` → `components/games/<slug>-game-client.tsx`) takes one lesson's vocabulary (`?lessonId=`), builds 6 questions with `lib/games/game-data.ts` builders, shows `GameResultCard` with «Дахин тоглох», and that's it.

## Design — a shared level engine + campaign for 4 games: arrange (排序), match (холбох), translate (орчуулга), missing-word (дутуу үг). (Others can come later.)
1. **`lib/games/levels.ts`** (shared, client-safe types + pure functions):
   - `LEVELS_PER_HSK = { "1": 12, "2": 10, "3": 16, "4": 20, "5": 24, "6": 24, "7-9": 40 }` → level number n maps to (hskLevel, slice index). Total ≈ 146 levels. `levelMeta(n) → { hskLevel, indexInLevel, title: "Үе n", subtitle: "HSK 2 · 3/10" }`. Boss levels: every 5th level within an HSK band is «⭐ Шалгалтын үе» (8 questions, mixed from the whole band so far, pass needs ≥ 7).
   - Stars: correct/total ≥ 1.0 → 3, ≥ 0.83 → 2, ≥ 0.67 → 1, else 0 (fail; level not passed). Pass = ≥ 1 star (boss: ≥ 7/8).
   - Progress store `localStorage["buunduu-game-levels-v1"]`: `{ [gameType]: { [level]: { stars, best, attempts, at } } }` with `getLevelProgress(game)`, `currentLevel(game)` (first level with 0 stars), `saveLevelResult(game, level, correct, total)`, `totalStars(game)`. Also call the existing `saveGameResult` so dashboards keep working (lessonId = `level-<n>`).
2. **Deck API** `app/api/games/level-deck/route.ts` GET `?game=arrange|match|translate|missing-word&level=N` → `{ level, meta, items: GameVocabItem[] }`. Source: `data/hsk_words.json` (fs, cached; add `"/api/games/level-deck": ["./data/hsk_words.json"]` to `outputFileTracingIncludes`). For the band's words sorted by `frequency` (nulls last), take a window: window size 12 words per level for match/translate (they need distractors), 8 for arrange/missing-word (need `example_zh` ≥ 4 chars — filter first). Deterministic per level (seeded shuffle with the level number) so a level looks the same when replayed. Boss levels: 8 words sampled (seeded) from all windows of the band so far. Map fields: `id: simplified`, `chinese`, `pinyin`, `mongolian: meaning_mn`, `hskLevel`, `exampleChinese: example_zh`, `exampleMongolian: example_mn`. Distractors for translate/missing-word come from the same deck (the builders already do that — pass the whole window as `vocabulary`).
3. **Level host** `components/games/level-game-host.tsx` (client): props `{ game, level }`. Loads the deck (fetch), renders the game client with `key={level}` and new optional props on the four clients: `levelMode?: { level: number; total: number; onFinished: (correct: number, total: number) => void }`. In level mode the clients: (a) use the passed vocabulary (already do), (b) question count = 6 (boss 8 — pass `maxQuestions` through), (c) on finish call `levelMode.onFinished` and render **`LevelResultCard`** instead of `GameResultCard`: big stars animation (0–3 ⭐ filling one by one), «Үе N дууслаа», correct/total, «Дараагийн үе →» (enabled only if passed; else «Дахин оролдох»), «Үеийн газрын зураг» link, and «+XP» line (correct × 10, boss ×2). `onNextLevel` → host sets level+1 (URL `?level=` updated with `router.replace`, no full reload) and fetches the next deck — the next level starts immediately on the same screen.
   - Header in level mode: `GameHeader` shows «Үе 7 · HSK 2» and a small star tally for the game; boss levels get «⭐ Шалгалтын үе» badge and a slightly different background tint.
4. **Level map** `app/games/[slug]/levels/page.tsx` (for the 4 slugs; others → notFound) + `components/games/level-map.tsx`: sections per HSK band («HSK 1 · 12 үе»), grid of round nodes: locked 🔒 (grey), current (pulsing ring, «Та энд байна»), passed (stars under it), boss nodes bigger with ⭐. Tap a passed/current node → `/games/<slug>?level=N`. Top: game title, total stars «⭐ 23 / 438», «▶ Үргэлжлүүлэх» (current level). Locked levels are not playable (except the owner's dev flag `?unlock=1`).
5. **Routing**: `app/games/<slug>/page.tsx` for the 4 games: if `searchParams.level` present → render `<LevelGameHost game level />` (server page passes the parsed level; the host fetches the deck client-side); else keep the existing lesson mode exactly as is. The games hub `components/mobile/games-app-view.tsx`: each of the 4 game tiles gets a second line «Үе 7 · ⭐ 12» and links to `/games/<slug>/levels` when the tile is tapped in «campaign» — simplest: keep the tile link as is (lesson mode) and add a small «🗺 Үе давах» pill/button on the tile that links to the level map. Also add a featured card at the top of the games hub: «🏆 Үе давах — 4 тоглоом · ⭐ N» linking to `/games/arrange/levels` (or the game with the lowest current level).
6. **Kids**: nothing special beyond big stars.
7. ZH_UI: «Үе»: "关", «Үе давах»: "闯关", «Дараагийн үе →»: "下一关 →", «Дахин оролдох»: "再试一次", «Үеийн газрын зураг»: "关卡地图", «Та энд байна»: "你在这里", «Шалгалтын үе»: "考试关", «Үргэлжлүүлэх»: exists, «дууслаа»: exists?, «Түгжээтэй»: "未解锁", «Нийт од»: "总星数", plus whatever you add.
