# Dialogues модулийг холбох — 2 жижиг өөрчлөлт

Шинээр 2 файл нэмлээ:

```
components/lesson/modules/DialoguesModule.tsx     ← гол код (чат + хурд)
components/lesson/modules/dialogues-module.css    ← загвар (bs- угтвартай)
```

Player-тэй холбохын тулд аль хэдийн байгаа 2 файлд жижиг засвар хийнэ.

---

## 1) `types/lesson.ts` — нэг талбар нэмэх

`DialogueLine`-д мөрийн аудио файлын (заавал биш) талбар нэмнэ. `Dialogue`-д
дүр зургийн (scene) талбарыг нэмж болно — байхгүй бол алгасна:

```ts
export interface DialogueLine {
  speaker: string;
  zh: string;
  pinyin: string;
  mn: string;
  audio?: string;        // ← ШИНЭ: мөр бүрийн аудио файл (заавал биш)
}

export interface Dialogue {
  id: number;
  title_mn?: string;
  scene_mn?: string;     // ← ШИНЭ (заавал биш): дүр зургийн тайлбар
  audio?: string;        // бүх ярианы нэг MP3 (хэвээр)
  lines: DialogueLine[];
}
```

> JSON-д `audio` талбар одоохондоо байхгүй ч асуудалгүй — байвал файлыг,
> байхгүй бол хөтчийн хятад хоолойг (TTS) уншуулна.

---

## 2) `LessonPlayer.tsx` — модулийг бүртгэх

Дээд талд import нэмнэ:

```ts
import DialoguesModule from "./modules/DialoguesModule";
```

`renderModule()` доторх `switch`-д `dialogues` тохиолдлыг нэмнэ
(одоо `ComingSoon` руу унаж байгааг солино):

```ts
case "dialogues":
  return <DialoguesModule lesson={lesson} onDone={next} />;
```

Болоо. `modules_enabled`-д `"dialogues"` байвал тэр байрандаа автоматаар гарч ирнэ.

---

## Хэрхэн ажилладаг вэ

- **Чат хэлбэр.** Хэлэгчид гарч ирэх дарааллаараа зүүн/баруун талд хуваарилагдана
  (1-р хэлэгч зүүн, 2-р баруун...). Бөмбөлөг бүрт: пиньинь → 汉字 → монгол.
- **Мөр бүрийн аудио.** Мөрд аудио файл (`line.audio`) байвал ТҮҮНИЙГ, байхгүй бол
  хөтчийн хятад хоолойг уншуулна. Дарвал тоглоно, дахин дарвал зогсоно.
- **Хурд 0.5× / 0.75× / 1×.** Дээд талын сонгогчоор. Аудио файлд шууд (тоглож байх
  үед ч), TTS-д дараагийн тоглуулалтаас үйлчилнэ.
- **"Бүгд" товч.** Ярианы бүтэн MP3 (`dialogue.audio`) байвал л гарч ирнэ.
- **Нэг зэрэг нэг л дуу.** Шинэ мөр эсвэл хурд дарахад өмнөх нь автоматаар зогсоно.
  Модулиас гарахад мөн зогсоно.
- **Олон яриа.** Доод талын Өмнөх/Дараагийнх-аар шилжинэ. Сүүлийн яриа дуусахад
  дараагийн модуль руу (`onDone`) автоматаар орно.

## Анхаарах 2 зүйл

1. **Аудио файлын зам.** `audio_base_path` + мөрийн/ярианы зам нийлж бүтэн зам болно
   (Supabase/CDN суурь зам тааруулахад бэлэн). Зам нь `http(s)` байвал тэр чигээрээ
   ажиллана.
2. **TTS хязгаар.** Хөтчийн хятад хоолой үнэгүй, шууд ажиллана — гэхдээ жинхэнэ хүний
   хоолой биш. Мөр бүрд аудио файл нэмбэл автоматаар тэрийг тоглуулна.
