# Бөөндөө Сурцгаая — Хичээлийн Player (Үе 1: код)

Энэ багц нь **schema-driven хичээлийн player**-ийн эхний хувилбар.
JSON-ийг уншаад модулиудыг **дарааллаар** үзүүлнэ. Одоо **2 модуль бүрэн**:
- `hook` → **Хичээлийн нүүр** (Тэмээ багшийн оршил + юу сурах + алхмууд)
- `vocabulary` → **Үгийн карт** (汉字 + пиньинь + монгол + жишээ + дуудлага)

Бусад модуль (dialogues, texts, grammar, дасгал...) одоохондоо "удахгүй" гэсэн
түр харагдацтай — player эвдрэхгүй, бүх урсгал ажиллана. Дараа нэг нэгээр нь нэмнэ.

---

## 1. Файлуудыг хаана тавих вэ

Дараах байдлаар чиний Next.js төслийн дотор хуулна (зам нь чиний бүтэцтэй адил байх ёстой):

```
types/
  lesson.ts                         ← хичээлийн TypeScript төрлүүд
components/
  lesson/
    lesson-player.css               ← загвар (bs- угтвартай, мөргөлдөхгүй)
    LessonPlayer.tsx                ← үндсэн player (модулиудыг удирдана)
    SpeakButton.tsx                 ← дуудлага (аудио эсвэл хөтчийн TTS)
    modules/
      LessonOverview.tsx            ← hook модуль
      VocabularyCard.tsx            ← vocabulary модуль
      ComingSoon.tsx                ← түр placeholder
```

> `@/types/lesson` гэсэн импортыг чиний `tsconfig.json` дахь зам (paths) дэмждэг.
> Хэрэв `@/` ажиллахгүй бол харьцангуй зам (`../../types/lesson`) болгож засна.

## 3. Хэрхэн ашиглах (хичээлийн хуудсан дээр)

```tsx
// app/lessons/[id]/page.tsx  (эсвэл хаана ч хичээлээ үзүүлэх газар)
"use client";

import LessonPlayer from "@/components/lesson/LessonPlayer";
import type { Lesson } from "@/types/lesson";

// Туршилтад: JSON-оо шууд импортлоод үзэж болно.
// (Дараа нь Supabase-аас татаж ирсэн өгөгдлөө дамжуулна.)
import lessonJson from "@/data/lesson-01.json";

export default function LessonPage() {
  const lesson = lessonJson as unknown as Lesson;
  return <LessonPlayer lesson={lesson} onExit={() => history.back()} />;
}
```

### Supabase-аас татаж ашиглах үед
`LessonPlayer`-т өгөх `lesson` объект нь `types/lesson.ts`-ийн `Lesson` бүтэцтэй
таарч байх ёстой (modules_enabled, hook, vocabulary гэх мэт). Импортын JSON чинь
яг энэ бүтэцтэй учраас шууд тохирно.

## 4. Юу ажиллах вэ (одоо)

- **Хичээлийн нүүр**: гарчиг, Тэмээ багшийн оршил (JSON-оос), "юу сурах" тоо
  (32 үг, 3 яриа, 2 эх, 5 дүрэм — автоматаар), модулийн жагсаалт, "Эхлэх" товч.
- **Үгийн карт**: үг бүрийн 汉字 + пиньинь + монгол + (байвал) жишээ өгүүлбэр.
  🔊 товч — **аудио файл байхгүй учраас хөтчийн хятад дуу (TTS)** ашиглана.
  "Мэднэ / Дахин давтах" + Өмнөх/Дараагийнх. Бүх үг дуусвал дараагийн модуль руу.

## 5. Шударга тэмдэглэл (анхаарах)

- **Дуудлага (TTS):** одоохондоо үгийн дуудлагыг **хөтчийн** хятад хоолойгоор уншуулж
  байгаа (өгөгдөлд үг тус бүрийн аудио файл алга). Энэ нь үнэгүй бөгөөд шууд ажиллана,
  гэхдээ жинхэнэ хүний хоолой биш. Дараа үг бүрд аудио файл нэмбэл автоматаар тэрийг
  тоглуулна (SpeakButton-д `src` өгөхөд хангалттай).
- **Жишээ өгүүлбэр:** зөвхөн `example_zh` (хятад) байгаа үгэнд л жишээ харагдана.
  Пиньинь/монгол орчуулга нь өгөгдөлд **байхгүй тул зохиогоогүй** — `example_pinyin`,
  `example_mn` талбар нэмбэл автоматаар харагдана.
- **声调 = "хөг"** гэсэн нэр томьёог код/контентод баримтална.

## 6. Дараагийн алхам

Энэ 2 модуль аппдаа ороод ажиллаж байгааг баталгаажуулсны дараа:
- `dialogues` (чат хэлбэр, аудиотой, 0.5×/0.75×/1× хурд)
- `grammar` (загвар тодорсон)
- `exercises` (шалгалт — зөв/буруугийн тайлбартай)
- гэх мэтийг нэг нэгээр нь нэмнэ.
